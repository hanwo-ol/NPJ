# S1-2 LODO: 26개 데이터셋 상세 결과

본 문서는 S1-2 Leave-One-Dataset-Out 실험의 26개 데이터셋별 상세 결과를 기록한다. 각 행은 해당 데이터셋을 타겟으로 설정하고, 동일 주기 그룹의 나머지 데이터셋을 소스로 사용하여 학습한 결과이다.

---

## 결과 해석 가이드

- **RMSE** (mg/dL): 연속 예측 오차. 낮을수록 좋다.
- **Delta**: 전이학습 RMSE - Target-Only RMSE. 양수이면 전이학습이 더 나쁘고, 음수이면 전이학습이 더 좋다.
- **음영 처리**: Delta가 0 이하(전이학습이 유리하거나 동등)인 셀을 별표(*)로 표시하였다.
