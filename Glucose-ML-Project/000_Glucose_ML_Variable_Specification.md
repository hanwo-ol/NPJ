# 다기관 CGM 예측 모델 입력 및 목표 변수 정의서 (문서 1)
**— 정적 인구통계학적 지표부터 동적 시계열 채널 및 예측 타겟 정의까지 —**

본 문서는 Glucose-ML 프로젝트의 다기관/다양성 연속혈당측정(CGM) 시계열 예측 모델에 투입되는 입력 변수(Features)와 예측 대상인 목표 변수(Target)의 구성 및 역할에 대해 정의합니다.

---

## 1. 입력 변수 (Input Variables / Features)

입력 변수는 모델이 과거 이력을 토대로 미래 혈당 변화 양상을 학습할 수 있도록 제공되는 정보군으로, 성질에 따라 정적 변수(Static)와 동적 변수(Dynamic)로 분류됩니다.

### 1.1. 정적 변수 (Static Variables / Demographics)
시각에 따라 변하지 않고 환자의 고유 상태 또는 배경 정보를 나타내는 변수군입니다.
- **나이 (Age):** 환자의 연령 수치(세). 누락 시 해당 코호트의 중앙값(T1DM: 35세, ND: 40세, GDM: 30세)으로 Imputation 처리됩니다.
- **성별 (Sex):** 환자의 생물학적 성별. Female은 1.0, Male은 0.0, 미식별 시 코호트 기본값인 0.5로 설정됩니다.
- **당화혈색소 (HbA1c):** 과거 약 2~3개월간의 평균 혈당 상태를 나타내는 지표(%). 누락 시 eGMI 추정치 수식 또는 코호트별 중앙값(T1DM: 7.8, ND: 5.4, GDM: 5.9)으로 Imputation을 이행합니다.
- **코호트/질환군 분류 (Cohort One-hot):** 데이터셋이 속한 당뇨병 임상 하위 분류군 지표로, 원핫 인코딩(One-hot encoding) 형태로 제공됩니다.
  - T1DM (제1형 당뇨병): `[1, 0, 0]`
  - ND (비당뇨군): `[0, 1, 0]`
  - GDM (임신성 당뇨병): `[0, 0, 1]`

### 1.2. 동적 시계열 변수 (Dynamic Variables / Time Series)
시간의 흐름에 따라 순차적으로 계측되는 연속 측정 변수군입니다. 입력 텐서의 시퀀스 형태 `[Batch, Lookback_Steps, Input_Channels]`를 구성합니다.

#### 1.2.1. 기저 혈당 변수 (Core Glucose Value)
- **혈당 수치 (`glucose_value_mg_dl`):** CGM 센서로부터 매 분 또는 매 5분/15분 주기로 계측된 1차 혈당 측정값(mg/dL)입니다. 모든 입력 채널의 제0번 인덱스에 매핑되는 핵심 시계열입니다.

#### 1.2.2. 외생 변수 / 공변량 (Exogenous Covariates / Event Logs)
각 의료기관 데이터셋마다 부분적으로 지원되는 치료 및 행동 이벤트 로그 데이터입니다. 데이터 로딩 시점의 컬럼 매핑 규칙에 따라 우선순위 탐색 후 입력 채널에 누적 결합됩니다.
- **인슐린 투여량 (Insulin):** 속효성(Bolus) 또는 기저(Basal) 인슐린 주입량(Units).
- **탄수화물 섭취량 (Carbs / Meal Input):** 식사 또는 간식을 통해 섭취한 탄수화물 중량(g) 및 칼로리(kcal).
- **생체 신호 및 활동 지표:** 스마트워치 또는 외부 센서로 측정된 심박수(Heart Rate, bpm) 및 누적 걸음 수(Steps).

---

## 2. 목표 변수 (Target Variable)

모델이 예측해야 하는 최종 타겟 출력값입니다.

- **목표 혈당 수치 ($Y$):** 미래의 특정 시점인 $t + n_{fwd}$의 혈당 값 $G_{t+n_{fwd}-1}$ (mg/dL)입니다.
- **예측 지평선 (Horizon):** 
  - 기본 규격: `PREDICTION_STEPS = 3` (현재 시각 $t-1$ 기준 $t+2$ 시점의 실측 혈당).
  - 샘플링 주기가 5분인 센서에서는 15분 뒤의 혈당값을 의미하며, 15분 주기 센서에서는 45분 뒤의 혈당값을 의미합니다.
- **출력 채널 수 (Target_Channels):** 다변량 입력을 받더라도 최종 예측 대상은 혈당값 단독이므로 언제나 $1$ 채널로 고정됩니다.

## 3. 입출력 토폴로지 요약 테이블

| 데이터 성격 | 변수명 | 데이터 타입 | 입력 채널 인덱스 | 텐서 차원 형태 |
|:---|:---|:---|:---|:---|
| **동적 (입력)** | `glucose_value_mg_dl` | float32 | `[:, :, 0]` | `[Batch, Lookback_Steps, 1]` |
| **동적 (입력)** | 외생 변수 (인슐린, 식사 등) | float32 | `[:, :, 1:1+K]` | `[Batch, Lookback_Steps, K]` |
| **정적 (입력)** | 나이, 성별, HbA1c, 질환 코호트 | float32 | 별도 병합 (MLP) | `[Batch, Demographics_Dim]` |
| **동적 (출력)** | 미래 혈당 수치 ($Y$) | float32 | 예측 타겟 | `[Batch, Horizon_Steps, 1]` |
