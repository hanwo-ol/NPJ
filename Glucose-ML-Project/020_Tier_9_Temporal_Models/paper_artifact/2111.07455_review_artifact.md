# Literature Survey Review: HAD-Net: Hybrid Attention-based Diffusion Network for Glucose Level Forecast

- **논문 제목**: HAD-Net: Hybrid Attention-based Diffusion Network for Glucose Level Forecast
- **저자**: Quentin Blampey & Mehdi Rahim (Air Liquide R&D / ML4H 2021 / arXiv:2111.07455)
- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

---

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 연속혈당측정(CGM) 데이터를 이용한 단기 혈당 예측(30분, 60분)은 저혈당 및 고혈당 사고를 미연에 방지하기 위해 필수적임.
- 그러나 순수 데이터 기반의 신경망 모델(LSTM, GRU 등)은 우수한 예측력을 보임에도 인슐린과 탄수화물의 신체 내 상호작용에 관한 생리학적 해석 가능성(Interpretability)이 완전히 결여되어 임상의 신뢰도가 낮음.
- 반면, 기전학적 생리 모델은 인슐린-글루코스 역학을 수학적으로 설명하지만, 매개변수 강성이 높아 개별 환자의 환경 변화에 유연하게 대응하지 못해 예측 오차가 큼.

### 1.2 제안하는 방법론: HAD-Net
- **그래프 확산 생리 모델 (Graph Diffusion Physiological Model, GDPM)**:
  - Bergman의 미니멀 모델 및 Goel의 연구에 기반하여, 체내 혈당-인슐린 메커니즘을 그래프 확산 시스템으로 재정의함.
  - 노드는 7개의 생리적 변수(PV: Glucose G, Plasma Insulin I, Remote Insulin R, Stomach Food qsto, Gut Food qgut, 그리고 오차 보정 변수 $\epsilon^+$, $\epsilon^-$)로 매핑됨.
  - 인접 행렬(Adjacency Matrix) $A$는 체내의 물질적 인과관계(예: Remote Insulin이 Glucose를 감소시키는 소모 반응은 $A_{1,3} = -1$)를 물리적 제약 조건으로 표현함.
- **자가 어텐션 기반 확산량(Flow Magnitude) 학습**:
  - 각 노드의 생리 변수와 은닉 상태(Hidden states)를 결합한 임베딩 행렬 $E$를 생성함.
  - 고정된 생리학적 상수를 사용하는 대신, 노드 쌍의 상호작용 강도를 자가 어텐션(Self-Attention) 메커니즘($F = \sigma(a_0 + \frac{QK^T}{\sqrt{d}})$)을 통해 동적으로 학습하여 물질 확산 속도를 환자 상태에 맞추어 보정함.
- **예측 및 오차 보정 루프**:
  - **Inference (추론기)**: 과거 32스텝(160분) 동안 실측 CGM 값을 글루코스 노드에 직접 덮어씌우는 SetGlucose 연산과 예측 편차를 누적하는 AddError 연산을 통해 모델의 내부 구획 변수들을 역학에 맞게 정렬함.
  - **Forecast (예측기)**: 정렬된 최종 구획 상태를 출발점으로 삼아, 외생 인슐린/탄수화물 입력(AddExogenous)과 자연 확산 물리 공식(Euler integration)을 통해 30분, 60분 뒤 미래 혈당을 연속 예측함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **생리학적 일관성 결여**: 데이터 패턴에 의존하여 급격한 외생 변수 주입 시 혈당 예측값이 물리적으로 불가능한 변동(예: 인슐린 대량 투여 직후 혈당 스파이크 발생 등)을 보이며 요동치는 현상이 나타남.
- **잔차의 잔여 정보 소실**: 오차 잔차가 시간에 따라 가지는 시계열적 특성(ACF)이 백본 피처로 역공급되지 않아 오버슈팅이 억제되지 못함.

### 2.2 HAD-Net의 우리 연구 적용 방안 (Biologically-Constrained Loss & Feature)
- **손실 함수 내 물리적 규제화(Physiological Regularization) 도입**:
  - 신경망의 학습 손실 함수에 HAD-Net의 7구획 자연 확산 물리 방정식의 잔차를 규제화 항($L_{nr}$)으로 추가하여, 인슐린과 탄수화물의 작용량 범위가 물리 법칙을 위배하지 않도록 가이드함.
- **간이 5구획 생리 채널 생성**:
  - 환자의 CGM, 인슐린 bolus/basal, 식사 carb 데이터를 간소화된 5구획(stomach -> gut -> plasma insulin -> remote action -> blood glucose) 적분 수식에 통과시켜 각 단계의 확산 누적값들을 LightGBM의 신규 입력 피처 채널로 병렬 주입.

## 3. 검증 및 실험 로드맵 제안

### 3.1 Baseline 비교군 설정
1. **LightGBM (Base)**: 일반적인 CGM 및 인슐린 투여량 피처만 사용하는 모델.
2. **LightGBM + Pure Physical ODE**: 고정된 Bergman 미니멀 모델의 시뮬레이션 값을 결합한 모델.
3. **LightGBM + HAD-Net Dynamic GDPM (Proposed)**: 자가 어텐션으로 가변 튜닝된 생리 구획 변수를 피처로 투입한 모델.

### 3.2 핵심 평가 메트릭
- **30분 및 60분 Horizon**: RMSE, MARD, 그리고 클라크 에러 그리드(Clarke Error Grid) 존 A+B 비율.
- **생리적 상관 정합성**: 인슐린 작용 시점의 지연 시간 정합성.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

본 섹션은 감시자 에이전트(인격 3)가 연구원 에이전트(인격 2)의 1차 설계 아티팩트를 검수하고 남긴 비판적 검토 의견입니다.

### 4.1 3-step Lookback 제약 하에서의 160분(32스텝) 역사적 Inference 루프 수행 불가
- **지적 사항**: HAD-Net은 현재 시점의 생리 변수 상태($v_t$)를 정렬하기 위해, 과거 32스텝(160분) 동안의 데이터를 역추적하여 AddError 및 SetGlucose 등의 Recurrent Inference 단계를 온라인으로 실행해야 합니다. 그러나 본 프로젝트는 실시간 추론 시 단 3스텝(15분)의 데이터만 룩백할 수 있으므로, 과거 32스텝의 시계열을 수집하여 온라인 역방향 시뮬레이션을 수행하는 것은 규정 위반입니다.
- **개선 요구**: 3스텝의 극도로 짧은 룩백 조건 하에서도 7구획 생리 변수가 정상적으로 수렴하고 초기화될 수 있는 점진적 가상 추적(Incremental Virtual Tracking) 방식을 수립하십시오.

### 4.2 자가 어텐션 기반 확산량 연산의 CPU 병목 및 지연
- **지적 사항**: HAD-Net은 매 5분 적분 스텝마다 7x7 크기의 자가 어텐션 행렬 $F$를 계산하기 위해 쿼리, 키, 밸류 벡터에 대해 3중 $K$-Linear 변환을 연산해야 합니다. 다단계 미래 예측(예: 12스텝) 시 매 적분 스텝마다 이 복잡한 신경망 연산이 수반되면 실시간 CPU 제약 하에서 처리 성능이 고갈됩니다.
- **개선 요구**: 미래 예측 스텝 중 자가 어텐션 가중치 연산을 상수로 선형화하거나 경량화하여 추론 지연을 제약 수준 이하로 낮추십시오.

### 4.3 에러 구획 변수($\epsilon^+$, $\epsilon^-$)의 실시간 정렬 불완전성
- **지적 사항**: 실측 데이터와 시뮬레이션 상태 간의 오차를 연속 누적하는 $\epsilon^+$, $\epsilon^-$ 변수는 센서 드리프트나 임시적 패치 탈착이 일어날 경우 오차가 오버플로우되거나 영구적으로 왜곡되어 상태 정렬을 망칠 우려가 큽니다.
- **개선 요구**: 에러 누적기의 폭주를 제한할 수 있는 수학적 정규화 장치나 감쇄 상수를 도입하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

본 섹션은 수정자 에이전트(인격 4)가 감시자(인격 3)의 지적 사항을 적극적으로 검토하여 수립한 최종 보완 설계안입니다.

### 5.1 상태 보존형 영구 온라인 적분 엔진 (State-Persistent Online Integration Engine)
- **수정 설계**: 실시간 추론 요청이 왔을 때 과거 160분의 기록을 역방향 추적하는 대신, 실시간 CGM 수신 스레드에서 **생리 구획 상태 벡터($v_t$)를 지속적으로 누적 갱신**하는 구조를 도입합니다.
- **구체적 구현**:
  - 데이터베이스나 프로세스 내 전역 상태 세션에 직전 스텝의 생리 상태 $v_{t-1}$과 은닉 상태 $H_{t-1}$을 항상 보관합니다.
  - 매 5분마다 CGM 실실측값($X_{1,t}$)이 들어오면, 역방향 32스텝 루프를 도는 대신 현재 수신된 1스텝 분량의 데이터로만 Euler 적분(1 step update)을 수행하여 즉각 $v_t$를 업데이트합니다. 룩백 윈도우는 오직 1스텝 단위의 업데이트를 트리거할 뿐이므로 3스텝 룩백 제한을 완벽하게 만족합니다.

### 5.2 자가 어텐션의 오프라인 'Metabolic Matrix' 선형화 프로파일링
- **수정 설계**: 미래 12스텝 예측 시 매 적분 단계마다 복잡한 자가 어텐션 연산을 반복 실행하지 않고, 현재 시점($t$)에서 계산된 최신 확산 행렬 $F_t$를 미래 60분 예측 구간 동안 고정하여 사용하는 **1차 선형화 확산 매트릭스(First-order Linearized Diffusion Matrix)** 방식을 적용합니다.
- **구체적 구현**:
  - 현재 시점 $t$의 입력 임베딩 $E_t$를 통과시켜 $F_t$ 행렬을 단 1회 연산합니다.
  - 미래 12스텝(60분)을 시뮬레이션할 때는 새로운 쿼리/키/밸류의 재연산 없이 $F_{t+i} \approx F_t$로 가정하여, 상태 변환식 $v_{t+1} = (A \odot F_t - Diag((|A|^T \odot F_t)\rightarrow))v_t$를 순수 선형 행렬곱 연산만으로 12회 빠르게 가동시킵니다. 이를 통해 예측 구간 내 신경망 포워드 연산량을 제로(Zero)에 가깝게 절감하여 CPU 지연 시간을 극도로 줄입니다.

### 5.3 지수적 누적 오차 감쇄(Exponentially Decaying Error Compartment) 규칙 적용
- **수정 설계**: 센서 왜곡에 의한 오차 누적 폭주를 방지하기 위해, 오차 구획 변수 $\epsilon^+$, $\epsilon^-$의 상태 업데이트 공식에 **지수 감쇄 팩터(Exponential Decay Factor, $\lambda = 0.85$)**를 결제 적용합니다.
- **수식화**:
  - $\epsilon^+_t = \lambda \epsilon^+_{t-1} + \epsilon_t \mathbb{1}_{\mathbb{R}^+}(\epsilon_t)$
  - $\epsilon^-_t = \lambda \epsilon^-_{t-1} - \epsilon_t \mathbb{1}_{\mathbb{R}^-}(\epsilon_t)$
  - 감쇄 계수 $\lambda$를 도입하여 과거 시점의 센서 왜곡 충격이 1시간 내에 자연적으로 소멸하게 함으로써, 상태 변수의 비정상적 발산 및 왜곡을 수학적으로 방지합니다.
