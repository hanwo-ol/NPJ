## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 1차원 시간 영역(1D Time domain)에서 다중 주기(Multi-periodicity)를 가진 시계열 데이터를 직접 모델링할 때, 여러 주파수가 뒤엉켜 국소 변동(Intraperiod variation)과 장기 추세(Interperiod variation)를 동시에 구분해 학습하기 어려운 문제를 해결하고자 함.
- 1D 순차 레이어가 가진 장기 의존성 학습의 한계를, 컴퓨터 비전의 검증된 2D 합성곱(CNN) 아키텍처를 시계열로 변환 적용하여 우회하고자 함.

### 1.2 제안 방법론: TimesNet 및 TimesBlock
- **주기 추출 (FFT-based Period Extraction)**: 고속 푸리에 변환(FFT)을 사용하여 입력 시퀀스의 지배 주파수(Dominant frequencies)들을 분석하고 상위 $k$개의 주기들을 적응형으로 추출.
- **1D to 2D 텐서 변환 (2D Reshaping)**: 각 추출 주기 $P_i$를 기준으로 1D 시퀀스를 2D 텐서 `(인덱스 변동, 주기 간 흐름)` 구조로 재배치.
  - *Intraperiod-variation (열 방향)*: 1주기 내에서의 미시적 변동(예: 시간별 흐름).
  - *Interperiod-variation (행 방향)*: 주기 간의 거시적 추세(예: 일별 흐름).
- **2D 합성곱 학습 (TimesBlock & Inception)**: 변환된 2D 텐서에 2D CNN 커널(Inception Block)을 적용하여 다차원 스케일의 국소/전역 시간 특징을 동시에 추출한 뒤, 최종 1D 벡터로 복원 결합.
- **성공적 결과**: 예측, 결측치 대체, 이상 탐지, 분류 등 시계열 5대 주요 과제 전반에서 압도적인 SOTA 성능과 뛰어난 파라미터 효율성을 검증함.

## 2. Glucose-ML 프로젝트(Stage 2) 적용 방안

### 2.1 매핑점
- **혈당 변동의 다중 주기 대사 모델링**: 혈당 수치는 일주기 리듬(24시간)과 식사 주기(약 4~6시간) 등의 명확한 **다중 주기성**을 띰. TimesNet의 **2D 변환 기법**을 차용하여, 혈당 시퀀스를 식사 주기 단위로 잘라 2D로 배치하면, 식사 중의 단기 변동성(Intraperiod)과 일일 기저 인슐린 농도 변동(Interperiod)을 분리하여 학습할 수 있음. 이를 통해 Stage 1 LightGBM이 놓친 거시-미시 하이브리드 대사 동역학 복원 가능.
- **2D CNN 인프라의 연산 안정성**: Attention 연산이 배제되어 CPU LODO 프로토콜 훈련 시 비교적 경량으로 고성능을 도출.

### 2.2 구현적 시사점
- FFT를 통한 주기 추출 후 텐서 Reshape 연산과 `nn.Conv2d`를 활용한 Inception 레이어 결합 모듈을 PyTorch로 구현하여 전처리 인코더로 빌드.

## 3. 한계점
- **초단기 룩백에서의 2D 변환 붕괴**: `LOOKBACK_STEPS=3` 세팅은 3포인트 데이터만 있으므로 FFT를 돌려도 유의미한 주기가 나오지 않으며, 2D 텐서로 Reshape할 시 한 차원의 크기가 1이나 2가 되어 2D CNN의 커널 크기(3x3, 5x5 등)보다 작아져 연산이 불가능해지거나 형상이 붕괴됨.
- **FFT의 연산 불안정성**: CPU 환경에서 단기 시퀀스를 매 미니배치마다 FFT 연산하여 2D로 변경하는 작업은 상당한 메모리 스왑 및 훈련 지연의 요인이 됨.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 3스텝 룩백에서의 2D 이미지화 불합리 및 차원 붕괴
- **지적 사항**: TimesNet은 시퀀스가 충분히 길어 2D 이미지의 형상을 띨 수 있을 때 작동합니다. 3스텝 인풋으로 2D Reshape를 가하면 텐서 크기가 Conv2D 커널(예: 3x3)보다 작아서 연산 오류가 납니다. 커널을 1x1로 축소하는 것은 단순 Linear 연산에 불과하므로 2D 변환의 실익이 없고 연산만 지연됩니다.
- **개선 요구**: 3스텝 룩백 조건에서는 FFT 및 2D 텐서 변환을 생략하고 1D Causal Conv 레이어로 바이패스하십시오. 룩백이 24스텝 이상일 때만 2D 변환을 허용하되 주기는 FFT 대신 고정 주기(예: 12스텝=1시간)로 정적 제정하여 연산 지연을 차단하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 1D/2D 가변형 하이브리드 인코더 및 정적 주기 적용 설계
- **수정 설계**: 감시자의 차원 붕괴 에러 및 연산 지연 지적을 해결하기 위해 다음과 같이 우회 조정합니다.
- **시퀀스 길이 연동형 이미지화 생략**:
  - `LOOKBACK_STEPS=3`인 단기 시나리오에서는 FFT와 2D 변환 모듈을 비활성화하고, 원본 3스텝 데이터를 1D Causal Conv1D 레이어와 MLP에 통과시켜 특징 맵을 직접 구성합니다.
  - `LOOKBACK_STEPS`가 24 이상인 경우에 한해서만, 2D 변환 모듈을 활성화합니다.
- **정적 주기(Static Period) 설정**:
  - 미니배치마다 FFT를 적용하는 무거운 dynamic 연산 대신, 도메인 지식을 활용하여 1시간 대사 주기(12스텝)를 정적 주기 parameter로 고정하여 2D Reshaping을 수행함으로써 CPU 연산 지연을 원천 차단합니다.
- **Inception 커널 크기 비대칭 제어**:
  - 2D 합성곱 시 윈도우 크기가 붕괴하는 것을 막기 위해 Inception 커널 크기를 3x3 대신 비대칭 형태(예: 1x3, 3x1)로 조정하여 정보 소실을 방지합니다.
- 은닉 채널 수는 16, 내부 합성곱 깊이는 1층으로 축소하여 CPU 사양을 준수합니다.
