## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 기전적 상미분방정식(ODE) 모델은 생리학적 인과성(Causal grounding)을 제공하지만 현실의 복잡한 비선형성(예: 운동 효과)과 개인별 변동성을 반영하지 못함.
- 반면 블랙박스 딥러닝 모델은 데이터 피팅력은 우수하지만, 운동/인슐린/탄수화물 간의 혼재(Confounding)로 인해 비인과적인 상관관계(예: 인슐린 주입이 혈당을 올린다고 오판하거나, 운동이 저혈당 위험을 낮춘다고 추론)를 학습하는 인과적 역전(Causal Reversal) 현상이 일어남.
- 유연성을 높인 하이브리드 모델(MNODE, LPSC 등) 역시 순수 예측 오차(MSE) 최소화로만 학습할 경우 인과성이 쉽게 무너져 무작위 임의 추정과 동일한 수준으로 전락함.

### 1.2 제안하는 방법론: H2NCM (Hybrid2 Neural ODE Causal Modeling)
- **하이브리드 디코더 및 인코더 구조**:
  - **컨텍스트 인코더 ($M_{context}$)**: 과거 이력($T_{context}$)의 CGM 계측치 및 인슐린 주입 기록을 입력받아 초기 생리 상태 및 잠재 변수 $(s_0, z_0)$를 추정하는 시퀀스-투-시퀀스 모델.
  - **하이브리드 ODE 디코더 ($M_{pred}$)**: 기전적 물리 변수 $s$와 신경망으로 학습되는 보정 상태 $z$의 전이 역학을 동시에 수행하는 신경 ODE(Neural ODE) 디코더.
- **예측-인과 하이브리드 손실 함수 (Hybrid Loss)**:
  - $L_{hybrid} = (1 - \alpha) L_{pred} + \alpha L_{causal}$
  - **예측 손실 ($L_{pred}$)**: 미래 예측 혈당 궤적과 실제 값 간의 MSE.
  - **인과 손실 ($L_{causal}$)**: 가상의 다중 탄수화물/인슐린 주입 시나리오($X^{(i)}$) 하에서 예측된 혈당 변화 크기(Treatment Effect)의 순위(Ranking)가 생리학적으로 널리 알려진 순서(예: 탄수화물 섭취량이 클수록 혈당이 높음)와 일치하도록 소프트맥스 교차 엔트로피(Softmax Cross-Entropy) 페널티를 강제함.
- **성능**: 실제 제1형 당뇨병 환자들의 운동 임상 데이터셋인 T1DEXI 데이터를 활용하여 검증함. 하이브리드 손실 함수를 도입하여 예측 정확도를 세계 최고 수준으로 유지하면서도, 인과적 순위 오류율을 거의 0%에 수렴시켜 모델의 안전성을 정비함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **인과적 반사 오류**: 식사 섭취 직후 동시 볼러스 인슐린 투입 시, 모델이 탄수화물과 인슐린의 반대 작용을 구분하지 못해 식사 피처의 기여도를 음수로 왜곡하거나 인슐린 주입 시 혈당 강하 기울기를 과소 추정하는 현상 발생.
- **외삽 시의 발산**: 15분 룩백 기반 다단계 예측 시 기전적 경계가 없어, 특정 공변량이 결합될 때 혈당 예측 곡선이 비이상적으로 치솟거나 급락하는 불안정성이 상존함.

### 2.2 H2NCM의 우리 연구 적용 방안 (Causal Ranking Loss & Monotonic Constraints)
- **인슐린-탄수화물 인과적 순위 손실 도입**:
  - 우리 시계열 예측 모델의 학습 목적 함수에 인과적 순위 정형화 항(Causal Ranking Regularizer)을 설계함.
  - 학습 시 배치 단위로 가상의 인슐린/식사 변동 시나리오를 구성하고, 모델의 예측 궤적 크기가 "인슐린 주입량 증가 = 혈당 강하율 증가" 및 "탄수화물 섭취량 증가 = 혈당 상승률 증가"의 단조성(Monotonicity) 순위를 유지하도록 유도함.

## 3. 검증 및 실험 로드맵 제안

### 3.1 Baseline 비교군 설정
1. **Pure Predictive Model**: 인과 순위 손실 없이 오직 MAE/MSE로만 학습한 시계열 MLP/TCN.
2. **Monotone Neural Network**: 물리적 단조성을 위해 네트워크 가중치에 비음수 제약을 직접 걸어 유연성을 희생시킨 모델.
3. **H2NCM Hybrid Model (Proposed)**: 유연한 백본에 시나리오 기반 Causal Ranking Loss를 탑재하여 다단계 혈당 예측과 인과 관계를 동시에 확보한 모델.

### 3.2 핵심 평가 메트릭
- **예측력**: Horizon 30분, 60분 혈당 MAE/RMSE.
- **인과 타당성 (Causal Validity)**: 무작위 생성된 인슐린/식사 시나리오에 대해 "투입량 증가 대비 예측 혈당 역관계"를 올바르게 판별한 비율.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 15분(3스텝) CGM 및 인슐린 입력 룩백 하에서 컨텍스트 인코더의 상태 초기화 실패
- **지적 사항**: H2NCM은 과거 컨텍스트 윈도우 $T_{context}$ (보통 수 시간에서 수 일)를 활용하여 체내 인슐린 잔량(IOB) 및 미소화 식사량 등 복잡한 잠재 생리 상태 $(s_0, z_0)$를 인코더로 포착함. 그러나 15분(3스텝)의 짧은 이력 데이터만을 입력으로 주입할 경우, 인코더가 과거 2~3시간 전 투입된 인슐린의 잔여 효과를 인지하지 못해 초기치 $(s_0, z_0)$가 0으로 수렴하거나 극도로 왜곡되는 상태 유실(State Loss) 현상이 발생함.
- **개선 요구**: 15분 룩백 하에서 초기 생리 상태 $(s_0, z_0)$의 정밀도를 보존할 수 있는 오프라인 프로파일 추정 및 하이브리드 초기화 기법을 도입하십시오.

### 4.2 실시간 추론 루프 내 Neural ODE 수치적 적분기(Solver) 구동으로 인한 연산 부하
- **지적 사항**: Neural ODE는 Runge-Kutta(RK45) 등 수치 적분기 내부에서 다층 신경망(f)을 수차례 평가(Forward Pass)해야 함. 이는 실시간 5분 단위 다단계 Horizon 예측 시 막대한 연산 오버헤드와 CPU 연산 지연을 초래하여 모바일 환경에 탑재하기에 극도로 부적합함.
- **개선 요구**: 실시간 추론 시 수치 적분기의 반복 호출을 배제하고 단일 1-스텝 Forward Euler 계산으로 연산을 축소할 수 있는 경량화 구조를 제시하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 오프라인 프로파일 매핑 매칭 및 정적 초기 상태 주입 (Profile-Based State Initialization)
- **수정 설계**: 15분 룩백 하에서 컨텍스트 인코더를 사용하는 대신, 환자의 오프라인 기본 대사 메타데이터(예: 일일 총 인슐린 요구량, 인슐린 민감도 지수, 공복 혈당)를 기반으로 고정된 **생리학적 초기 프로파일 룩업 테이블(Physiological Profile Lookup Table)**을 활용함.
- **구체적 구현**:
  - 추론 시점의 3스텝 CGM 및 인슐린 입력만으로 인코더를 돌리지 않고, 사전 등록된 환자 프로파일 매트릭스에서 해당 시점의 기본 물리 상태 $s_0$를 직접 매핑 주입함.
  - 시간 보정 변수 $z_0$는 0으로 초기화하고, 이후 실시간 수집되는 incremental dynamic covariates를 통해서만 순방향 갱신되도록 차단하여 Warm-up 오차를 원천 배제함.

### 5.2 1-스텝 Euler 전이 근사 및 초경량 MLP 구조 적용
- **수정 설계**: 수치 적분기(ODE Solver)의 실시간 구동을 전면 배제하고, 고정 시간 간격 $T=5$분에 맞춰 단 1회의 **Forward Euler 1-스텝 대칭 차분 근사(Single-step Euler Transition)**를 수행하도록 강제함.
- **구체적 구현**:
  - 디코더 내부의 적분 루프를 완전히 소멸시키고, $s_{k+1} = s_k + T \cdot [m(s_k, x_k) + f(s_k, x_k; \theta)]$ 형태의 일차 대수 공식으로 직접 연산함.
  - 신경망 $f$의 크기를 2레이어(은닉 유닛 16개) 이하의 초경량 MLP로 대폭 제한하고 ReLU 활성화 함수만을 사용하여 부동 소수점 연산량(FLOPs)을 극소화함으로써 싱글 코어 CPU 환경에서 실시간 5ms 이내의 연산 속도를 보장함.
