# Literature Survey Review: A Decoder-Only Foundation Model for Time-Series Forecasting

- **논문 제목**: A Decoder-Only Foundation Model for Time-Series Forecasting (TimesFM)
- **저자**: Abhimanyu Das, Weihao Kong, Rajat Sen, & Yichen Zhou (Google Research / arXiv:2310.10688)
- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

---

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- NLP 분야에서 대형 기초 모델(Foundation Model)이 큰 성공을 거둔 것과 달리, 시계열 분야에서는 도메인별 가변적인 주파수, 결측값 패턴, 그리고 불규칙한 컨텍스트/예측 길이 문제로 인해 단일 범용 제로샷(Zero-shot) 예측 모델을 설계하는 데 어려움이 있었음.
- 기존 연구들은 시계열 데이터를 사전 학습된 언어 모델(LLM)에 텍스트 형태로 프롬프팅하여 예측을 수행하려 했으나, 이는 토큰 연산 오버헤드가 극도로 크고 시계열 고유의 수치적 변동성을 충분히 보존하지 못한다는 한계가 존재함.

### 1.2 제안하는 방법론: TimesFM
- **디코더 전용 아키텍처 (Decoder-only Attention)**:
  - 입력 패치 시퀀스를 받아 다음 패치를 순차적으로 예측하는 Causal Attention 구조를 채택함.
  - LLM과 동일하게 병렬 교사 강제(Teacher Forcing) 학습이 가능하여 대규모 데이터셋에 대한 학습 효율성을 극대화함.
- **입출력 비대칭 패칭 (Asymmetric Input/Output Patching)**:
  - 입력 패치 크기(p = 32)는 연산량 감소를 위해 작게 유지하되, 출력 패치 크기(h = 128)는 더 길게 설정함.
  - 이를 통해 긴 예측 Horizon을 출력할 때 오토레그레시브(Auto-regressive) 디코딩 반복 횟수를 대폭 낮추고 예측 정확도의 누적 왜곡을 줄임.
- **패치 마스킹 전략 (Patch Masking)**:
  - 첫 번째 패치의 일부분을 무작위로 마스킹 처리하여, 모델이 패치 크기의 배수 단위뿐 아니라 임의의 모든 컨텍스트 길이(1부터 Max Context까지)에 대응할 수 있도록 유연성을 부여함.
- **대규모 시계열 Pretraining 코퍼스**:
  - Google Trends(검색어 빈도), Wikipedia Pageviews(페이지 뷰 트래픽), 그리고 합성 시계열 데이터(ARMA, 트렌드, 주기 결합)를 조합하여 총 1,000억 개의 데이터 포인트를 사전 학습에 활용함.

### 1.3 실험 결과
- Monash, Darts, ETT 등 사전 학습에서 제외된 다양한 공개 시계열 벤치마크 데이터셋에서 제로샷으로 평가를 수행함.
- TimesFM은 각 데이터셋별로 전용 지도 학습된 최신 SOTA 모델들(PatchTST 등)과 유사하거나 이를 능가하는 뛰어난 제로샷 예측 성능을 입증함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **시점 불일치 및 가변 예측 Horizon 대응 부족**:
  - Stage 1의 기존 모형은 예측 구간(예: 30분, 60분)마다 별도의 단일 타겟 회귀 모델을 학습해야 하는 구조적 경직성을 가짐.
  - 이로 인해 다중 구간 혈당 흐름의 일관성 있는 궤적을 묘사하지 못하고 개별 시점 예측값들이 서로 모순되는 현상이 발생함.

### 2.2 TimesFM의 우리 연구 적용 방안 (Decoder-only Horizon Trajectory)
- **통합 다중 구간 디코더 도입**:
  - 입출력 비대칭 패칭 구조를 모방하여, 입력 데이터의 패치 시퀀스를 임베딩한 뒤 단일 디코더 패스를 통해 30분, 60분, 90분의 혈당 궤적을 단 한 번에 출력하도록 설계함.
  - 이를 통해 예측 구간별 다중 모델 관리 오버헤드를 제어하고 혈당 변화의 인과적 흐름을 단일 궤적으로 통일성 있게 추정함.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 3-step Lookback ($L=3$, 15분 이력) 환경 하에서의 패치 정합 붕괴 및 제로 패딩 편향
- **지적 사항**: TimesFM은 기본적으로 $p=32$ 또는 $p=16$과 같은 패치 크기를 전제로 작동합니다. 하지만 Glucose-ML의 $L=3$ (15분 이력) 환경에서는 입력 차원이 패치 최소 사양보다 현저히 작습니다. 이 경우 TimesFM의 마스킹 정책에 따라 29개의 빈 자리를 제로 패딩한 뒤 전체를 마스킹 처리하여 입력 토큰을 구성해야 합니다. 이로 인해 임베딩 벡터가 거의 전부 zero-padding으로 채워진 단일 가상 토큰으로 인입되며, stacked causal attention 레이어 내에서 시계열의 시퀀스적인 주의집중 가중치 계산이 원천적으로 불가능해져 예측 출력이 비정상적인 상수값으로 수렴(Degenerate)하는 심각한 정합 붕괴가 초래됩니다.
- **개선 요구**: 15분이라는 극소형 룩백 윈도우 환경 하에서 패칭 구조의 마스킹 붕괴를 극복할 수 있는 실질적인 전처리 또는 입력 구조 변경안을 제시하십시오.

### 4.2 Stacked Transformer 연산량으로 인한 CPU 추론 병목
- **지적 사항**: TimesFM은 200M 수준의 파라미터와 수십 개의 Transformer 레이어를 적층한 무거운 구조를 갖습니다. 서버 GPU 환경과 달리 사용자 모바일 단말(Edge CPU) 환경에서 5분마다 실시간 추론을 수행할 때, 여러 개의 어텐션 헤드와 FFN 레이어를 직렬 연산하게 되면 배터리 소모와 기기 발열 및 100ms를 초과하는 Latency 오버헤드가 발생하여 실시간 혈당 모니터링 서비스 구현이 불가능합니다.
- **개선 요구**: 실시간 단말 CPU 구동을 위해 모델 크기 및 연산 오버헤드를 극적으로 감축할 수 있는 경량화/압축 아키텍처 우회안을 수립하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 클라이언트측 슬라이딩 링 버퍼 및 버추얼 패치 투영 (Client-Side Ring Buffer & Virtual Patch Projection)
- **수정 설계**: 15분 룩백 제한 하에서 패치 차원이 붕괴되는 문제를 우회하기 위해, **단말측 슬라이딩 링 버퍼**를 두어 물리적인 입력 길이를 확보하고, 동시에 단기 전용 **버추얼 패치 레이어**를 구성합니다.
- **구체적 구현**:
  - 단말 앱 내부의 SQLite 또는 메모리에 최근 12시간 동안 수집된 혈당/인슐린/식사 이력(144 스텝)을 누적 보관하는 링 버퍼(Sliding Ring Buffer)를 운영합니다. 모델 추론 시에는 이 144 스텝의 컨텍스트를 통째로 입력하여 TimesFM이 $p=32$의 정상적인 멀티 패스 토큰을 활용할 수 있도록 보장합니다.
  - 누적 데이터가 부족한 초기 기동 시점(Cold Start)에는 $L=3$의 원시 입력을 32차원으로 맵핑하는 가상의 입력 프로젝터(Virtual Linear Projection Layer)를 적용하여 제로 패딩 없이 단일 차원으로 인코딩된 패치 토큰으로 변환함으로써 어텐션 매트릭스의 수치적 붕괴를 사전에 방지합니다.

### 5.2 어텐션 레이어 프루닝 및 MLP 지식 증류 (Attention Layer Pruning & MLP Distillation)
- **수정 설계**: CPU 연산 오버헤드를 제어하기 위해, **레이어 프루닝**을 통해 네트워크 크기를 줄이고, 사전 학습된 지식을 **초경량 MLP로 증류(Distillation)**하여 배포합니다.
- **구체적 구현**:
  - 사전 학습된 TimesFM 모델의 하위 3개 인코더 레이어만 남기고 상위 레이어들을 전면 제거(Pruning)한 후, 당뇨병 관련 파인튜닝 데이터셋으로 재조정하여 단말 구동용 10M 미만의 서브 모델로 경량화합니다.
  - 더 나아가, 학습 서버 상에서 원본 TimesFM 모델이 출력하는 예측 궤적의 로짓(Logits) 정보를 지도 신호로 삼아, 단말에 탑재할 3층 구조의 초경량 TSMixer(MLP-based, <500K parameters) 모델을 지식 증류 방식으로 학습시킵니다. 이를 통해 단말 CPU에서는 가볍고 빠른 MLP 연산만 수행하도록 함으로써 1ms 미만의 극초고속 추론 환경을 달성합니다.
