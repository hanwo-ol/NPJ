## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 기존 딥러닝 기반 시계열 예측 연구들은 대다수 특정 데이터셋에 고정된 context window와 prediction horizon을 결합해 학습하므로, 범용적인 제로샷(Zero-shot) 전이 능력을 갖추지 못했음.
- 시계열 도메인 전반에 걸쳐 신뢰성 있는 확률적 분포(Probabilistic uncertainty)를 예측하고, 신규 도메인 데이터가 극소수(Few-shot)만 제공되는 상황에서도 미세 조정(Fine-tuning)을 통해 빠르게 성능을 수렴시키는 시계열 기초 모델이 필요함.

### 1.2 제안하는 방법론: Lag-Llama
- **지연 특성 기반 토큰화 (Lag-based Tokenization)**:
  - 수치 데이터를 직접 임베딩하는 대신, 주파수별(시간, 일, 주, 월, 분기)로 중요도가 정의된 고정된 지연 인덱스(Lag indices: $L = \{1, 2, 3, \dots, 288, \dots\}$)에 맞춰 과거 시점들의 값들로 지연 벡터(Lag vector)를 구성함.
  - 여기에 타임스탬프 정보(날짜/시간 공변량)와 데이터의 통계값(Summary statistics)을 결합하여 개별 토큰을 구성함.
  - 이 방식은 특정 주파수에 종속되지 않고, 이종 시계열 데이터를 동일한 토큰 스페이스로 취합할 수 있는 유연성을 제공함.
- **Decoder-only LLaMA 아키텍처**:
  - LLaMA 백본(RMSNorm, RoPE, SwiGLU 구성)을 기본 디코더로 채택하여 입력 토큰 시퀀스로부터 미래 분포를 예측함.
- **로버스트 표준화 (Robust Standardization)**:
  - 데이터의 이상치(Outliers) 영향을 차단하기 위해, 컨텍스트 평균 대신 중간값(Median)을 빼고 사분위간 범위(IQR)로 나누어 입력을 스케일링함: $x'_t = \frac{x_t - \text{Median}}{\text{IQR}}$.
- **Student's t-분포 예측 헤드**:
  - 출력 레이어에서 Student's t-분포의 3대 파라미터(자유도, 평균, 스케일)를 계산하여 확률밀도함수를 도출하고, 음의 로그 우도(NLL) 손실 함수로 학습함.
- **인플루엔스 기반 확률적 궤적 생성**:
  - 추론 단계에서는 예측된 t-분포로부터 미래 수치 토큰을 샘플링하여 입력단으로 오토레그레시브하게 피드백하는 방식으로 다중 예측 궤적들을 확률적으로 생성함.

### 1.3 실험 결과
- Pretraining에 사용되지 않은 다양한 도메인의 시계열 데이터셋에서 제로샷으로 우수한 분포 예측 정확도(CRPS)를 보였으며, 단 20%의 데이터만으로 미세 조정을 수행하는 Few-shot 설정에서 전용 지도 학습 모델들을 능가하는 속도로 최적화 성능에 도달함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **개인별 당뇨 유형 편차 및 이상치 대응력 부족**:
  - 환자 개개인의 생활 습관이나 인슐린 감수성에 따라 극단적인 고혈당 스파이크나 저혈당 쇼크 등의 이상치(Outliers)가 빈번히 발생함.
  - Stage 1의 L2 손실(MSE) 기반 평균값 회귀 예측은 이러한 극단적 스파이크 이상치에 취약하며, 예측 범위가 한쪽으로 쏠리거나 왜곡되는 한계를 가짐.

### 2.2 Lag-Llama의 우리 연구 적용 방안 (Robust Scaled Student's t-Distribution)
- **로버스트 스케일러 및 자유도 제어**:
  - Lag-Llama의 Robust Standardization(Median-IQR 스케일러)을 혈당 전처리 패스로 도입하여 식사 직후의 급격한 이상치 데이터 왜곡을 차단함.
  - Student's t-분포 헤드를 통해 혈당의 변동 대역을 확률적으로 추정하고, 자유도(Degrees of Freedom) 파라미터를 실시간 분석하여 현재 환자의 급격한 변동 위험성(꼬리가 두꺼운 분포 형태)을 경고하는 인프라를 구축함.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 3-step Lookback ($L=3$, 15분 이력) 환경 하에서의 지연 벡터(Lag Vector) 구성 원천 불능
- **지적 사항**: Lag-Llama의 핵심 토큰화 전제는 일간/주간 주기를 캡처하기 위한 대규모 지연 인덱스 $L$ (예: 과거 24스텝, 288스텝 전의 값들)의 확보입니다. 하지만 Glucose-ML의 실시간 추론 시점에는 $L=3$ (15분 이력) 제한이 걸려있으므로, 3스텝 이전의 지연 인덱스(예: 12스텝, 24스텝, 288스텝 전의 과거 혈당) 값들은 실시간 인입 데이터에 아예 존재하지 않습니다. 이 결측된 지연 특성들을 강제로 제로(0)로 채우거나 직전 혈당값으로 단순 복사해 채워 넣으면, pretraining 시점의 데이터 분포와 극심한 괴리가 생겨 Student's t-분포 파라미터가 비정상적인 값(음수의 스케일 혹은 자유도 수렴 실패)을 출력해 예측 자체가 완전히 오작동하는 정합성 붕괴가 일어납니다.
- **개선 요구**: 15분 국소 입력만 가용한 단말 조건에서 누락된 대규모 지연 인덱스 벡터를 보정 또는 우회할 수 있는 설계를 수립하십시오.

### 4.2 오토레그레시브 궤적 샘플링의 Edge CPU Latency 병목
- **지적 사항**: Lag-Llama는 미래 60분(12스텝)의 확률적 예측 범위를 생성하기 위해 디코더 forward 연산을 12회 수행해야 하며, 100개의 궤적 샘플을 구하려면 총 1,200회의 LLaMA 디코더 포워드 패스를 Edge CPU 상에서 순차 실행해야 합니다. LLaMA 구조 특유의 RMSNorm, Rotary Embeddings 및 캐시 관리 오버헤드는 모바일 단말 CPU에 수백 ms 이상의 부하를 주어 실시간성 가이드라인을 준수하기 어렵습니다.
- **개선 요구**: 모바일 단말에서 구동 가능한 디코딩 루프 간축안 또는 경량화 모델 배포 전략을 확보하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 단말 캐시 링 버퍼 및 결측 지연 선형 근사 (Edge Cache Ring Buffer & Nearest Lag Interpolation)
- **수정 설계**: 실시간 15분 데이터 수집 상황에서 대규모 지연 벡터 구성이 불가한 문제를 우회하기 위해, **단말 로컬 데이터베이스 링 버퍼**를 두어 물리 지연 벡터를 완성하고, 부득이한 데이터 결측 상황 시 **가장 가까운 지연값 선형 근사 프로젝션**을 도입합니다.
- **구체적 구현**:
  - 단말 백그라운드 서비스 내에 Sliding Ring Buffer를 구축하여 최근 24시간 동안 수집된 288개의 CGM 수치 및 인슐린 투여 기록을 유지합니다. 이를 통해 모델 추론 시 요구되는 모든 대규모 지연 인덱스(1, 2, 3, 12, 24, 288 등) 값을 로컬 캐시에서 즉각 추출해 완벽한 Lag Feature 토큰을 구성해 냅니다.
  - 센서 이탈 등으로 인해 과거 24시간 내에 중간 결측이 발생한 경우, 인접한 잔여 수치의 시간 차이를 고려한 선형 보간(Linear Interpolation) 및 지수 이동 평균 보정을 통해 가상의 지연 벡터를 복원 주입하여 토큰 스페이스 왜곡을 억제합니다.

### 5.2 단일 패스 Quantile Head 전환 및 초경량 MLP-Mixer 지식 증류 (Single-Pass Quantile Head & Student MLP Distillation)
- **수정 설계**: Edge CPU 연산 폭발을 제어하기 위해, **단일 패스 Quantile Regression Head**로 출력 레이어를 수정하고, 이를 **초경량 MLP-Mixer 학생 모델로 증류**합니다.
- **구체적 구현**:
  - 디코더 기반의 반복 샘플링 대신, 인코더 최종 Layer에 예측 Horizon 12스텝 전체에 대한 대표 Quantile(10%, 50%, 90% 백분위수)을 즉각 출력하는 병렬 Linear Heads ($12 \times 3$ 차원 출력)를 직접 결합하여 오토레그레시브 디코딩 루프를 전면 생략하고 단 1회의 포워드 연산으로 예측 범위를 묘사합니다.
  - 더 경량화된 탑재를 위해, 서버 상에서 Lag-Llama가 생성하는 Student's t-분포 매개변수와 Quantile 값들을 Target Label로 설정하고, 300KB 미만의 초경량 Student MLP-Mixer를 학습시켜 모바일 단말 CPU 상에서 0.5ms 미만의 단일 텐서 연산으로 예측을 완료하도록 배포 구조를 고도화합니다.
