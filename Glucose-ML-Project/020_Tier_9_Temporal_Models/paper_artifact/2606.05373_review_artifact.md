# Literature Survey Review: Evidence-Guided Neural Architecture Selection under Uncertainty for Subject-Specific Blood Glucose Forecasting

- **논문 제목**: Evidence-Guided Neural Architecture Selection under Uncertainty for Subject-Specific Blood Glucose Forecasting
- **저자**: Islam, M. A., et al. (University at Buffalo, arXiv 2026)
- **분석 시점**: 2026-06-10
- **고유 식별자**: arXiv:2606.05373
- **리뷰어**: 인격 2 (연구원 에이전트)

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 소량의 노이즈가 많고 이질적인 데이터 환경에서 고전적인 경험적 모델 설계나 검증 방법은 신뢰할 수 있는 예측 및 일반화 성능을 보장하지 못함.
- 특히 환자 간 편차가 크고 생리학적 지연이 존재하는 제1형 당뇨병(T1D) 환자의 혈당 예측 환경에서, 과거 데이터에 과적합되지 않으면서도 미지의 환자에게 안전하게 일반화될 수 있는 최적 크기의 신경망 구조를 선택하는 데 어려움이 있음.

### 1.2 제안 방법론: EVIDENT (EVidence-based IDEntification of Neural architectures)
- **개념**: 베이지안 신경망 학습, 베이지안 증거(Model Evidence) 기반 랭킹, 그리고 작업 특화 불확실성 검증을 통합한 체계적인 수준별(Level-wise) 신경망 구조 선택 프레임워크.
- **동작 방식**: 
  - 후보 모델 구조들을 파라미터 수(용량)에 따라 오름차순으로 정렬된 여러 단계의 용량 레벨로 분류.
  - 베이지안 변분 추론(Variational Inference)을 적용해 모델 가중치의 사후 분포를 학습하고 Laplace 근사를 활용해 모델 증거(Bayesian Evidence)를 산출하여 상위 모델 선정.
  - 타겟 미지 환자 검증 단계에서 음의 로그 예측 밀도(NLPD)를 기준으로 예측 손실과 베이지안 불확실성을 통합 검증하여 사전에 설정된 신뢰 수준(NLPD 임계값)을 통과하는 가장 단순한(가장 작은 용량의) 모델 구조를 최종 선택.
- **실험 결과**: UVA/Padova T1D 시뮬레이터 데이터를 활용한 10명 환자 대상 5-fold 교차 검증에서, EVIDENT는 과소 및 과적합 TCN 구조를 효과적으로 배제하며 소형이면서 미지 환자에게 안정적으로 일반화되는 TCN 모델을 도출함.

## 2. Glucose-ML 프로젝트(Stage 2) 적용 방안

### 2.1 매핑점
- **LODO 전이학습 신뢰도 검증**: 미지 기관/환자 데이터셋에 대해 일반화 성능을 예측할 때, 포인트 지표(RMSE)뿐만 아니라 모델의 베이지안 사후 불확실성을 함께 반영하는 검증 메트릭(예: NLPD의 단순화된 대용치)을 차용하여 LODO 검증의 보수성과 안정성을 극대화할 수 있음.
- **경량화 구조 최적화**: 모델의 표현 용량을 점진적으로 확장해가며 제약을 충족하는 최소 용량의 모델을 채택하는 전략은 우리의 CPU 제한 환경에 완벽히 부합함.

### 2.2 구현적 시사점
- 다변량 1D Causal CNN 기반 인코더-디코더 TCN 구조를 차용하되, 채널 크기 및 블록 깊이를 최소화하여 훈련 속도를 확보함.

## 3. 한계점
- **베이지안 추론의 연산 부하**: 변분 추론(Variational Inference)이나 Laplace 근사를 통한 가중치 분포 학습은 CPU 전용 LODO 루프에서 계산 복잡도를 폭발시켜 실시간 학습 및 다기관 교차 검증을 불가능하게 함.
- **초단기 룩백에서의 Receptive Field 설계 붕괴**: 논문은 수백 분에서 하루 단위의 입력 윈도우를 활용해 TCN의 Dilation(팽창 합성곱) 메커니즘을 적용했으나, 본 프로젝트의 `LOOKBACK_STEPS=3`(15분) 제한 조건 하에서는 Dilation Factor(>1)를 적용할 수 없으며 커널 크기가 입력 길이보다 커져 연산 오류가 발생함.

---

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 CPU 자원 한계와 3스텝 룩백에서의 TCN 설계 모순
- **지적 사항**: 본 논문은 예측 오차와 모델 불확실성을 동시에 정렬하기 위해 베이지안 신경망(BNN)을 사용합니다. 그러나 BNN의 변분 추론 가중치 샘플링 및 Laplace 근사는 순방향/역방향 전파 시 CPU 연산 오버헤드를 배가시키며 메모리 제한이 큰 환경에서 감당하기 어렵습니다.
- **룩백 충격**: TCN의 핵심 이점은 Dilation을 통한 Receptive Field 확장인데, `LOOKBACK_STEPS=3`에서는 Dilation Base $b$와 Block Number $N$을 통한 팽창이 성립하지 않습니다. 입력 길이가 3인 상황에서 Dilation Rate를 2 이상으로 잡을 경우 피처 맵 크기가 음수가 되거나 데이터가 누수되어 모델이 비정상적으로 동작합니다.
- **개선 요구**: 가중치 사후 분포를 모델링하기 위한 BNN 연산을 전면 배제하고, 결정론적 TCN에 몬테카를로 드롭아웃(MC Dropout)을 적용하여 간접적으로 예측 분산을 계산하는 경량 불확실성 추정 방식으로 우회하십시오. 또한 `LOOKBACK_STEPS=3` 시 Dilation Rate를 1로 강제 제한하고 커널 크기를 2 이하로 제어하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 Glucose-EVIDENT TCN Causal Bypass 및 경량 MC Dropout 설계
- **결정론적 TCN + MC Dropout 변환**:
  - 복잡한 BNN variational layers 대신 표준 PyTorch `nn.Conv1d`와 `nn.Dropout(p=0.1)` 레이어를 매칭합니다.
  - 학습 시에는 일반 SGD/Adam으로 학습을 수행하여 CPU 연산 시간을 단축합니다.
  - 추론 시에는 `model.eval()` 상태에서도 dropout을 활성화하여 10회 미만의 몬테카를로 포워드 패스를 수행함으로써 예측 분산 $\sigma^2_{pred}$을 실시간으로 추정하고, 이를 통해 간이 NLPD 검증 수치($d(D_{val}, T_{\xi})$)를 획득합니다.
- **초단기 룩백 우회 로직**:
  - `LOOKBACK_STEPS=3`인 경우: Dilation Base $b = 1$, Block Number $N = 1$, Kernel Size $f = 2$로 고정하여 단순 Causal 1D CNN으로 축소 동작시킵니다.
  - `LOOKBACK_STEPS >= 12`인 시계열 확장 조건이 활성화될 때만, 동적으로 Dilation Base $b \in [2, 3]$ 및 다층 블록을 활성화하여 장기 Receptive Field를 복원하는 시퀀스 가변형 코드를 적용합니다.
- **경량 채널 스케줄**:
  - 인코더 및 디코더 은닉 채널 수 $c_1$을 8 또는 16으로 극단적으로 축소하여 파라미터 수를 1만 개 이하로 유지함으로써 CPU 전이학습(LODO) 최적화를 달성합니다.
