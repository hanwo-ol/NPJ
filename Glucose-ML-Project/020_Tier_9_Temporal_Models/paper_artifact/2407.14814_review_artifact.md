# Literature Survey Review: FMamba: Mamba based on Fast-attention for Multivariate Time-series Forecasting

- **논문 제목**: FMamba: Mamba based on Fast-attention for Multivariate Time-series Forecasting
- **저자**: Shusen Ma, Yu Kang, Peng Bai, & Yun-Bo Zhao (University of Science and Technology of China / arXiv:2407.14814)
- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

---

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 다변량 시계열 예측(Multivariate Time-series Forecasting, MTSF)에서는 시간적 흐름뿐 아니라 변수(채널) 간의 상관관계(Inter-variable Correlation)를 파악하는 것이 중요함.
- 기존의 Transformer 계열 채널 믹싱 모델들은 높은 오차 정합성을 보이지만, 자가 어텐션(Self-Attention)의 복잡도가 채널 수와 시퀀스 길이의 제곱($O(L^2)$ 또는 $O(C^2)$)으로 증가하여 비효율적임.
- Mamba 아키텍처는 선형 복잡도로 시간 의존성을 잘 추출하지만, 본질적으로 단방향 순차 스캔 구조이므로 변수 간의 전역적 다차원 상관관계(Global Cross-variable Correlation)를 직접 계산하지 못하는 한계가 있음.

### 1.2 제안하는 방법론: FMamba
- **채널 독립성(Channel Independence, CI) 기반 토큰화**:
  - 각 시계열 변수(채널)를 독립적인 토큰 시퀀스로 취급하여 임베딩 레이어(MLP + Positional Embedding)를 통해 고차원 벡터로 변환함.
- **빠른 어텐션 메커니즘 (Fast-Attention Module)**:
  - 기존의 $O(C^2)$ 복잡도를 갖는 Dot-product self-attention 대신, 가우시안 커널 함수 $F(x) = \exp(-x^2 / 2)$를 활용하여 비선형 커널 매핑을 수행함.
  - 분산 곱셈 순서를 제어하는 Fast-attention 수식($\text{Attention}(Q', K', V') = Q'(K'^\top V') / \text{kernel\_dim}$)을 통해, 연산 복잡도를 채널 수 $C$에 대해 선형 $O(C)$ 복잡도로 낮추면서 전역 변수 간 상관관계를 성공적으로 캡처함.
- **Mamba 및 MLP 블록 결합**:
  - Fast-attention 뒤에 Mamba 블록을 연결하여, 이전 단계에서 취합된 채널 간 상관 특징을 바탕으로 각 채널 내의 선택적 시간 동역학(Selective Temporal Dependencies)을 추출함.
  - 이후 최종 선형 프로젝터(Projector)를 거쳐 미래 예측 Horizon을 출력함.

### 1.3 실험 결과
- PEMS, Electricity, SML2010, Weather, Solar-Energy 등 8개 공인 시계열 데이터셋에서 S-Mamba 및 iTransformer 등 SOTA 모델 대비 성능 우위를 입증함.
- 특히 self-attention을 fast-attention으로 대체하여 예측 정확도를 손상하지 않으면서도, 연산 속도와 메모리 효율성을 비약적으로 높임.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **혈당-인슐린-식사 간의 전역 비선형 상관관계 무시**:
  - 기존 Stage 1의 LightGBM 기반 다변량 혈당 예측은 트리 분기 방식에만 의존하여 식사량, 인슐린 투여량, 혈당 수치 간의 상호작용(Inter-variable Dynamics)을 단순 선형 결합 피처로만 반영했음.
  - 이로 인해 급격한 식사 섭취에 따른 급격한 혈당 상승 곡선과 인슐린에 의한 하강 곡선이 중첩될 때, 변수 간 비선형 시너지 효과를 모델이 구조적으로 학습하지 못해 혈당 피크 시점에서 예측 지연이 유도됨.

### 2.2 FMamba의 우리 연구 적용 방안 (Linear Variable Attention)
- **초경량 다변량 혈당 전이 블록 구축**:
  - 다변량 입력 채널(CGM, 인슐린, 식사 등) 간의 상관관계를 FMamba의 Fast-attention을 통해 계산함.
  - 변수 수 $C$가 늘어나더라도 선형 복잡도를 유지하면서 비선형 가우시안 커널을 통해 인슐린 작용 강도와 탄수화물 흡수 속도의 상호 비선형 의존성을 학습하고, 이를 Mamba 레이어로 전달하여 시간적 궤적을 예측함.

## 3. 검증 및 실험 로드맵 제안

### 3.1 Baseline 비교군 설정
1. **S-Mamba**: Fast-attention 없이 Mamba 블록만으로 구성된 모델.
2. **iTransformer**: 기존의 무거운 quadratic self-attention을 적용한 채널 어텐션 모델.
3. **FMamba (Proposed)**: Fast-attention과 Mamba가 순차 결합된 선형 복잡도 하이브리드 모델.

### 3.2 핵심 평가 메트릭
- **연산 오버헤드**: CPU Forward Latency (ms) 및 Memory footprint.
- **예측 평가지표**: RMSE, MAE, MARD.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

본 섹션은 감시자 에이전트(인격 3)가 연구원 에이전트(인격 2)의 1차 설계 아티팩트를 검수하고 남긴 비판적 검토 의견입니다.

### 4.1 3-step Lookback ($L=3$) 환경 하에서의 가우시안 커널 ($F$) 연산 붕괴
- **지적 사항**: FMamba는 각 채널 토큰의 차원인 lookback window $L$ 상에서 가우시안 커널 $F(x) = \exp(-x^2 / 2)$을 계산하여 변수 간 어텐션을 수행합니다. 그러나 $L=3$ (15분 이력) 조건 하에서는 임베딩을 통과하더라도 토큰 표현 공간의 차원과 분산이 극히 제한적입니다. 이 조건에서 인슐린 주입이나 식사 섭취와 같은 스파이크성 동적 공변량의 절댓값이 커지면, 가우시안 지수 연산 특성 상 커널 출력 값이 0으로 급격히 수렴(Saturation)하여 변수 간 어텐션 연결이 전면 붕괴(Zero-Weight Collapse)되고 핵심 신호가 디코더단에 전혀 전달되지 못하는 불안정성이 발생합니다.
- **개선 요구**: 3스텝 룩백 조건에서도 가우시안 커널의 수치적 포화 현상을 예방하고 외생 변수의 중요 스파이크 신호를 보존할 수 있는 보완 장치를 수립하십시오.

### 4.2 복합 레이어 적층으로 인한 CPU 추론 Latency 오버헤드
- **지적 사항**: FMamba 블록은 임베딩, Fast-attention, Mamba, MLP-block을 순차적으로 거치며 다수의 레이어를 가집니다. GPU 환경에서는 병렬 가속이 가능하나, CPU 환경에서는 각 연산 레이어가 직렬로 연산되어 실시간 15분 예측 시 지연 시간이 누적됩니다. 특히 Mamba의 스캔 연산과 MLP-block의 추가 변환이 CPU 자원을 지속 점유하여 성능 부하를 가중시킵니다.
- **개선 요구**: CPU 가용 리소스 제약 하에서 FMamba의 적층 오버헤드를 감소시키기 위한 경량화 아키텍처 수정안을 제시하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

본 섹션은 수정자 에이전트(인격 4)가 감시자의 지적 사항을 분석하여 수립한 최종 보완 설계안입니다.

### 5.1 스케일 바운디드 가우시안 커널 및 외생 변수 게이트 바이패스 (Scale-Guarded Kernel & Exogenous Bypass Gate)
- **수정 설계**: 지수 커널 포화 문제를 극복하기 위해, **커널 스케일 정규화 가드**를 탑재하고 스파이크성 변수의 경우 **직접 잔차 바이패스 경로**를 추가합니다.
- **구체적 구현**:
  - 가우시안 커널 입력 벡터에 대해 Layer Normalization을 사전에 적용하고, 가우시안 분모에 동적 가드 스케일 $\sigma_{guard} = \max(\text{std}(x), 0.1)$를 주입하여 $F(x) = \exp(-x^2 / (2\sigma_{guard}^2))$로 계산함으로써 지수 포화를 방지합니다.
  - 인슐린/식사 로그와 같은 임펄스 변수들은 Fast-attention 연산을 거치지 않고 직접 Linear Layer를 통해 Mamba 블록의 SiLU 게이트단으로 직접 Concatenate하여 바이패스시키는 Exogenous Gate 구조를 결합해 정보 유실을 원천 예방합니다.

### 5.2 순차 차원 경량화 및 MLP 블록 압축 (Layer Pruning & Dimension Squeezing)
- **수정 설계**: CPU 자원 소모를 통제하기 위해, FMamba 블록의 직렬 깊이를 축소하고 내부 feature dimension을 압축합니다.
- **구체적 구현**:
  - Mamba 블록 직후 배치된 복잡한 2-layer MLP-block을 단일 Dense 레이어(Linear Projection)로 통폐합하여 MLP 연산량을 50% 절감합니다.
  - 내부 모델 차원 $D_{model}$을 기존 512차원에서 64차원 또는 128차원으로 스퀴징하여 CPU 상에서 Fast-attention 및 Mamba의 행렬 연산 속도를 비약적으로 향상시킵니다.
