# Literature Survey Review: TSKANMixer: Kolmogorov-Arnold Networks with MLP-Mixer Model for Time Series Forecasting

- **논문 제목**: TSKANMixer: Kolmogorov–Arnold Networks with MLP-Mixer Model for Time Series Forecasting
- **저자**: Young-Chae Hong, Bei Xiao, & Yangho Chen (Amazon / arXiv:2502.18410)
- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

---

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 선형 및 MLP 기반 시계열 모델(예: TSMixer)은 빠르고 간결하지만, 가중치가 고정된 선형 매핑에 의존하여 시간에 따라 급변하고 복잡한 비선형 당대사 패턴이나 외생 변수 간의 동적 관계를 표현하는 데 한계가 있음.
- 반면 트랜스포머 기반 모델은 과적합에 취약하고 연산 비용이 크며, 기존 MLP 모델은 빠른 학습 속도 뒤에 급격한 과적합(Validation Loss 상승)을 겪는 경향이 있음.

### 1.2 제안하는 방법론: TSKANMixer
- **Kolmogorov-Arnold Network (KAN) 레이어 융합**:
  - 노드에 고정 활성화 함수를 두고 에지에 선형 가중치를 두는 MLP와 달리, KAN은 에지에 학습 가능한 활성화 함수(B-spline 곡선)를 두고 노드에서는 단순 합산만 수행하는 새로운 신경망 구조임.
  - TSMixer 아키텍처 내에 KAN 레이어를 결합하여 비선형 표현력을 극대화함.
- **TSKANMixer 두 가지 변종 아키텍처**:
  - **v01**: TSMixer의 최종 Temporal Projection(시간 축 선형 투영) 레이어를 KAN 레이어로 대체하여 $L$에서 $H$로의 비선형 예측 매핑을 학습함.
  - **v02**: Mixer 레이어 직후와 Temporal Projection 사이에 KAN 기반의 Time-Mixing 레이어를 삽입하여 비선형 템포럴 특징을 정제함.
- **부드러운 수렴과 과적합 억제**: KAN의 파라미터는 완만하게 학습되는 특성이 있어, 학습 초기에 오버슈팅 되지 않고 점진적으로 검증 오차를 낮춰 일반화 성능을 향상시킴.

### 1.3 실험 결과
- ETT, FRED-MD, Exchange, Hospital 등 10개 벤치마크 데이터셋에서 TSMixer 대비 최대 18% 이상의 MSE/MAE 오차 절감 및 SOTA 성능을 기록함.
- 파라미터 수가 작음에도 비선형 표현력이 우수하여 성능 효율을 입증함. 단, 학습 시간은 B-spline 그리드 연산으로 인해 TSMixer 대비 10배에서 최대 50배까지 지연되는 한계가 있음.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **개인별 비선형 당대사 곡선 모델링 실패 및 정적 가중치 한계**:
  - 당뇨병 환자의 인슐린-식사-혈당 역학은 개별 환자의 신체 상태, 인슐린 감수성, 소화 속도에 따라 극도로 비선형적이고 상이함.
  - Stage 1의 LightGBM 및 일반 선형 딥러닝 레이어는 정적인 1차 가중치 결합에 의존하므로, 인슐린 농도에 따른 급격한 혈당 강하율의 비선형 포화 곡선(S-곡선 등)을 개별 학습하여 예측 성능을 끌어올리기 불가능했음.

### 2.2 TSKANMixer의 우리 연구 적용 방안 (Kolmogorov-Arnold Non-linear Glucose Projection)
- **혈당 변동성 특화 KAN 비선형 프로젝션 탑재**:
  - TSMixer 백본을 탑재한 후 최종 출력단에 `TSKAN-Projection` 레이어를 도입하여 $L \to H$ 예측을 2층 KAN 구조로 매핑함.
  - 고정 활성화 함수 대신 학습 가능한 B-spline 에지를 통과시킴으로써, 인슐린 주입량에 따른 혈당 하강 속도의 생리학적 비선형 한계점과 식사량 대비 소화 흡수 곡선의 비선형 임계치를 KAN 레이어 내 에지 활성화 맵으로 유연하게 근사하여 정교한 개인화 예측을 실현함.

## 3. 한계점

### 3.1 3-step Lookback (L=3, 15분 이력) 환경 하에서의 B-spline 그리드 붕괴 및 발산
- $L=3$의 입력 조건에서 KAN 레이어 $[3, 7, H]$를 구동하면 B-spline의 그리드 분할 간격($G$) 설정 시 데이터 분포의 다변성이 극도로 결여되어 그리드 경계가 왜곡되거나 수치 발산(division-by-zero)이 발생하기 쉬움. 입력값들이 정상 상태로 밀집되어 입력 분산이 0에 수렴할 경우, 스플라인 미분 연산 시 그래디언트 폭발이 일어나 학습이 붕괴될 위험이 큼.

### 3.2 Edge CPU 상에서의 스플라인 곡선 재귀 연산(Cox-de Boor) 미지원
- 모바일 단말 CPU는 B-spline 곡선을 평가하기 위한 재귀 분할 공식(Cox-de Boor recursion)이나 동적 제어점(Control Points) 탐색 연산을 하드웨어 수준에서 가속하지 못함. TensorFlow Lite 컴파일러 또한 KAN 커스텀 연산자를 기본 지원하지 않아 컴파일이 실패하며, 강제로 구현 시 모바일 CPU 레이턴시가 수십 배 폭증해 5분 실시간 구동이 저해됨.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 극소 입력(L=3)에서의 Spline 그리드 수치적 불안정성 및 그래디언트 폭발
- **지적 사항**: 3스텝 혈당 수치만으로 KAN B-spline을 학습시키면, 입력 특징 공간이 협소하여 제어점 가중치가 특정 노이즈 포인트에 과도하게 고착됩니다. 환자의 혈당 수치가 평탄한 basal 상태에서는 스플라인 그리드 업데이트 분모가 0에 가깝게 소멸하여 수치적 발산이 즉각 초래됩니다.
- **개선 요구**: L=3 컨텍스트에서도 수치적 붕괴나 수렴 실패 없이 안전하고 견고하게 비선형 매핑을 수행할 수 있는 KAN 변형 설계를 고안하십시오.

### 4.2 모바일 CPU 가속 엔진 컴파일 호환성 결여 및 연산 레이턴시
- **지적 사항**: 모바일 단말기에서 B-spline 가중치와 제어점 파라미터를 동적 갱신하는 것은 모바일 메모리 풋프린트 오버헤드가 막대하며, TFLite 컴파일러 호환 규격을 심각하게 벗어납니다.
- **개선 요구**: Custom Operator 연동을 배제하고 표준 MatMul과 ReLU/GELU 등 모바일 컴파일 친화적 연산자만으로 KAN의 비선형성을 근사할 수 있는 가속화 설계안을 수립하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 장기 링 버퍼 기반 KAN 인코딩 및 실시간 L=3 MLP 잔차 결합 (12h KAN Buffer & Linear Skip)
- **수정 설계**: 극소 룩백 수치 붕괴를 피하기 위해 **12시간 링 버퍼(144 스텝)**에서 혈당 이력을 뽑아 KAN의 입력으로 제공하여 스플라인 그리드 안정성을 확보하고, 실시간 L=3 정보는 병렬 linear 경로로 우회 결합합니다.
- **구체적 구현**:
  - 단말기 내부에서 12시간 링 버퍼(144포인트)를 생성하여 입력 범위를 넓히고, KAN 레이어 $[144, 289, H]$를 가동해 장기 비선형 트렌드를 수치 발산 없이 부드럽게 예측합니다.
  - 최신 3스텝 혈당 데이터는 KAN을 거치지 않고, 병렬의 단층 Dense Layer를 통해 직접 타겟 H 차원으로 선형 투영(Skip Connection)한 후 KAN 출력에 합산 결합하여 실시간 급격 변동에 대한 수치적 즉각 대응성을 회복합니다.

### 5.2 Piecewise Linear KAN 근사 및 RBF 기반 가속화 (Piecewise Linear KAN & Radial Basis Function Approximation)
- **수정 설계**: B-spline의 재귀 연산 부하를 차단하기 위해 KAN을 **Piecewise Linear KAN(1차 스플라인 KAN)** 또는 **RBF-KAN(방사형 기저 함수 KAN)**으로 전환하여 표준 텐서 연산화합니다.
- **구체적 구현**:
  - KAN의 B-spline 곡선을 다중 구간 ReLU 활성화 함수와 Bias의 선형 결합(Piecewise Linear KAN)으로 근사합니다:
    $$\phi(x) = w_{base} \cdot \text{GELU}(x) + \sum_{g=1}^G w_g \cdot \text{ReLU}(x - t_g)$$
    여기서 $t_g$는 고정된 그리드 노드들입니다. 이 변환을 통해 B-spline 제어점 재귀 연산이 단순 ReLU와 선형 행렬곱으로 전치되어 TFLite 표준 가속 컴파일이 100% 호환되며 Edge CPU 상의 추론 연산량이 95% 이상 절감됩니다.
  - 훈련 완료된 KAN 레이어의 미세 조정을 피하고, 모바일 개인화 파인튜닝 시에는 KAN 레이어를 Frozen(동결)하고 최종 linear 출력 레이어만 단말로 갱신하게 하여 학습 병목을 근원 차단합니다.
