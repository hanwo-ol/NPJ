## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 일반적인 시계열 예측 모델의 손실 함수(MSE, MAE 등)가 예측 오차를 균일하게 처리하기 때문에, 환자에게 임상적으로 매우 위험한 저혈당(Hypoglycemia) 및 고혈당(Hyperglycemia) 구간에서의 예측 정확도를 보장하지 못하는 문제를 해결하고자 함.
- 거대한 파라미터 크기를 가진 최근 기초 모델들(TimesNet, BG-BERT 등)이 가진 하드웨어 연산 부하를 피하고, 초경량 구조이면서도 임상적으로 완벽한 혈당 안전판을 제공하고자 함.

### 1.2 제안 방법론: GLIMMER 프레임워크
- **경량 CNN-LSTM 아키텍처**: 1D CNN 레이어를 활용하여 다변량 입력 피처들로부터 공간 특징을 추출하고, LSTM 레이어를 통해 혈당 변동의 순차적 장기 의존성 모델링 (전체 모델 파라미터 수 약 10,000개 수준으로 제한).
- **임상 인지형 커스텀 손실 함수 (Glycemic-Aware Custom Loss)**:
  - 예측 오차를 계산할 때, 혈당 값이 임상적 위험 구간(저혈당 < 70 mg/dL, 고혈당 > 180 mg/dL)에 도달할 경우 오차에 대한 페널티 가중치를 증폭 부과.
  - 오차 가중치 하이퍼파라미터들은 유전 알고리즘(Genetic Algorithm)을 활용해 최적화.
- **성공적 결과**: OhioT1DM 및 실제 당뇨 데이터셋에서 기존 SOTA 대비 RMSE 23%, MAE 31% 개선을 달성함과 동시에, 저/고혈당 위험 탐지 recall 98.4%, F1-score 86.8%를 기록함.

## 2. Glucose-ML 프로젝트(Stage 2) 적용 방안

### 2.1 매핑점
- **위험 영역에 대한 오차 가중 페널티 도입**: Stage 1 LightGBM은 급격한 혈당 상승/하강 시점의 Peak 예측을 뭉개는 한계가 있었음. GLIMMER의 **임상 인지형 커스텀 손실 함수** 설계를 차용하여, 우리의 Stage 2 PyTorch LSTM 잔차 보정기 학습 단계에서 저혈당(< 70) 및 고혈당(> 180) 오차에 3~4배의 페널티 가중치를 반영하는 Custom Loss를 정의하면 급변 오차를 획기적으로 낮출 수 있음.
- **초경량 파라미터 설계**: 약 1만 개의 극도로 슬림한 파라미터 설계 사상을 빌려 CPU 자원 내 LODO 크로스 밸리데이션 학습 시간 병목을 원천 방지 가능.

### 2.2 구현적 시사점
- `nn.MSELoss` 대신 타겟 텐서 값에 따라 가중 팩터를 곱해주는 커스텀 Loss 클래스를 정의하여 PyTorch 학습 파이프라인에 주입.

## 3. 한계점
- **유전 알고리즘의 연산 지연**: 손실 함수의 오차 가중치 매개변수를 찾기 위해 유전 알고리즘을 CPU 상에서 반복 수행하는 것은 극도의 연산 병목을 유발함.
- **단기 룩백에서의 CNN 레이어 정보 축소**: `LOOKBACK_STEPS=3` 세팅은 입력 크기가 너무 작아 CNN을 통한 특징 융합이 단순 Linear 가중 믹싱으로 회귀함.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 실시간 유전 알고리즘 최적화 불가 및 CNN 구조 무력
- **지적 사항**: GPU가 없는 환경에서 유전 알고리즘을 LODO 반복 루프마다 돌리는 것은 물리적으로 불가능합니다. 또한 3스텝 룩백 조건에서 Conv1D를 통과시키는 것은 커널 연산 오버헤드만 낳고, 인풋 차원을 축소하여 LSTM의 시퀀스 학습 능력을 저해합니다.
- **개선 요구**: 유전 알고리즘 탐색 단계를 생략하고, 고정된 임상 가중 페널티(예: 저혈당 페널티 4.0, 고혈당 페널티 3.0, 정상 영역 1.0)를 사용하는 정적 커스텀 Loss로 설계를 우회하십시오. 3스텝 룩백 시에는 Conv1D를 생략하고 곧바로 LSTM 레이어로 순차 특징을 입력하도록 제어해야 합니다.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 정적 가중 임상 손실(Static Glycemic Loss) 및 LSTM 우회 설계
- **수정 설계**: 감시자의 연산 부하 및 3스텝 Conv 무용론 경고를 반영하여 GLIMMER 모델 및 훈련 설계를 우회 조정합니다.
- **정적 가중 손실 함수 (Static Weighted MSE Loss) 구현**:
  - 유전 알고리즘 탐색 단계를 배제하고, 임상 기준에 따라 아래 식과 같이 손실 값에 가중 가중치를 부여하는 정적 손실 함수를 구현합니다.
  - $\text{Loss} = w_i \times (y_i - \hat{y}_i)^2$
  - 여기서 $w_i$는 $y_i < 70$ 또는 $y_i > 180$일 경우 4.0으로, 정상 구간($70 \le y_i \le 180$)일 경우 1.0으로 고정 지정합니다. 이로써 CPU 연산 오버헤드 없이 임상적 안정성 목적을 달성합니다.
- **3스텝 Causal C-LSTM 간소화**:
  - `LOOKBACK_STEPS=3`인 단기 조건에서는 Conv1D 인코더를 바이패스하여 혈당 및 공변량 시퀀스를 단층 LSTM(은닉 차원 16)으로 즉시 공급합니다.
  - `LOOKBACK_STEPS`가 12 이상으로 확장될 경우에 한하여, Kernel size 2의 가벼운 Conv1D 층을 활성화하여 spatial pooling 효과를 확보합니다.
- 최종 출력단에는 드롭아웃 0.2를 반영한 nn.Linear를 배치하여 과적합을 제어합니다.
