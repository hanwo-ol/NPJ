# Literature Survey Review: FCN: Time Series Classification from Scratch with Deep Neural Networks: A Strong Baseline

- **논문 제목**: Time Series Classification from Scratch with Deep Neural Networks: A Strong Baseline
- **저자**: Zhiguang Wang et al. (GE Global Research / University of Maryland Baltimore County / arXiv:1611.06455)
- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

---

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 전통적인 시계열 분류(Time Series Classification) 기법들은 수동적인 특징 추출(Feature Crafting), 복잡한 데이터 전처리(Preprocessing), 혹은 DTW(Dynamic Time Warping) 기반의 값 대조에 의존하여 도메인 지식의 요구도가 높고 연산 지연이 큼.
- 딥러닝 기법(예: 기존 CNN)을 시계열에 적용하려는 시도가 있었으나, 대형 풀링(Pooling) 레이어의 반복으로 신호의 타임라인 정보가 유실되거나 ad-hoc 윈도우 슬라이싱과 같은 과도한 데이터 증강 튜닝이 개입되는 한계가 존재했음.

### 1.2 제안하는 방법론: Fully Convolutional Network (FCN)
- **종단간 비지도/지도 학습 구조 (Pure End-to-End)**:
  - 사전 특징 추출 과정 없이 원시 시계열 수치 데이터를 그대로 입력받아 다차원 레이블로 직결하는 단순하고 강력한 아키텍처를 제안함.
- **FCN 특징 추출 블록**:
  - 3층의 1D 합성곱(Convolution) 레이어를 적층하며, 커널 크기는 $\{8, 5, 3\}$로 다르게 구성하여 다양한 범위의 국소 시간 패턴을 점진 포착함.
  - 각 합성곱 직후 Batch Normalization 및 ReLU 활성화 함수를 배치하여 깊은 망의 가속 수렴과 그래디언트 안정성을 달성함.
  - 오버피팅 예방과 맥락 정보 보존을 위해 맥스 풀링(Max Pooling)과 같은 다운샘플링 연산을 완전히 배제함.
- **Global Average Pooling (GAP) 및 Softmax**:
  - 마지막 합성곱 특징 맵의 전체 시간 축에 대해 평균값을 취하는 GAP 레이어를 도입하여 파라미터 수를 획기적으로 줄이고, 클래스 활성화 맵(Class Activation Map, CAM)을 유도하여 모델 예측 근거의 시각화(Explainability)가 가능하도록 유도함.

### 1.3 실험 결과
- UCR 44개 시계열 벤치마크 데이터셋에서 실험을 수행하여, 복잡한 앙상블 기법( flat-COTE, BOSSVS)과 MCNN 대비 비슷하거나 우수한 최고 수준의 정확도를 보여줌.
- 특히 FCN은 매우 단순한 레이어 구조와 최소화된 하이퍼파라미터 조건만으로도 최고 수준의 일반화 성능을 달성함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **온디바이스 혈당 예측 모델의 설명 가능성 결여 및 경량성 요구**:
  - 당뇨 환자는 인슐린 펌프 주입이나 식사 판단 시 예측 모델의 신뢰도 뿐만 아니라, 모델이 "왜" 특정 시간에 저혈당 혹은 고혈당 위험을 예측했는지에 대한 의학적 근거(설명 가능성)를 필요로 함.
  - FCN의 GAP와 CAM(Class Activation Map) 기법은 예측 결과에 기여한 원시 시계열의 특정 시간대(예: 1시간 전 식사 섭취 시점)를 가중치 활성화 맵으로 역산하여 제공할 수 있으므로, Stage 1의 설명 가능성 한계를 완벽히 보완함.
  - 또한, FCN은 연산 파라미터가 매우 적어 모바일 기기의 추론 연산 레이턴시를 혁신적으로 차감함.

### 2.2 FCN의 우리 연구 적용 방안 (Explainable Edge-FCN & CAM Attribution)
- **온디바이스 설명 가능한 1D FCN 구현**:
  - 다변량 입력 CGM 채널에 대해 1D FCN 백본을 탑재하고, 최종 혈당 예측단 바로 직전에 GAP 연산을 대체하는 설명 가능 전결합 레이어를 배치함.
  - 환자가 모바일 앱 화면에서 위험 경보를 볼 때, 역전파 기울기 또는 CAM 가중치를 단말 내부에서 closed-form으로 즉각 매핑하여 "최근 30분 전 탄수화물 섭취가 현재 고혈당 위험 예측의 80% 기여를 함"과 같은 시계열 어트리뷰션 정보를 실시간 표출하도록 구현함.

## 3. 한계점

### 3.1 3-step Lookback (L=3, 15분 이력) 환경 하에서의 대형 커널 $\{8, 5\}$ 작동 불능 및 Border Artifacts
- $L=3$의 극단적으로 짧은 시퀀스에 대형 1D 커널(크기 8 및 5)을 적용하면, 커널 윈도우가 입력 데이터의 범위를 초과하여 대부분 제로 패딩(Zero padding) 영역을 참조하게 됨.
- 이로 인해 경계부 왜곡(Border Artifacts) 노이즈가 출력 특징 맵에 지배적으로 유입되며, 원래 모델이 포착하고자 했던 필터링 정보가 완전히 무손실 학습되지 못하고 왜곡 수렴함.

### 3.2 Global Average Pooling (GAP)에 의한 미시적 혈당 스파이크 변동성 상실
- GAP는 시간 축의 모든 값을 평균 내어 고정 벡터로 변환하므로 분류 태스크에는 적당하나 회귀 예측(Forecasting)에는 치명적임.
- 3스텝(15분) 내에서 인슐린 주입 직후 발생하는 급격한 혈당 하강 추세의 세부 타임스탬프 정보가 GAP 평균 연산에 의해 지워져(평탄화) 실시간 제어 반응성을 완전히 상실함.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 L=3 환경 하의 커널 오버사이징 및 왜곡 지적
- **지적 사항**: 3스텝 길이의 입력에 커널 크기 8과 5를 적용하는 것은 극단적인 border padding 의존을 의미하며, 이는 유효 데이터의 표현력을 거의 상실시키고 경계 노이즈를 전파합니다.
- **개선 요구**: 3스텝 룩백 조건에 맞게 합성곱 커널 크기를 적정 스케일로 축소 조정하고 패딩 오차를 제어하십시오.

### 4.2 GAP 연산자의 평균 평탄화에 따른 제어성 상실 방지
- **지적 사항**: 회귀 모델링 하에서 시간 축 평균 풀링(GAP)을 가하는 것은 최근 혈당 변화 트렌드(1차/2차 미분치)를 완전히 희석시켜 실시간 예측의 예측력 저하를 초래합니다.
- **개선 요구**: 시간 축 정보를 왜곡 없이 다운스트림 회귀 레이어로 전달할 수 있는 특징 융합 및 어트리뷰션 추출 설계를 제시하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 12시간 단말 링 버퍼 적용 및 L=3 Local Kernel-3 Bypass (12h Buffering & Local Kernel-3 Bypass)
- **수정 설계**: 대형 $\{8, 5\}$ 커널 합성곱과 설명 가능한 CAM 분석은 단말에 저장된 **12시간 링 버퍼(144 스텝)** 데이터를 입력으로 하여 작동시키고, 실시간 추론 시의 **L=3** 최신 데이터는 커널 크기 **3** 이하의 **일반 Causal Conv 및 Skip Connection** 브랜치로 우회하여 결합합니다.
- **구체적 구현**:
  - 144스텝의 대사 변동 이력에 대해서는 원본 규격의 FCN(커널 8, 5, 3)을 가동하여 12시간 대사 특징 맵을 만들고 CAM 기여도를 계산합니다.
  - 동시에, 실시간 $L=3$ 입력은 Dilation=1, Kernel=3인 1층 Causal Conv를 통과시켜 가장 최근의 순시 잔차 특징을 신속히 추출합니다. 두 특징을 Concatenate하여 최종 Ridge 예측기로 전달하여 Border Artifacts를 원천 방지합니다.

### 5.2 GAP 제거 및 Temporal Flatten-Attention 대체 (Temporal Flatten-Attention Substitution)
- **수정 설계**: 시간 축의 평균화 평탄화 문제를 배제하기 위해, GAP 레이어를 전면 제거하고 대신 **Temporal Flatten-Attention** 또는 **Direct Spatial Projection (nn.Linear)** 레이어를 사용해 각 시점의 가중치를 독립적으로 예측단에 보존 결합합니다.
- **구체적 구현**:
  - 최종 Conv 특징 맵의 시간 차원을 평균 내지 않고, 3스텝 전체 특징 벡터를 Flatten하거나 시간 가중 텐서곱($W_{temp} \in \mathbb{R}^{3 \times 1}$)을 적용하여 각 타임스탬프의 가중 반영 값을 직접 보존한 상태로 출력 레이어로 정사영시킵니다. 이를 통해 순시 혈당 하강 속도 유실을 완벽히 차단합니다.
