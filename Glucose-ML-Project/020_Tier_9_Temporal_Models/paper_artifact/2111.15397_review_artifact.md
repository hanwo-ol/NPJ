## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 기존의 Facebook Prophet은 해석 가능하고 사용하기 편리한 시계열 예측 툴킷으로 자리잡았으나, Stan 백엔드 사용으로 인해 딥러닝 모듈과의 확장이 어렵고, 로컬 콘텍스트(Local Context) 정보를 포착하기 위한 자기회귀(Auto-Regression) 및 lagged covariates 모델링 기능이 부족하여 단기 예측 정확도가 떨어진다는 한계가 있었음.
- 딥러닝 기반의 블랙박스 예측 모델들은 높은 정확도를 보이지만, 부서별 의사결정이나 의료 임상 적용 단계에서 중요한 예측 분해 및 설명 가능성(Explainability)을 제공하지 못함.

### 1.2 제안하는 방법론: NeuralProphet
- **모듈러 선형-딥러닝 하이브리드 구조**:
  - Prophet의 전통적인 가산 구성요소(Trend, Seasonality, Events/Holidays)와 PyTorch 백엔드 기반의 신경망 모듈(AR-Net)을 결합하여 가산적 분해($\hat{y}_t = T(t) + S(t) + E(t) + F(t) + A(t) + L(t)$) 형식을 유지함.
- **AR-Net 기반의 Local Context 모델링**:
  - 자기회귀 $A(t)$와 lagged covariates $L(t)$를 위해 AR-Net 구조를 도입하여 과거 $p$개의 시점(lags)을 입력으로 받아 향후 $h$개의 예측 Horizon을 한 번에 출력함.
  - 이 AR-Net은 단일 선형 레이어(Linear AR) 또는 다층 신경망(Deep AR)으로 구성할 수 있으며, 가중치 규제($\Lambda_A$)를 통해 희소한 자기회귀 가중치(Sparse AR)를 학습할 수 있어 높은 해석력을 제공함.
- **PyTorch 기반 Stochastic Gradient Descent (SGD) 학습**:
  - Stan 백엔드를 PyTorch로 교체하여 표준 미니배치 SGD 및 AdamW 옵티마이저를 사용해 파라미터를 최적화하며, Huber 손실 함수를 기본으로 채택하여 이상치에 강건한 학습을 지원함.

### 1.3 실험 결과
- 인공 데이터셋 분해 실험에서 참값에 준하는 설명 가능한 패턴을 완벽히 복원해냈으며, 다양한 실제 시계열 데이터셋(univariate benchmarks)을 대상으로 한 단기 및 중기 예측 평가에서 Prophet 대비 55%에서 92%까지의 MSE 성능 개선을 입증함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **대사 역학 추세와 연속된 생리학적 지연 작용의 분리 곤란**:
  - 환자의 일주기 혈당 리듬(하루 주기)과 단기 인슐린/식사 투여에 의한 순시 혈당 하강/상승 작용이 얽혀 있어, 고정된 트리 모델로는 전체적인 일주기 흐름(Trend 및 Seasonality) 속에서 인슐린 잔여 약효(IOB)와 탄수화물 잔여 흡수(COB)의 기여도를 분해하여 분석하는 것이 불가능했음.
  - NeuralProphet의 퓨리에 항 기반 Seasonality 분해 및 Lagged Regressor 모듈 구조를 적용하면, 일주기 변동을 주기성 성분($S(t)$)으로 따로 떼어내어 모델링하고 인슐린/식사 이력을 Lagged Covariate 성분($L(t)$)으로 분리 학습함으로써 혈당 변화 요인을 임상적으로 명확히 설명할 수 있음.

### 2.2 NeuralProphet의 우리 연구 적용 방안 (Interpretable Daily Rhythm Decomposition & Compiled AR-Net Linear Layer)
- **일주기 리듬과 단기 인슐린 작용의 분해형 에뮬레이터**:
  - 퓨리에 급수를 이용하여 환자의 24시간 혈당 일주기 패턴을 학습하는 Seasonality 블록을 모바일 단말에 고정 탑재하고, 인슐린 볼러스 및 식사량 입력을 lagged covariates 모듈의 입력으로 하여 식후 급격한 혈당 상승세를 예측하도록 에뮬레이터를 구조화함.
- **임베디드 선형 AR-Net의 고속 추론 컴파일**:
  - Linear AR-Net은 실질적으로 $h \times p$ 크기의 가중치 행렬 곱 연산($y = Wx$)에 불과하므로, PyTorch 백엔드 없이 가중치를 바이너리로 저장한 뒤 C++ 또는 Neon 어셈블리 명령어로 직접 행렬곱 연산을 수행하도록 온디바이스 추론기를 경량 컴파일 배포함.

## 3. 한계점

### 3.1 3-step Lookback (L=3, 15분 이력) 환경 하에서의 인슐린 작용 지연(60~90분) 모델링 붕괴
- $L=3$ (15분)의 룩백 제약 조건에서는 AR-Net의 입력 차원 $p$가 3으로 축소됨. 이는 60분~90분 뒤에 최고조에 도달하는 인슐린 볼러스 및 식사의 지연 대사 피드백 정보를 완전히 누락하게 만듦.
- 입력 lags가 3인 조건에서는 푸리에 주기를 결정할 시퀀스가 성립하지 않아 Seasonality 모듈이 온전히 작동하지 못하고 상수 오프셋으로 평탄화됨.

### 3.2 PyTorch 런타임의 Edge CPU 상에서의 온디바이스 학습 연산 오버헤드
- NeuralProphet은 SGD 역전파와 PyTorch 자동 미분(Autograd) 시스템에 의존하므로, 모바일 기기 내부에서 환자 맞춤형 실시간 학습을 수행하기에는 PyTorch 모바일 엔진의 메모리 풋프린트와 CPU 사이클 소모량이 극심하여 가벼운 실시간 서비스에 부적합함.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 L=3 환경 하의 피처 스파스 한계 및 지연 피드백 해결 요구
- **지적 사항**: 15분짜리 $L=3$ 입력 윈도우 조건 하에서는 NeuralProphet의 퓨리에 Seasonality 성분 연산과 AR-Net의 다단계 예측 가중치가 데이터 스파스성으로 인해 발산하거나 제 기능을 잃습니다.
- **개선 요구**: 모바일 기기의 로컬 저장소 상에 최근 12시간 혈당 및 인슐린 이력을 누적 캐싱하는 링 버퍼를 생성하고, 이를 기반으로 24시간 주기 Fourier 특성과 인슐린 지연 약효(IOB)를 계산하여 모델의 Lagged Regressor 입력으로 공급하십시오.

### 4.2 PyTorch 백엔드 의존성에 따른 리소스 제어 요구
- **지적 사항**: 모바일 단말에서 PyTorch를 통한 경사 하강법 학습을 직접 구동하는 것은 자원 제약 하에서 심각한 레이턴시와 메모리 누수를 발생시킵니다.
- **개선 요구**: 온디바이스 파인튜닝 시 PyTorch 백엔드를 제거하고, Linear AR-Net 가중치를 고정하되 환자 개인화가 필요한 리프 선형 결합(Last-mile Fusion Layer)만을 재귀 최소 자승법(Recursive Least Squares, RLS) 또는 Kalman Filter와 같은 초경량 대수 필터로 단말 내에서 업데이트하도록 우회 설계를 도입하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 12시간 단말 링 버퍼 기반의 Rolling Features 및 L=3 Direct Feature Injection (12h Buffering Rolling Features & L=3 Direct Injection)
- **수정 설계**: 모바일 단말 측에 **12시간 링 버퍼(144 스텝)** 메모리를 운영하여 24시간 및 12시간 주기의 퓨리에 성분을 실시간 보간하고, 인슐린 지연 효과를 근사하는 감쇄 피처(IOB decay)를 Lagged Regressor 피처로 공급하며, 최신 **L=3** 혈당은 인젝션 특징으로 직접 linear path에 매핑합니다.
- **구체적 구현**:
  - `time_of_day` 정보를 사용하여 24시간 푸리에 주기 함수 $S(t)$ 값을 실시간 테이블 룩업으로 산출합니다.
  - 최신 3개 시점의 CGM 혈당 원시 값은 스파이크성 변동을 신속히 인지할 수 있도록 linear bypass 경로를 통해 최종 디코더 입력에 병렬 concat 결합합니다.

### 5.2 Decoupled Linear AR-Net 및 Recursive Least Squares Edge Tuner (Decoupled Linear AR & RLS Tuner)
- **수정 설계**: NeuralProphet의 딥러닝 구조를 Trend, Seasonality, Linear AR-Net으로 극도로 간소화하여 PyTorch 의존성을 완전히 제거한 C++ 엔진으로 포팅하고, 환자 개인화 학습 시에는 학습된 가중치를 동결한 뒤 최종 예측 바이어스 보정용 선형 가중치(Bias correction weight)만을 **Recursive Least Squares (RLS)** 필터 알고리즘으로 매 5분마다 1스텝 업데이트합니다.
- **구체적 구현**:
  - 예측 수식 $\hat{y}_{t+h} = T(t) + S(t) + W \cdot X_t + w_{bias} \cdot e_t$를 정적 C++ 코드로 최적화합니다. ($W$는 오프라인 사전 학습된 Sparse AR 가중치 행렬)
  - 5분 주기 데이터 수집 시마다 실제 잔차 $e_t$를 활용하여 1차원 $w_{bias}$ 가중치를 업데이트하는 RLS 공식(O(1) 복잡도)을 적용해 CPU의 연산 부담과 메모리 사용량을 최소화합니다.
