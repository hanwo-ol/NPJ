- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 자가 혈당 측정(SMBG)은 연속 혈당 측정(CGM)에 비해 저비용이며 널리 사용되지만, 데이터가 극도로 희소하고 불규칙하게 샘플링되어 임상적 지표인 TIR, TAR, TBR 등의 혈당 관리 범위 지표(TR Metrics)를 정확히 추정하기 어려움.
- 기존의 지도학습 모델들은 희소한 입력 조건 하에서 쉽게 과적합되거나, 샘플링 빈도 및 습관에 의존하여 모델 일반화 성능이 심각하게 저하되는 문제를 안고 있음.

### 1.2 제안하는 방법론: PACD-Net
- **다중 뷰 입력 표상 (Multi-View Input Representation)**:
  - 입력 데이터를 2차원 그리드 $D \times T$ (일수 $\times$ 일일 계측 수, 5분 해상도 기준 $T=288$) 형태로 변환.
  - 혈당값 행렬 $M_s$, 계측 누락 여부를 0/1로 표시한 결측 마스크 행렬 $M_m$, 그리고 일일/주기적 시간 정보를 복합 인코딩한 2차원 사인파 위치 인코딩 행렬 $M_p$를 채널 방향으로 결합하여 $3 \times D \times T$ 텐서 구축.
- **의사 증강 및 다중 뷰 생성 (Pseudo-Augmentation)**:
  - 동일한 CGM 실측 데이터로부터 임의 샘플링 비율 $\alpha$에 따라 두 종류의 뷰를 생성.
  - **교사 뷰 (Teacher Views, SMBG-T)**: 더 조밀한 샘플링 비율 $\alpha_T$를 적용하여 비교적 온전한 혈당 패턴 보존.
  - **학생 뷰 (Student Views, SMBG-S)**: 현실적인 희소 샘플링 비율 $\alpha_S < \alpha_T$를 적용하고, 활성 지점 선택(APS) 및 확률적 노이즈를 융합하여 가상 SMBG 뷰 구축.
- **Swin-CRB 백본 아키텍처**:
  - 이동 윈도우 기반 셀프 어텐션(W-MSA/SW-MSA)을 사용하는 Swin Transformer와 합성곱 잔차 블록(CRB)을 병렬로 연결하여 local continuity와 long-range dependency를 동시에 보존.
- **지식 증류 및 대조 학습**:
  - 교사 네트워크는 학생 네트워크 가중치의 지수 이동 평균(EMA)으로 파라미터를 점진 업데이트하며, 학생 뷰의 잠재 벡터가 교사 뷰의 Centering/Sharpening 기반 분포 타겟을 모방하도록 Cross-Entropy Loss ($L_{KD}$) 학습 수행.
  - 동일 샘플의 다른 학생 뷰 간에는 representations의 일관성을 유지하도록 contrastive loss 적용.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **희소 변수 및 불규칙 샘플링**: 환자별로 SMBG 입력 주기가 다르고 데이터가 간헐적일 때, LightGBM 백본 예측의 정확도가 급격히 붕괴됨.
- **결측 대처 방안 부재**: 기존 전처리는 forward-fill 또는 단순 선형 보간에만 의존하여 보간 편향이 잔차 자기상관(ACF)으로 누적됨.

### 2.2 PACD-Net의 우리 연구 적용 방안
- **결측 마스킹 피처 및 위치 인코딩 결합**:
  - 혈당 결측 위치를 나타내는 바이너리 마스크 $M_m$을 추가 차원 피처로 주입하고, 하루 중 시점(TOD) 정보를 사인/코사인 조합 위치 인코딩으로 매핑하여 모델에 명시적 샘플링 패턴 정보 제공.
- **오프라인 의사 증강을 통한 가중치 규제**:
  - 훈련 시 실측 결측을 모사하는 마스킹 증강(Masking Augmentation) 기법을 데이터 로더에 이식하여, 희소한 실제 계측치 하에서도 모델이 안정적으로 예측하도록 유도.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 3스텝 룩백(LOOKBACK_STEPS=3) 조건 하의 Swin-CRB 구조적 무력화
- **지적 사항**: 본 프로젝트의 기본 제약인 15분 룩백(3스텝) 조건 하에서는 2차원 패치 변환 및 계층적 Swin Transformer(이동 윈도우 self-attention, 패치 머징) 연산이 연산 차원 소멸로 인해 원천 불가능함. $3 \times D \times T$ 텐서 구성은 최소 며칠 단위의 윈도우가 필요하므로 15분 입력 API에 부적합함.
- **개선 요구**: 15분 단기 룩백 제약 조건 하에서 이 모델의 핵심 개념인 의사 증강 지식 증류와 결측 위치 인코딩을 구현할 수 있는 실질적인 차원 축소 및 네트워크 대체 안을 마련하십시오.

### 4.2 실시간 지식 증류 및 대조 학습의 Edge CPU 연산 오버헤드
- **지적 사항**: 교사-학생 EMA 업데이트, 대조 학습 쌍(Contrastive Pairs) 연산, Centering 벡터 모멘텀 업데이트 등은 모바일/웨어러블 Edge CPU 환경에서 실시간으로 처리하기에 메모리 및 연산 부하가 큽니다.
- **개선 요구**: 임베디드 자원 제약 하에서 추론 속도를 보장하기 위해 추론 아키텍처를 단순화할 방안을 구체화하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 15분 룩백 우회를 위한 '상태 지속성 로컬 링 버퍼(Client-Side Sliding Ring Buffer)' 및 1D CNN 대체 설계
- **수정 설계**: 15분 API 규격을 준수하면서도 과거 24시간의 누적 컨텍스트를 활용할 수 있도록 **Client-Side Sliding Ring Buffer** 기법을 적용합니다. 
  - 모바일 단말 측 메모리 캐시에 최근 288개(24시간 분량)의 5분 주기 실측/결측 혈당 세그먼트를 링 버퍼 형태로 누적 관리하고, 매 추론 시점마다 이 버퍼에 담긴 1D 시퀀스를 입력으로 전달합니다.
- **아키텍처 다운사이징**: 2D Swin Transformer 구조를 폐기하고, 1D 시퀀스에 대응하는 **1D Convolutional Residual Block (1D-CRB)**과 단일 헤드 어텐션(SHA) 1개 층으로 백본을 경량화하여 연산 차원 붕괴와 CPU 오버헤드를 동시에 해결합니다.

### 5.2 오프라인 증류 및 정적 학생 모델(Frozen Student) 배포 전략
- **수정 설계**: 실시간 EMA 및 온디바이스 학습 연산 문제를 해결하기 위해, 교사-학생 증류 프레임워크와 대조 학습은 고성능 오프라인 서버 환경에서만 진행합니다.
- **배포 방식**: 학습 완료 후 최적화된 **학생 모델(Student Encoder)**의 가중치만을 추출하여 ONNX 또는 PyTorch Lite 형태로 변환한 뒤 디바이스에 배포(Frozen Deployment)합니다. 실시간 추론 시에는 대조 학습 및 교사 네트워크 연산을 전면 배제하여 CPU 점유율을 1% 미만으로 유지합니다.
