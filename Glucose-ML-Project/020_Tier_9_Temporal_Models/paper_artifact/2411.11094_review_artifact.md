# Literature Survey Review: Non-Invasive Glucose Level Monitoring from PPG using a Hybrid CNN-GRU Deep Learning Network

- **논문 제목**: Non-Invasive Glucose Level Monitoring from PPG using a Hybrid CNN-GRU Deep Learning Network
- **저자**: Abdelrhman Y. Soliman, Ahmed M. Nor, Octavian Fratu, Simona Halunga, Osama A. Omer, & Ahmed S. Mubark (Aswan University / National University of Science and Technology POLITEHNICA Bucharest / arXiv:2411.11094)
- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

---

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 바늘로 피부를 찌르는 기존의 침습적 자가혈당측정(SMBG) 방식은 환자에게 신체적, 정신적 고통을 유발하며, 이는 지속적인 혈당 관리의 순응도를 떨어뜨리는 주요 원인임.
- 광학식 광전용적맥파(PPG) 센서를 이용한 비침습적 혈당 측정 연구가 진행되어 왔으나, 기존 연구들은 대부분 수동적인 주파수 영역 및 시간 영역 피처 추출 공식(FFT, Kaiser-Teager 에너지 등)에 의존하여 PPG 신호와 혈당 간의 비선형적인 관계를 충분히 학습하지 못함.

### 1.2 제안하는 방법론: Hybrid CNN-GRU Network
- **데이터 전처리 파이프라인**:
  - 2175 Hz로 고속 샘플링된 raw PPG 신호를 0.5 Hz ~ 8 Hz 대역의 대역통과 필터(Band-pass Filter)에 통과시켜 노이즈를 제거함.
  - 연산량 절감을 위해 주파수 특성을 보존하는 Nyquist 이론에 기반하여 30 Hz로 다운샘플링을 적용함.
  - 데이터 부족 문제(Mazandaran 데이터셋 v2, 67개 신호)를 극복하기 위해 가우시안 노이즈 주입 방식(Augmentation)을 적용하여 269개 샘플로 확장함.
- **병렬 하이브리드 아키텍처**:
  - **듀얼 CNN 블록**: 서로 다른 커널 크기를 가진 2개의 1D CNN 브랜치를 병렬로 배치하여, PPG 신호 내의 미시적(short-term) 및 거시적(long-term) 공간 피처(Spatial Patterns)를 효과적으로 추출함.
  - **단일 GRU 블록**: 다층 GRU 레이어를 배치하여 맥파 신호의 시퀀스 내 시간적 의존성(Temporal Patterns) 및 맥박 변동성을 캡처함.
  - **결합 및 회귀단**: 세 브랜치(CNN 2개, GRU 1개)의 출력 피처맵을 각각 Flatten한 후, 동일한 크기의 Fully Connected Layer를 거쳐 Concatenate(융합)하고, 최종 선형 레이어를 통해 연속적인 혈당 수치(mg/dL)로 회귀 예측함.
- **성능**: 테스트셋 기준 MAE 2.96 mg/dL, RMSE 3.94 mg/dL, R2 Score 0.97을 달성하였으며, Clarke Error Grid 분석에서 100%의 예측값이 임상적 안전 구역인 Zone A에 위치함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **단일 모달리티의 정보 한계**: CGM 데이터만 사용하는 기존 모델은 환자의 급격한 혈동역학적 변화(예: 운동으로 인한 말초 혈류량 변화, 자율신경계 반응)나 급격한 스트레스 상황에서의 혈당 변동을 신속하게 캡처하지 못해 오차가 누적됨.
- **입력 룩백의 지연**: 15분(3스텝)의 짧은 CGM 이력만으로는 향후 30분 ~ 1시간 뒤의 혈당 변동 기울기를 정확히 외삽하기 어려움.

### 2.2 본 논문 방법론의 우리 연구 적용 방안 (PPG Auxiliary Stream Integration)
- **자율신경 및 혈류역학 대리 변수 주입**:
  - 웨어러블 디바이스의 PPG 센서로부터 30 Hz로 획득된 단기 맥파 흐름(예: 10초 윈도우)을 CNN-GRU 네트워크에 통과시켜 순시적 혈류 점성 및 심박변이도(HRV) 관련 잠재 피처를 추출함.
  - 이를 우리 백본 모델(LightGBM 또는 Temporal Model)의 메인 입력단에 동적 공변량 채널로 주입하여, CGM 잔차 자기상관(ACF)을 유발하는 생리학적 미계측 노이즈를 상쇄함.

## 3. 검증 및 실험 로드맵 제안

### 3.1 Baseline 비교군 설정
1. **CGM-only Temporal Model**: CGM 이력(3스텝)과 기본 정적 피처만 사용하는 베이스라인.
2. **CGM + Raw PPG Fusion**: Raw PPG 신호(30 Hz, 10초)를 단순 컨볼루션하여 메인 모델에 결합한 하이브리드.
3. **CGM + CNN-GRU Latent Feature (Proposed)**: 본 논문의 병렬 구조로 추출된 맥동 공간-시간 잠재 벡터를 CGM 시퀀스와 결합하여 학습한 모델.

### 3.2 핵심 평가 메트릭
- **예측 타겟**: 향후 30분, 60분 혈당 수치 예측의 MAE, RMSE.
- **임상적 안전성**: Clarke Error Grid의 Zone A+B 비율 및 오차의 자기상관성(Ljung-Box p-value).

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 3-step Lookback(15분) 제약과 30 Hz 고빈도 PPG 신호 간의 주파수 불일치 및 차원 충돌
- **지적 사항**: 본 프로젝트의 실시간 추론 API는 5분 단위로 계측되는 3스텝(15분) CGM 이력 데이터를 입력으로 사용하도록 엄격히 제약되어 있음. 반면, 30 Hz PPG 신호는 10초 분량만 하더라도 300개의 데이터 포인트를 생성하므로 차원 수와 타임스텝의 주기가 전혀 맞지 않음. 만약 15분 전체의 PPG 신호를 추론 윈도우로 잡는다면 27,000스텝의 초고차원 입력이 필요하게 되어 실시간 API 규격을 완전히 위반함.
- **개선 요구**: 15분 CGM 룩백 제약을 유지하면서 고빈도 PPG 데이터를 정합할 수 있는 입력 차원 정렬 및 동기화 기법을 제시하십시오.

### 4.2 Edge CPU 환경에서 3개 병렬 딥러닝 브랜치(CNN2, GRU1) 동시 추론 부하
- **지적 사항**: 본 논문은 2개의 CNN 브랜치와 1개의 GRU 브랜치를 병렬로 실행한 후 결합하는 구조를 가짐. 이는 모바일이나 웨어러블 디바이스의 Edge CPU 환경에서 실시간 5분 주기로 연속 추론을 수행할 때 메모리 대역폭 점유율이 높고 연산 지연(Latency)을 유발할 수 있음. 특히 GRU는 순차적 연산 특성으로 인해 CPU 스레드 병렬화 효율이 매우 낮음.
- **개선 요구**: 모델의 병렬 구조를 유지하되 연산 FLOPs와 메모리 풋프린트를 80% 이상 절감할 수 있는 경량화 필터를 고안하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 비동기식 '터치 트리거형' 이벤트 기반 예측 및 잠재 상태 인코더 (Event-Driven Latent Encoder)
- **수정 설계**: CGM의 5분 주기 동기 추론 루프에 PPG 데이터를 상시 주입하는 대신, 사용자가 스마트 워치 등의 전극에 손을 대어 측정이 개시되는 시점에만 비동기적으로 동작하는 **터치 트리거형(Event-driven) 잠재 상태 인코더** 구조를 채택함.
- **구체적 구현**:
  - PPG 신호는 터치 센서 활성화 시점 기준 최신 10초(300 스텝)만 수집함.
  - 이 10초의 PPG를 본 논문의 CNN-GRU 인코더에 통과시켜 단일 정적 벡터 $\mathbf{v}_{ppg} \in \mathbb{R}^{16}$로 압축함.
  - 압축된 16차원의 잠재 벡터는 CGM의 3스텝 정적 공변량(Static Covariates) 채널에 결합(Concatenate)되어 메인 예측 모델로 주입됨. 이로써 3스텝 시퀀스 형태의 메인 룩백 구조를 전혀 훼손하지 않으면서 주파수 정합 문제를 완벽히 해결함.

### 5.2 구조적 경량화 및 깊이별 분리 합성곱(Depthwise Separable Conv) 적용
- **수정 설계**: 병렬 브랜치의 연산 부하를 제어하기 위해 1D 일반 합성곱을 **1D 깊이별 분리 합성곱(Depthwise Separable Convolution)**으로 대체하고, GRU 유닛을 단일 레이어 및 채널 독립형 선형 매핑으로 간소화함.
- **구체적 구현**:
  - CNN 브랜치의 Conv1D 레이어를 `Depthwise Conv1D`와 `Pointwise Conv1D`로 분할하여 파라미터 수와 연산량을 대폭 감소시킴. (예: 커널 크기 $K=15$일 때 연산량 약 85% 감축)
  - 순차 추론 연산 부하가 큰 GRU 브랜치는 GRU 셀 개수를 16개로 최소화하고 중간 전사 게이트(Update/Reset Gate) 연산을 간소화한 경량 GRU(Minimal GRU) 또는 시간 축 풀링 후 1D Convolutional 레이어로 대체하여 순차 의존성 연산 지연을 차단함.
