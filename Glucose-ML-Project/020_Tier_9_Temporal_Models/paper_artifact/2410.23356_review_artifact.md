# Literature Survey Review: Sequential Order-Robust Mamba for Time Series Forecasting

- **논문 제목**: Sequential Order-Robust Mamba for Time Series Forecasting
- **저자**: Seunghan Lee, Juri Hong, Kibok Lee, & Taeyoung Park (Yonsei University / arXiv:2410.23356)
- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

---

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 시계열 예측에서 Mamba 아키텍처를 도입하여 채널 간 상관관계(Channel Dependency, CD)를 처리하려는 최신 연구들이 등장함 (예: iTransformer처럼 각 채널을 독립 토큰으로 취급).
- 그러나 Mamba는 자연어 처리에서 유래하여 토큰의 입력 '순서'에 민감한 순방향 순차 편향(Sequential Order Bias)을 내장하고 있음. 반면 다변량 시계열의 채널들(예: 기온, 풍속, 습도 등)은 자연어와 달리 특정한 물리적 순서가 존재하지 않음.
- 기존 연구들은 이를 해결하기 위해 두 개의 서로 다른 가중치를 갖는 양방향 Mamba(Bidirectional Mamba)를 사용하여 연산 매개변수가 2배로 증가하거나, 학습 시 채널 순서를 무작위 셔플하고 추론 시 최적의 순서를 탐색하는 추가 비용이 발생함.

### 1.2 제안하는 방법론: SOR-Mamba
- **CD-Mamba 블록 설계 (1D 합성곱 제거)**:
  - 기존 Mamba 블록은 순차 데이터의 국소 정보 취합을 위해 SSM 레이어 앞에 1D-convolution을 적용함. 그러나 채널 차원은 인접 채널 간의 국소적 순서가 무의미하므로 1D-conv가 불필요함.
  - SOR-Mamba는 1D-conv를 블록에서 제거하여 연산량을 절감하고 채널 독립적 관계 학습에 집중함.
- **채널 순서 대칭 규제화 (Sequential Order Regularization)**:
  - 단일 단방향 Mamba(Shared Parameter)만 사용하면서, 입력 채널 토큰 순서 $Z$와 이를 역순으로 뒤집은 $Z^\star$를 각각 통과시킵니다.
  - 순방향 출력 $Z_1$과 역순방향 출력의 역순 정렬 $Z_2$ 사이의 MSE 거리를 계산하여 규제화 손실 함수 $L_{reg}$를 생성함.
  - 이 규제화를 통해 단방향 Mamba가 입력 순서에 무관하게 동일한 표현을 출력하도록 강제하고, 두 출력의 평균을 내어 잔차 경로에 더함 ($Z_{new} = (Z_1 + Z_2) + Z$).
- **채널 상관관계 모델링 사전 학습 (Channel Correlation Modeling, CCM)**:
  - 데이터 공간에서의 채널 간 피어슨 상관 행렬 $R_x$와, 인코더 통과 후 잠재 공간에서의 상관 행렬 $R_z$ 간의 거리를 최소화하는 사전 학습 태스크(CCM)를 도입함. 이를 통해 임베딩 단계에서 채널 간의 선형 상관관계 구조를 강력히 보존함.

### 1.3 실험 결과
- ETT, PEMS, ECL, Weather 등 13개 벤치마크 데이터셋에서 S-Mamba 및 iTransformer 대비 우수한 예측 성능(MSE/MAE)을 입증함.
- 단방향 Mamba에 대칭 규제화만 가하는 구조로, 2배의 파라미터를 갖는 Bidirectional Mamba보다 우수한 성능과 효율성을 달성함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **채널 간 선후 관계 규정의 모호성**:
  - 혈당 예측에 활용되는 다변량 변수들(CGM 혈당, 주입된 인슐린량, 식사 탄수화물량, 활동량 등)은 논리적 선후 관계가 명확하지 않음.
  - Mamba 백본을 혈당 다변량 채널에 직접 적용 시, 변수를 어떤 순서로 모델에 주입하느냐(예: [CGM, 인슐린, 식사] vs [식사, 인슐린, CGM])에 따라 예측 성능이 변동하여 모바일 헬스케어 디바이스에서의 예측 일관성이 깨지는 문제가 우려됨.

### 2.2 SOR-Mamba의 우리 연구 적용 방안 (Order-Robust CD-Mamba)
- **채널 불변형 다변량 인코더 구축**:
  - 혈당 예측의 다변량 피처를 처리할 때 SOR-Mamba의 규제화 기법을 차용함.
  - 임의의 변수 순서로 주입하더라도 모델 내부의 잠재 벡터가 일치하도록 순서 대칭 손실을 적용하여 학습함으로써 환자의 입력 로그가 누락되거나 정렬이 바뀌어도 동일한 출력 신뢰도를 보장하도록 설계함.

## 3. 검증 및 실험 로드맵 제안

### 3.1 Baseline 비교군 설정
1. **iTransformer**: 채널 단위 self-attention을 수행하는 트랜스포머 모델.
2. **S-Mamba**: 2배의 파라미터를 갖는 고정 Bidirectional Mamba 모델.
3. **SOR-Mamba (Proposed)**: 1D-conv가 제거되고 순서 규제화 손실 $L_{reg}$가 추가된 단방향 Mamba 모델.

### 3.2 핵심 평가 메트릭
- **순서 불변성 테스트 (Order-Permutation Shift)**: 입력 채널의 순서를 무작위로 변경했을 때 예측값의 분산(Variance of predictions under permutation). 이상적인 수치는 0에 수렴해야 함.
- **예측 평가지표**: RMSE, MAE, MARD.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

본 섹션은 감시자 에이전트(인격 3)가 연구원 에이전트(인격 2)의 1차 설계 아티팩트를 검수하고 남긴 비판적 검토 의견입니다.

### 4.1 3-step Lookback ($L=3$) 환경 하에서의 피어슨 상관 행렬 ($R_x$) 계산 붕괴
- **지적 사항**: SOR-Mamba가 제안한 CCM 사전학습은 데이터 공간에서의 채널 간 상관관계 행렬 $R_x \in \mathbb{R}^{C \times C}$를 계산합니다. 그러나 $L=3$ (15분 이력) 조건 하에서는 각 채널별 표본 크기가 단 3개에 불과합니다. 단 3개의 데이터 포인트로 계산된 피어슨 상관계수는 통계적 불확실성이 극도로 높고 노이즈에 극 취약하여 실제 물리적 채널 상관관계(예: 식사 섭취 후 인슐린 작용에 의한 혈당 하강)를 전혀 반영하지 못하고 왜곡된 학습 목표를 제시하게 됩니다.
- **개선 요구**: 극도로 짧은 룩백 제약 하에서도 안정적으로 채널 간 상관 구조를 캘리브레이션할 수 있는 사전 학습 손실 우회안을 도출하십시오.

### 4.2 실시간 추론 시 이중 순방향 패스 연산으로 인한 CPU 병목
- **지적 사항**: SOR-Mamba는 순방향 $Z_1$과 역순방향 $Z_2$의 출력을 모두 계산하고 평균을 내어 잔차에 더합니다 ($Z_{new} = (Z_1 + Z_2) + Z$). 이는 비록 파라미터는 공유하지만, 추론 단계에서 동일한 Mamba 블록에 대해 두 번의 Forward-pass를 순차 실행해야 하므로 CPU 상의 연산 자원 점유율을 2배로 증가시킵니다. 실시간 Edge 예측 시 추론 지연을 유발할 수 있습니다.
- **개선 요구**: 학습 단계에서의 채널 불변성 규제 효과는 유지하되, 실시간 추론 시에는 단 1회의 순방향 연산만 수행할 수 있도록 연산 효율을 개선하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

본 섹션은 수정자 에이전트(인격 4)가 감시자의 지적 사항을 분석하여 수립한 최종 보완 설계안입니다.

### 5.1 배치 단위 표본 확장을 통한 미니배치 채널 상관 행렬 추정 (Cross-Batch Correlation Estimation)
- **수정 설계**: 단일 샘플 내 3스텝 길이의 한계로 인한 $R_x$ 계산의 통계적 불안정성을 해소하기 위해, **미니배치(Batch Size $B$) 전체 차원을 병합하여 상관 행렬을 추정**하는 방식을 적용합니다.
- **구체적 구현**:
  - 사전 학습 단계에서 단일 샘플(1, 3, $C$) 단위로 상관관계를 구하지 않고, 배치 내 모든 샘플을 병합하여 크기 ($B \times 3, C$)의 행렬로 재정렬합니다.
  - 배치 크기가 $B=64$인 경우 표본 크기가 $N = 192$로 확장되므로, 통계적으로 유의미하고 안정적인 $C \times C$ 피어슨 상관 행렬 $R_x$를 도출할 수 있습니다. 이를 통해 CCM 사전 학습의 타겟 노이즈를 극적으로 억제합니다.

### 5.2 추론 단방향 동결 배포 전략 (Inference-time Single-pass Deployment)
- **수정 설계**: 학습 단계에서 정합성을 만족하도록 훈련한 뒤, 실제 모바일/CPU 추론 환경에서는 역순방향 패스($Z_2$) 연산을 전면 생략하는 **단방향 동결 배포**를 적용합니다.
- **구체적 구현**:
  - 오프라인 학습 단계에서는 순방향 $Z_1$과 역순방향 $Z_2$를 모두 구하고 $L_{reg}$ 손실을 강제하여 가중치가 순서 불변성을 획득하도록 훈련합니다.
  - 모델의 순서 불변 성능이 검증된 후, 추론(Inference) 단계 코드에서는 $Z_2$ 계산 경로를 제거하고 오직 $Z_{new} = Z_1 + Z$만 연산하여 출력합니다. 가중치가 이미 순서에 무관하도록 학습되었기 때문에 단방향 스캔만으로 동등한 예측 결과를 유지하며 CPU 연산 오버헤드를 정확히 50% 절감합니다.
