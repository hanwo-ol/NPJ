- **논문 제목**: ms-Mamba: Multi-scale Mamba for Time-Series Forecasting

- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 시계열 데이터(전력망 부하, 기상, 교통량 등)는 시간의 흐름에 따라 여러 가지 서로 다른 시간적 스케일(Temporal Scale)의 변화 패턴(예: 시간당 변동, 일일 주기, 계절성 등)이 중첩되어 존재함.
- 기존의 Mamba 기반 모델(예: S-Mamba)이나 Transformer 모델들은 입력 시퀀스를 단일한 시간적 스케일(Single Temporal Scale)로만 처리하므로, 고주파 변동(급격한 피크)과 저주파 트렌드(장기 추세) 간의 트레이드오프가 발생하여 예측 성능이 제한됨.
- Transformers는 긴 시퀀스 입력 시 $O(L^2)$의 이차 복잡도 문제가 있어 멀티스케일 모델링 시 연산 부하가 매우 큼.

### 1.2 제안하는 방법론: ms-Mamba (Multi-scale Mamba)
- **SSM 이산화 파라미터 $\Delta$를 활용한 멀티스케일 모델링**:
  - Mamba의 상태 공간 모델(SSM)은 물리적 연속 상태를 이산화할 때 샘플링 레이트 $\Delta$를 적용함. 논문은 $\Delta$의 크기에 따라 시간적 해상도와 메모리 길이가 결정되는 물리적 성질에 주목함.
  - 큰 $\Delta$는 짧은 메모리와 낮은 해상도(대략적 패턴)를 유도하고, 작은 $\Delta$는 긴 메모리와 높은 해상도(정밀한 패턴)를 유도함.
- **병렬 Multi-scale Mamba 블록 설계**:
  - 입력 임베딩을 $s$개의 서로 다른 $\Delta_i$ 파라미터를 가진 Mamba 블록들에 병렬 주입하여 학습함.
  - 입력 데이터를 다운샘플링하는 아키텍처 구조 대신, SSM 내부의 이산화 속도만 다르게 적용하여 모든 블록이 동일한 차원의 입출력을 유지하도록 설계함. 이를 통해 기하학적 정렬 오버헤드 없이 직접 출력을 평균(Average)하여 병합함.
- **샘플링 레이트($\Delta_i$) 결정 전략**:
  - 오프라인 하이퍼파라미터 배수를 적용하는 fixed scales ($\Delta_i = \alpha_i \times \Delta_1$), 개별 학습하는 learnable scales, 입력 피처 기반 MLP로 추정하는 dynamic scales 세 가지를 설계 및 검증함. 실험적으로 learnable scales가 가장 우수한 성능을 보임.

### 1.3 실험 결과
- Traffic, ETT, Solar-Energy 등 13개 벤치마크 시계열 데이터셋에서 S-Mamba 및 iTransformer 등 SOTA 모델 대비 우수한 성능을 입증함.
- 특히 Solar-Energy 데이터셋에서 S-Mamba 대비 MSE를 0.240에서 0.229로 개선하면서도, 파라미터 수(3.53M vs. 4.77M)와 연산량(14.93G vs. 20.53G MACs)을 크게 절감함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **다양한 시간 주기의 혈당 변동 누출**:
  - 혈당 데이터는 식사 및 인슐린 주입에 의한 단기 급변동(30분~2시간)과 환자의 일주기 생체 리듬에 따른 장기 기저 트렌드(24시간 주기)가 동시에 작용함.
  - LightGBM은 이를 구분하지 못하고 단일 벡터의 피처로 취급하여, 식후 피크 혈당은 급격히 언더슈팅(평균값으로 수렴)하고 기저 혈당 대역에서는 불필요한 노이즈 예측을 반복하는 한계를 보임.

### 2.2 ms-Mamba의 우리 연구 적용 방안 (Multi-scale SSM Layer)
- **혈당 예측용 이중 스케일 Mamba 레이어 구축**:
  - 백본 모델에 ms-Mamba 블록을 도입하여 단기 스케일($\Delta_{fast}$)과 장기 스케일($\Delta_{slow}$)의 두 가지 병렬 경로를 생성함.
  - 단기 경로는 급격한 탄수화물 흡수 및 초속효성 인슐린 작용 곡선을 추적하고, 장기 경로는 체내 잔류 인슐린(IOB)의 느린 누적 감쇄 및 기저 대사 속도를 학습하여 정합 성능을 극대화함.

## 3. 검증 및 실험 로드맵 제안

### 3.1 Baseline 비교군 설정
1. **LightGBM (Base)**: 정적 표 형식 입력 피처를 사용하는 트리 모델.
2. **S-Mamba (Single-scale)**: 단일 $\Delta$를 가진 양방향 Mamba 모델.
3. **ms-Mamba (Proposed)**: 2~4개 스케일의 learnable $\Delta_i$를 결합한 멀티스케일 Mamba 모델.

### 3.2 핵심 평가 메트릭
- **혈당 예측 Horizon (30분, 60분)**: RMSE, MAE, MARD (Mean Absolute Relative Difference).
- **임상적 안전성 지표**: Clarke Error Grid (Zone A+B 비율), 하이포/하이퍼 검출 감도.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

본 섹션은 감시자 에이전트(인격 3)가 연구원 에이전트(인격 2)의 1차 설계 아티팩트를 검수하고 남긴 비판적 검토 의견입니다.

### 4.1 3-step Lookback ($L=3$) 환경 하에서의 멀티스케일 SSM 무력화 및 불안정성
- **지적 사항**: Glucose-ML 프로젝트의 엄격한 3스텝 룩백(15분 이력) 환경 하에서 시계열의 길이가 극도로 짧습니다. 이 조건에서는 입력 시퀀스 자체에 일주기나 몇 시간 단위의 저주파 패턴이 존재하지 않으므로, 느린 스케일($\Delta_{slow}$ 혹은 큰 $\Delta$) 경로가 학습할 수 있는 정보가 전무합니다. 또한 큰 멀티플라이어($\alpha_i$)를 적용할 경우, 매우 짧은 시퀀스 상에서 이산화 전이 행렬 $\bar{A} = \exp(\Delta A)$의 값이 급격히 발산하여 수치적 불안정성(Numerical Explosion)이 발생할 우려가 큽니다.
- **개선 요구**: 3스텝 룩백 제약 하에서도 수치적 안정성을 보장하고, 극도로 짧은 시퀀스의 한계를 우회하여 실제 멀티스케일 혈당 역학 정보를 전달할 수 있는 보완 설계를 수립하십시오.

### 4.2 CPU 전용 환경에서의 병렬 Mamba 스캔 연산 오버헤드
- **지적 사항**: Mamba의 핵심 연산인 Selective Scan은 GPU의 SRAM과 DRAM 간 초고속 데이터 전송 최적화(Kernel Fusion)에 극도로 의존합니다. GPU가 없는 CPU 전용 로컬 환경에서는 병렬 스캔 커널을 활용할 수 없으므로, PyTorch의 순차 루프 또는 느린 CPU 텐서 연산으로 에뮬레이션해야 합니다. 이 상황에서 병렬로 여러 개(예: 4개)의 Mamba 블록을 동시에 연산하고 평균을 내는 구조는 추론 지연 시간(Latency)을 최소 4배 이상 증가시켜 실시간 15분 추론 윈도우 내의 CPU 연산량을 크게 초과합니다.
- **개선 요구**: CPU 환경에서 스캔 루프 연산 횟수를 최소화하고 연산 효율을 높이기 위한 구조적 경량화 대안을 설계하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

본 섹션은 수정자 에이전트(인격 4)가 감시자의 지적 사항을 분석하여 수립한 최종 보완 설계안입니다.

### 5.1 오프라인 멀티스케일 슬라이딩 윈도우 캐시 피처 결합 (Static-Dynamic Multi-scale Feature Injector)
- **수정 설계**: 실시간 추론 시 3스텝 룩백 입력 길이 한계를 극복하기 위해, 원본 데이터 수준에서 장기 멀티스케일 정보를 요약하여 추가 변수로 주입하는 **오프라인 윈도우 캐시 주입기**를 적용합니다.
- **구체적 구현**:
  - 클라이언트 단말 장치 측에 2시간, 12시간, 24시간 단위의 슬라이딩 윈도우 링 버퍼를 유지합니다.
  - 이 버퍼로부터 계산된 장기 평균 혈당, 변동계수(CV), 인슐린 누적 주입량(IOB 대리 지표)을 계산하여 각 시점의 정적/동적 공변량 채널로 주입합니다.
  - Mamba 블록은 입력 길이 3의 짧은 시퀀스 내에서 이 사전 계산된 다중 주기 변수를 동적 채널로 받아들이므로, 이산화 불안정성 없이 단기 및 장기 물리 패턴을 동시에 학습할 수 있습니다.

### 5.2 이산화 샘플링 레이트 바인딩 및 시그모이드 스케일링 제약 (Bounded Delta Scaling)
- **수정 설계**: $\Delta$가 역전파 과정에서 과도하게 커져 $\bar{A}$가 발산하는 현상을 막기 위해, Mamba 블록 내부의 $\Delta$ 파라미터에 엄격한 상하한 범위를 강제하는 **시그모이드 매핑 제약**을 적용합니다.
- **구체적 구현**:
  - $\Delta_i$의 출력단에 $\Delta_{constrained} = \Delta_{min} + (\Delta_{max} - \Delta_{min}) \cdot \sigma(\theta_\Delta)$ 공식을 도입합니다.
  - 여기서 $\Delta_{min}=0.001$, $\Delta_{max}=0.5$로 바인딩하여 3스텝의 짧은 시퀀스 내에서도 이산화 전이 행렬이 안정적인 수렴 범위($\bar{A} < 1$) 내에 위치하도록 물리적으로 제한합니다.

### 5.3 단일 헤드 상태 스캔 분할 및 스케일 풀링 우회 (Single-Scan Channel-Split Multi-scale Scan)
- **수정 설계**: CPU 상에서 병렬 Mamba 블록의 다중 스캔 연산으로 인한 Latency 폭증을 해결하기 위해, 독립된 여러 블록을 병렬 구동하는 대신 **단일 Mamba 스캔 내부 채널 분할 구조**를 도입합니다.
- **구체적 구현**:
  - 단 1개의 Mamba 블록만 구동하되, 내부 히든 채널 차원 $D_{hidden}$을 2개 영역(예: 단기 채널군, 장기 채널군)으로 분할합니다.
  - 각 채널 영역별로 미리 정의된 이산화 파라미터 $\Delta_{fast}$와 $\Delta_{slow}$를 슬라이스 단위로 다르게 곱해 단 한 번의 Selective Scan 연산($O(1)$ CPU Scan)으로 다중 스케일 시간 패턴을 동시에 도출합니다.
  - 이를 통해 CPU 연산 횟수를 기존 대비 75% 이상 단축하여 단 1회 스캔 비용으로 실시간 추론 연산 지연을 제어합니다.
