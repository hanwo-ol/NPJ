# Literature Survey Review: GlucoFM-Bench: Benchmarking Time-Series Foundation Models for Blood Glucose Forecasting

- **논문 제목**: GlucoFM-Bench: Benchmarking Time-Series Foundation Models for Blood Glucose Forecasting
- **저자**: Baiying Lu, Zhaohui Liang, Ryan Pontius, Shengpu Tang, & Temiloluwa Prioleau (Dartmouth College / Emory University / arXiv:2606.06881)
- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

---

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 지도학습 기반의 기존 혈당 예측 모델(RNN, LSTM, Transformer 등)은 특정 단일 데이터셋이나 좁은 코호트에 맞춰 학습되어, 이종 환자군이나 새로운 치료 도메인에 적용할 때 일반화 성능이 현격히 떨어짐.
- 최근 다양한 도메인에서 사전 학습된 시계열 기초 모델(TSFM) 및 LLM 기반 시계열 예측 프레임워크가 각광받고 있으나, 임상 혈당 예측 분야에서의 제로샷(Zero-shot) 전이력, 데이터 효율성, 그리고 실제 임상적 유용성에 대한 벤치마크 평가는 거의 전무한 실정임.

### 1.2 제안하는 방법론: GlucoFM-Bench Framework
- **최초의 혈당 예측 TSFM 벤치마크**:
  - 12개의 공개 CGM 데이터셋과 3개의 제어 접근 데이터셋(OhioT1DM, DiaTrend, T1DEXI)을 통합하고, 5분 주기로 업샘플링/다운샘플링하여 총 1,117명 대상 1,100만 건 이상의 CGM 계측값으로 구성된 표준화된 벤치마크를 정비함.
- **비교 대상 모델군**:
  - **기초 모델 (TSFMs)**: Chronos-2 (GPT 계열 수치 토큰화), Moirai 2.0 (다중 패치 구조), Timer, TimesFM 2.5 (디코더 전용 패치 예측).
  - **LLM 기반 시계열 모델**: TimeLLM (텍스트 프롬프트 조건화), CALF (GPT-2 백본 크로스모달 파인튜닝).
  - **지도학습 기반 모델**: Martinsson et al.의 LSTM, Zhu et al.의 GPFormer (Transformer).
- **주요 실험 및 벤치마크 결과**:
  - **제로샷 및 퓨샷 전이력**: TimesFM 2.5와 Chronos-2는 미학습 도메인에서도 뛰어난 제로샷 성능을 보여주며, 가장 우수한 제로샷 성능은 전체 지도학습(Full-shot) 모델 오차의 5% 이내로 근접함.
  - **데이터 풍부 시의 반전**: 하지만 학습 데이터가 충분히 주어지는 풀샷(Full-shot) 파인튜닝 시나리오에서는 오히려 **경량 LSTM 모델이 TSFM 및 LLM 계열 대비 4% ~ 21% 더 낮은 예측 오차(RMSE)**를 보이며 가장 강력한 성능을 기록함. 이는 혈당 예측이 고도로 환자-특이적인 역학(Personalized Dynamics)에 지배받기 때문에, 거대한 범용 사전학습 패턴보다 소규모 맞춤형 학습이 더 유용함을 시사함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **개인화 분포 전이(Covariate Shift)**: LODO(Leave-One-Donor-Out) 검증 시, 특정 환자의 독특한 인슐린 반응성이나 일주기 주기성(Circadian periodicity)을 반영하지 못해 타겟 환자 전이 단계에서 일관적인 예측 오차가 누적됨.
- **데이터 부족 구간에서의 성능 급락**: 신규 수집된 소수 데이터셋에 대해 모델을 신속하게 적응(Few-shot adaptation)시키기 어려워 초기 탐색 기간에 불안정한 예측을 생성함.

### 2.2 GlucoFM-Bench의 우리 연구 적용 방안 (TimesFM-Guided LSTM Distillation)
- **사전학습 TSFM 기반의 Few-shot Warm-up 모듈 활용**:
  - 새로운 환자의 데이터가 유입되는 극초기(Few-shot 단계)에는 일반화 성능이 증명된 범용 TimesFM 2.5 제로샷 추정치를 결합하여 예측 안전판을 확보함.
  - 환자 데이터가 점진적으로 축적됨에 따라, TimesFM의 예측 궤적을 지식 증류(Knowledge Distillation)의 가이드라인으로 활용해 로컬 경량 LSTM 또는 LightGBM 백본을 정밀 파인튜닝(Full-shot)하는 2단계 전이 학습 파이프라인을 구축함.

## 3. 검증 및 실험 로드맵 제안

### 3.1 Baseline 비교군 설정
1. **Scratch Supervised LSTM**: 사전 지식 없이 신규 환자 데이터로 처음부터 학습한 LSTM.
2. **Zero-shot TimesFM 2.5**: 파인튜닝 없이 바로 혈당 예측을 수행하는 범용 TimesFM.
3. **TimesFM-Distilled Hybrid Model (Proposed)**: TimesFM 2.5의 제로샷 예측으로 초기 구간을 보조하고, 이후 정밀화된 로컬 경량 LSTM으로 점진 대체하는 파이프라인.

### 3.2 핵심 평가 메트릭
- **정확도**: 15분, 30분, 60분 Horizon에 대한 RMSE, MAE.
- **적응 속도**: 훈련 샘플 개수(1일치, 3일치, 10일치)에 따른 검증 오차 수렴 속도.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 15분(3스텝) 입력 룩백 하에서 TimesFM/Chronos의 12시간 컨텍스트 요구 충돌
- **지적 사항**: 본 벤치마크에 사용된 대부분의 TSFM(TimesFM, Chronos 등)은 시간적 일주기 패턴을 인식하기 위해 최소 12시간(144스텝)의 긴 입력 컨텍스트 윈도우를 기본 요건으로 요구함. 하지만 본 프로젝트의 실시간 추론 API 입력 규격인 15분(3스텝) CGM 데이터만 주입할 경우, 패치 단위 분할이 불가능하거나 트랜스포머의 어텐션 맵이 축소되어 Zero-shot 추론 자체가 완전히 거부되거나 예측 정확도가 심각하게 훼손됨.
- **개선 요구**: 15분 입력 제약을 훼손하지 않으면서 12시간 분량의 기초 모델 컨텍스트 윈도우를 정합할 수 있는 아키텍처적 우회 방안을 제시하십시오.

### 4.2 수억 개 파라미터 규모 TSFM 및 LLM(TimeLLM/CALF)의 Edge CPU 실시간 추론 불가
- **지적 사항**: 수억 개의 매개변수를 지닌 대규모 Foundation 모델이나 GPT-2 백본을 사용하는 TimeLLM/CALF를 모바일 기기나 임베디드 Edge CPU 상에서 구동하는 것은 메모리 부족(OOM) 및 수 초 이상의 추론 지연을 유발하므로 5분 주기 실시간 예측 시스템에 배치가 불가능함.
- **개선 요구**: 실시간 Edge 추론단에서 거대한 Foundation 모델의 추론 연산을 배제하고 고성능을 보존하는 모델 경량화 우회 설계를 도입하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 클라이언트측 12시간 슬라이딩 링 버퍼 캐싱 (Client-Side Sliding Ring Buffer Cache)
- **수정 설계**: 실시간 API 호출 시의 3스텝 입력 한계를 극복하기 위해, 사용자의 단말 장치 로컬 메모리에 최신 12시간(144스텝)의 CGM 계측값을 상시 보존하는 **클라이언트측 슬라이딩 링 버퍼 캐시** 구조를 수립함.
- **구체적 구현**:
  - 모바일 앱 또는 디바이스 내부에서 5분마다 CGM 값이 갱신될 때마다 링 버퍼 캐시에 데이터를 밀어 넣고 가장 오래된 값을 탈락시킴.
  - 실시간 추론 API가 실행될 때, API 매개변수로 최신 3스텝만 전달하는 대신 로컬 캐시에서 추출한 12시간 시퀀스를 백엔드로 한 번에 전송하여 TimesFM 2.5가 필요한 12시간 컨텍스트 윈도우를 완벽히 충족시킴으로써 모델 인터페이스 규격을 정합함.

### 5.2 오프라인 앙상블 및 경량 LSTM 단독 배포 (Edge LSTM Deployment)
- **수정 설계**: 본 논문에서 "충분한 데이터가 있을 때 경량 LSTM이 TSFM을 압도한다"는 실증적 분석에 기반하여, Edge 디바이스에는 수억 개 규모의 Foundation 모델을 아예 탑재하지 않고 오직 **단일 경량 LSTM(Hidden Size = 32)**만을 단독 배포함.
- **구체적 구현**:
  - 클라우드 또는 고성능 서버 환경에서 대용량 TSFM(TimesFM 2.5)을 활용하여 생성한 다양한 가상 환자 혈당 시나리오 및 예측 곡선을 오프라인 교재(Distillation Targets)로 활용함.
  - 이 데이터셋을 바탕으로 32차원의 초경량 LSTM 모델을 사전에 완전 지도학습(Full-shot Supervised Training)하여 Edge 디바이스에 단독 탑재함.
  - 이를 통해 Edge 단말의 실시간 추론 연산 시간을 1ms 이하로 단축하고 메모리 점유율을 1MB 이하로 압축하여 연산 오버헤드를 완벽히 소멸시킴.
