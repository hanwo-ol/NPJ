# Literature Survey Review: TimePre: Bridging Accuracy, Efficiency, and Stability in Probabilistic Time-Series Forecasting

- **논문 제목**: TimePre: Bridging Accuracy, Efficiency, and Stability in Probabilistic Time-Series Forecasting
- **저자**: Lingyu Jiang et al. (Tohoku University / Texas A&M University / MIT / arXiv:2511.18539)
- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 확률적 시계열 예측(PTSF)은 다중 미래 경로를 예측하기 위해 확산 모델(TimeGrad)이나 흐름 모델(TempFlow) 등을 사용하지만, 실시간 추론 시 여러 번의 반복 샘플링 연산이 필요해 효율성이 떨어짐.
- 다중 선택 학습(MCL) 기반의 Winner-Takes-All(WTA) 손실 함수를 사용하면 오토레그레시브 RNN 대신 경량 다중 헤드 MLP 구조를 적용할 수 있어 연산이 빠르지만, 입력 변수 간의 크기 불균형이 존재하고 선형 레이어의 매니폴드 제약이 없으면 일부 예측 헤드만 지속 업데이트되고 나머지는 학습이 멈추는 가설 붕괴(Hypothesis Collapse) 문제가 발생함.

### 1.2 제안하는 방법론: TimePre
- **안정적 인스턴스 정규화 (Stabilized Instance Normalization, SIN)**:
  - 입력 시퀀스 데이터에서 양끝 극단값을 제외(Trimming)한 평균과 분산을 이용해 각 채널(변수)별 인스턴스 정규화를 수행하고, 예측 후 다시 원래 스케일로 가역 복원함.
  - 이를 통해 아웃라이어 및 비정상성 통계량 변화에도 강건한 정규화 출력을 제공하여 다중 헤드가 고르게 학습될 수 있는 평탄한 피처 공간을 유지함.
- **경량 Temporal Encoder & Multi-Hypothesis Decoder**:
  - 채널 독립형 단층 Linear 레이어로 temporal feature를 인코딩한 후, K개의 병렬 예측 헤드를 통해 서로 다른 예측 궤적들을 한 번의 순방향 연산(Non-autoregressive)으로 출력함.
  - 학습 시에는 최적 궤적(Winner) 이외의 헤드에도 최소한의 그래디언트를 흘려주는 완화된 WTA 손실 함수(Relaxed WTA)와 각 헤드의 예측 확률을 보정하는 신뢰도 손실 함수(Confidence Calibration Loss)를 함께 최적화함.

### 1.3 실험 결과
- Electricity, Exchange, Traffic 등 6개 공개 벤치마크 데이터셋에서 기존 몬테카를로 샘플링 기반 확률 모델 대비 최대 30% 이상의 왜곡 오차(Distortion) 및 CRPS-Sum 성능 향상을 보임.
- 배치당 추론 연산 시간을 0.03초 이내로 단축하여 연산 효율과 확률론적 표현력을 모두 입증함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **혈당 예측의 불확실성 모델링 및 스파이크성 아웃라이어로 인한 학습 왜곡**:
  - 당뇨 환자의 혈당 변화는 고탄수화물 식사나 고용량 인슐린 주입에 의해 단기적이고 급격한 스파이크 변동을 겪게 됨.
  - Stage 1의 단일 결정론적 모델은 이러한 식후 급상승(Hyperglycemia)이나 저혈당(Hypoglycemia) 위험 구간의 다중 경로 가능성을 포착하지 못하며, 이러한 임펄스성 스파이크 데이터(아웃라이어)가 학습 시 손실 함수를 왜곡시켜 전체 평균 오차 성능을 저하시키는 원인이 됨.

### 2.2 TimePre의 우리 연구 적용 방안 (Robust Non-sampling Multi-trajectory Prediction)
- **비역학적 다중 혈당 예측 경로 매핑**:
  - 혈당 예측 백본 출력단에 WTA 손실 함수 기반의 4개 디코드 헤드를 도입하여, 환자의 행동 불확실성에 따른 다중 혈당 궤적(예: 인슐린 흡수 지연에 따른 저혈당 지연 발생 경로 vs 즉각 회복 경로)을 몬테카를로 샘플링 없이 실시간(Non-autoregressive)으로 도출함.
  - 입력단에 trimmed 정규화 기법을 도입하여 식사/인슐린 주입에 의한 단기 스파이크값이 전체 정규화 통계량을 흔들지 않도록 제어함으로써, 기본 혈당 변동에 대한 베이스 모델의 견고함을 확보함.

## 3. 한계점

### 3.1 3-step Lookback (L=3, 15분 이력) 환경 하에서의 Trimmed 통계량 연산 불능
- L=3의 극소 윈도우 조건에서 양방향 Trimming 비율 $p \ge 1/3$을 적용할 경우, 정렬된 순서 통계량에서 $k = \lfloor 3p \rfloor = 1$이 되어 양쪽 끝의 2개 데이터를 제거하게 됨. 결과적으로 단 1개의 데이터만 남아 분산 계산 시 분모가 0이 되어 수치적인 나눗셈 에러(Zero Division)가 발생하고 정규화 통계량이 붕괴됨.

### 3.2 Edge CPU 상에서의 실시간 정렬(Sorting) 오버헤드
- SIN을 계산하기 위해서는 매 추론 시점마다 채널별로 입력 시퀀스를 정렬(Sorting)하는 연산이 요구됨. 5분마다 저전력 Edge 디바이스에서 다변량 채널 전체에 대해 실시간 정렬 연산을 가동하는 것은 정적 메모리 가속 컴파일러(TFLite 등)의 최적화 파이프라인을 방해하고 배터리 소모를 가속화하는 요인이 됨.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 극소 입력(L=3)에서의 분산 소멸 및 수치적 발산 경고
- **지적 사항**: $L=3$ 조건에서 Trimming 비율 $p$를 강제하면 유효 데이터 수가 극도로 부족해져 정규화 분산이 소멸하거나 NaN이 발생합니다. Trimming을 적용하지 않고 $L=3$에서 일반 InstanceNorm을 돌릴 경우, 식사나 인슐린 투입 직후의 스파이크 포인트 하나로 인해 전체 입력의 부호가 반전되어 예측 오류가 증폭됩니다.
- **개선 요구**: 극소 입력 시계열에서도 통계적 붕괴와 NaN 발생 없이 정상 스케일을 유지할 수 있는 안정 정규화 기법을 제시하십시오.

### 4.2 Edge 구동 시 정렬 연산 제거 및 가속화
- **지적 사항**: 모바일 단말에서 정적 텐서 그래프가 아닌 정렬(argsort 등) 연산자를 사용하는 것은 TFLite 빌드 시 컴파일 지원 대상에서 제외되거나 CPU fallback으로 동작하여 지연을 초래합니다.
- **개선 요구**: CPU 환경에서 dynamic sorting 연산 오버헤드 없이 아웃라이어를 강건하게 필터링할 수 있는 정적 수치 클리핑 기법을 고안하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 12시간 링 버퍼 기반의 통계량 연산 및 L=3 Reversible Scaling (12h Sliding Stats & L=3 Reverse Norm)
- **수정 설계**: 수치적 NaN 및 분산 소멸을 방지하기 위해, 정규화 통계량(평균, 분산)은 단말에서 지속 갱신되는 **12시간 링 버퍼(144 스텝)** 데이터를 기반으로 Trimmed 계산하고, 실제 예측 입력 및 복원은 최신 $L=3$ 포인트에 대해서만 수행합니다.
- **구체적 구현**:
  - 모바일 디바이스에 최근 144스텝(12시간)의 혈당 및 외생 변수를 저장하는 슬라이딩 링 버퍼를 구성합니다.
  - 144스텝 시퀀스를 정렬하여 상하위 10%씩 총 28개 데이터를 제거한 후 robust 평균 $\mu_r$과 표준편차 $\sigma_r$을 구합니다.
  - 실시간 입력되는 최신 3스텝 벡터 $X_{L=3}$에 대해 이 robust 통계량을 적용해 $\tilde{X}_{L=3} = (X_{L=3} - \mu_r)/\sigma_r$로 정규화하여 선형 모델에 투입하고, 출력단에서도 동일한 $\sigma_r, \mu_r$을 이용하여 가역 스케일 복원을 실행해 수치적 안정성을 100% 보장합니다.

### 5.2 정적 수치 클리핑 기반의 Outlier-Free Instance Normalization (Static Clipping & Sorting-Free SIN)
- **수정 설계**: 단말 CPU 상에서의 정렬 연산을 배제하기 위해, 수학적 Trimming 대신 생리학적 임계치를 활용한 **정적 수치 클리핑(Static Value Clipping)**을 선제 가동하고 정적 Instance Normalization을 수행합니다.
- **구체적 구현**:
  - 정렬 함수를 완전히 배제하고, 입력값들을 사전에 정의된 물리적 정상 범주로 클리핑합니다:
    $$x_{clipped} = \min(\max(x, V_{min}), V_{max})$$
    여기서 혈당 채널은 $[40, 400]$ mg/dL, 인슐린 채널은 $[0, 10]$ U 등으로 고정 클리핑합니다.
  - 클리핑된 $x_{clipped}$에 대해 정적 평균과 표준편차를 구해 정규화함으로써, 정렬 연산 없이도 급격한 오기록이나 이상값으로 인한 정규화 편향을 방지하고 $O(1)$의 연산 복잡도로 TFLite 가속 모드로 완전 변환합니다.
