# Literature Survey Review: STG-Mamba: Spatial-Temporal Graph Learning via Selective State Space Model

- **논문 제목**: STG-Mamba: Spatial-Temporal Graph Learning via Selective State Space Model
- **저자**: Lincan Li, Hanchen Wang, & Wenjie Zhang (University of New South Wales / arXiv:2403.12418)
- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

---

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 시공간 그래프(Spatial-Temporal Graph, STG) 데이터(교통 흐름, 날씨 센서망 등)는 공간적 의존성과 시간적 변동이 동시에 존재하는 복잡한 비유클리드 데이터임.
- 기존의 그래프 신경망(GNN) 기반 예측 모델들은 주로 노드 간의 공간적 정적 관계에만 치중하여, 시스템 전체의 시간 동역학적 변화(Temporal State Evolution)를 세밀하게 모델링하지 못함.
- Transformer 계열 시공간 모델들은 장기 의존성 파악에는 유리하지만 대규모 그래프에서 연산 복잡도가 이차($O(N^2)$)로 증가하여 심각한 리소스 병목을 유발함.

### 1.2 제안하는 방법론: STG-Mamba
- **Graph Selective State Space Block (GS3B)**:
  - STG 네트워크를 하나의 물리적 '계(System)'로 정의하고, Residual Encoder 구조 하에 GS3B 블록을 다중 적층함.
- **칼만 필터링 그래프 신경망 (Kalman Filtering Graph Neural Networks, KFGN)**:
  - 다중 시간 해상도 데이터(최근-r, 주기-p, 트렌드-q)를 각각 **DynamicFilter-GNN**에 통과시켜 각 시간 스케일별 동적 인접 행렬 $A_{dyn}$을 구함.
  - **KF-Upgrading (칼만 필터링 업그레이딩)**: 통계학적 칼만 필터 이론을 차용하여, 각 시간 스케일별 예측 스트림을 가우시안 분포로 모델링하고 학습셋의 분산 $\sigma^2$의 역수(신뢰도 $\omega = 1/\sigma^2$)를 가중치로 삼아 가중 평균 결합을 수행함 ($\hat{y}_{fuse} = \epsilon (\hat{y}_q \omega_q) + \phi (\hat{y}_p \omega_p) + \hat{y}_r \omega_r$). 이를 통해 노이즈와 데이터 불확실성을 최적으로 필터링함.
- **시공간 선택적 상태 공간 모듈 (Spatial-Temporal Selective State Space Module, ST-S3M)**:
  - **Graph Selective Scan Algorithm** 도입: DynamicFilter-GNN으로부터 도출된 시공간 그래프 구조 정보 $\alpha_t$를 Mamba의 이산화 단계에 행렬곱으로 결합함 ($\Delta' = \text{matmul}(\Delta^\star, \alpha_t)$).
  - 공간적 연결 강도가 시간 축의 전이 행렬 이산화 크기($\Delta$)를 조절하게 함으로써, 공간 정보가 시간적 맥락 선택 메커니즘에 직접 개입하도록 설계함.

### 1.3 실험 결과
- PeMS04(교통 흐름), HZMetro(지하철 유출입), KnowAir(중국 대기질) 3개 실세계 시공간 벤치마크 데이터에서 기존 GNN 및 Transformer 기반 SOTA 모델 대비 성능 우위를 입증함.
- 특히 연산 복잡도를 선형 $O(N)$으로 축소하여 Transformer 대비 FLOPs와 추론 속도를 비약적으로 개선함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **공간적 다기관(LODO) 변동과 시간적 동역학의 격리**:
  - 기존 2-Stage Residual 이종 도메인 전이학습 환경에서는 환자 간의 생리적 거리(공간적 관계)와 혈당의 실시간 추세(시간적 패턴)를 완전히 별개의 파이프라인으로 분리하여 처리했음.
  - 이로 인해 새로운 환자 도메인 전이 시 공간 정보(도메인 거리)가 모델 가중치 전이에 유기적으로 통합되지 못하고 오차 분산이 증가하는 구조적 한계를 보임.

### 2.2 STG-Mamba의 우리 연구 적용 방안 (STG-Mamba Integration)
- **도메인-시간 융합 그래프 Mamba 블록 구축**:
  - 여러 환자의 혈당 데이터를 노드로 정의하고, 이들 간의 MMD/CORAL 거리를 그래프 엣지로 삼는 시공간 혈당 시스템을 모델링함.
  - ST-S3M의 원리를 차용하여 환자 도메인 간의 거리가 시간 이산화 스텝 $\Delta$를 동적으로 스케일링하게 함으로써, 생리적 거리가 가까운 환자 도메인의 시간 전이 상태 가중치가 더 강하게 이산화 전이에 개입하도록 설계함.

## 3. 검증 및 실험 로드맵 제안

### 3.1 Baseline 비교군 설정
1. **LGBM + CORAL/TrAdaBoost**: 공간적 거리 정렬만 가한 정적 전이학습 모델.
2. **iTransformer (CD)**: 다변량 채널 간 어텐션만 수행하는 모델.
3. **STG-Mamba (Proposed)**: 도메인 거리 기반 $\Delta$ 제어가 결합된 Graph Selective Scan 모델.

### 3.2 핵심 평가 메트릭
- **LODO 전이 오차**: Target 도메인에서의 RMSE, MAE, MARD.
- **연산 복잡도**: CPU Inference Latency (ms).

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

본 섹션은 감시자 에이전트(인격 3)가 연구원 에이전트(인격 2)의 1차 설계 아티팩트를 검수하고 남긴 비판적 검토 의견입니다.

### 4.1 3-step Lookback ($L=3$) 제약 하에서의 다중 시간 스케일 분산 추정 및 Kalman 융합 불가
- **지적 사항**: STG-Mamba의 핵심 구성요소인 KFGN은 과거 12스텝 데이터로부터 최근, 주기(Period), 트렌드(Trend)의 3가지 데이터 스트림을 분리 생성하여 Kalman Upgrading을 진행합니다. 그러나 15분(3스텝) 룩백 환경에서는 입력 데이터 슬라이스 자체가 매우 짧아 일일 주기나 장기 트렌드 슬라이스를 물리적으로 분리할 수 없습니다. 또한 단 3스텝 표본으로부터 계산된 평균 $S$와 표준편차 $\sigma$는 통계적 표본 오차가 지나치게 커 Kalman 가중치 $\omega_c = 1/\sigma_c^2$를 완전히 왜곡시켜 융합 출력을 발산하게 만듭니다.
- **개선 요구**: 3스텝 룩백 조건에서도 Kalman 융합의 수치적 안정성을 확보하고 다중 시간적 유효 정보를 통합할 수 있는 수정 설계를 제시하십시오.

### 4.2 Graph Scan 단계의 행렬곱으로 인한 CPU 추론 Latency 지연
- **지적 사항**: ST-S3M은 그래프 인접 행렬 $\alpha_t$와 $\Delta^\star$ 간의 행렬곱($\text{matmul}$)을 매 타임스텝의 스캔 과정에서 수행합니다. 이 구조는 GPU 환경에서는 커널 융합을 통해 고속 처리되지만, CPU 전용 환경에서는 루프 당 다차원 정렬 및 패딩 연산이 추가되어 연산 지연(Inference Latency)이 극대화됩니다. 환자 수 $N$이나 채널 수 $C$가 증가함에 따라 CPU에서의 실시간 다단계 예측 시 심각한 연산 병목을 유발합니다.
- **개선 요구**: CPU 가용 리소스 제약 하에서 그래프 정보 전이 시의 행렬곱 연산 오버헤드를 제어할 수 있는 경량화 우회안을 설계하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

본 섹션은 수정자 에이전트(인격 4)가 감시자의 지적 사항을 분석하여 수립한 최종 보완 설계안입니다.

### 5.1 오프라인 글로벌 통계 기반 정적 칼만 가중치 도입 (Static Variance-Weighting & Cache Injection)
- **수정 설계**: 3스텝 룩백 내에서의 무리한 분산 추정을 배제하고, 오프라인으로 사전 산출된 **전체 데이터셋 분산 가중치**와 **클라이언트 캐시 주기 슬라이스**를 활용하여 칼만 업그레이딩을 우회 적용합니다.
- **구체적 구현**:
  - 학습 단계 전체 데이터로부터 사전 집계된 최근, 일일 주기, 주간 트렌드 잔차의 모집단 분산 값($\sigma^2_{r,pop}$, $\sigma^2_{p,pop}$, $\sigma^2_{q,pop}$)을 구하고 이를 동결한 상수 가중치 $\omega_r, \omega_p, \omega_q$를 사용합니다.
  - 주기(Period) 및 트렌드(Trend) 입력을 실시간 3스텝 시퀀스로부터 구하지 않고, 단말 메모리 캐시에 상시 누적 보관된 '어제 동일 시간 혈당' 및 '지난주 동일 시간 혈당'의 3스텝 값을 가져와 주입합니다.
  - 이를 통해 3스텝 룩백 제한을 완벽히 극복하고 노이즈가 제거된 최적의 칼만 융합 값을 CPU 상에서 안전하게 산출합니다.

### 5.2 정적 대칭 인접 그래프 기반 Delta 필터링 (Static Matrix Delta Modulation)
- **수정 설계**: 매 스캔 루프에서 발생하는 동적 그래프 행렬곱을 우회하기 위해, **오프라인으로 정합된 정적 인접 행렬**을 사용하여 이산화 단계를 정적 선형 연산으로 변환합니다.
- **구체적 구현**:
  - 환자 간의 거리(MMD) 또는 다변량 변수 간의 물리적 지연 상관관계를 오프라인에서 사전 계산하여 고정된 정적 인접 그래프 행렬 $\alpha_{static}$을 도출합니다.
  - 실시간 추론 시에는 매 스텝마다 DynamicFilter-GNN과 matmul을 실행하는 대신, 오프라인에서 학습된 정적 $\alpha_{static}$ 가중치를 각 채널의 $\Delta^\star$에 사전 곱연산(Pre-multiplication)하여 고정한 뒤 단일 Selective Scan 루프로 통과시킵니다.
  - 이를 통해 스캔 루프 내부의 행렬곱 연산 비용을 전면 소멸시키고 단 1회의 선형 매핑만 수행하여 CPU 추론 속도를 80% 이상 단축합니다.
