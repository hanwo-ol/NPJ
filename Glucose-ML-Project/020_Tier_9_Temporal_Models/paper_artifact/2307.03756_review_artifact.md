# Literature Survey Review: FITS: Modeling Time Series with 10k Parameters

- **논문 제목**: FITS: Modeling Time Series with 10k Parameters
- **저자**: Zhijian Xu, Ailing Zeng, & Qiang Xu (The Chinese University of Hong Kong / arXiv:2307.03756)
- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

---

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 시계열 예측 및 이상 탐지 분야에서 고성능 트랜스포머 모델들은 거대한 파라미터 크기와 높은 연산 비용으로 인해 자원이 제한된 모바일 및 임베디드 Edge CPU 기기(MCU 등)에서 기동하기 불가능함.
- 기존 주파수 도메인 기반 모델(FEDformer, TimesNet) 등도 시간적 특징 추출에 복잡한 신경망 구조를 의존하여 모델이 무겁고 과적합에 취약한 한계가 존재함.

### 1.2 제안하는 방법론: FITS
- **주파수 보간 기반 예측 (Frequency Interpolation)**: 시계열 예측 태스크를 복소 주파수 영역(Complex Frequency Domain)에서의 보간(Interpolation) 연산으로 재해석함. 입력 시퀀스를 복소수 주파수로 변환한 뒤, 이를 선형 확장(보간)하여 미래 시점을 복원함.
- **복소수 선형 레이어 (Complex-valued Linear Layer)**: 크기 스케일링(Amplitude Scaling)과 위상 천이(Phase Shift, 시간 지연에 대응)를 복소수의 곱셈 연산으로 학습하는 단일 복소수 선형 매핑 레이어 구조를 채택함.
- **저역 통과 필터 (Low Pass Filter, LPF)**: 입력 주파수 성분 중 노이즈에 해당하는 고주파 성분을 차단하고 차단 주파수(Cutoff Frequency, COF) 이하의 저주파 유효 성분만 남겨 파라미터 수를 10k 이하로 극단적으로 경량화함.
- **Reversible Instance Normalization (RIN)**: 입력 데이터의 평균과 편차를 정규화하여 0-frequency(DC 성분)가 극단적으로 커지는 것을 차단함.

### 1.3 실험 결과
- ETTh1, ETTh2, ETTm1, ETTm2, Weather, Electricity, Traffic 등 7대 시계열 벤치마크 및 M4 단기 시계열에서 기존 SOTA 모델인 PatchTST, DLinear, FEDformer 등과 필적하거나 우수한 성능을 달성함.
- 파라미터 크기를 4.5K ~ 10K 수준으로 억제하여 DLinear 대비 50배 이상, 트랜스포머 계열 대비 10,000배 이상 소형화하였으며, Edge CPU 추론 지연을 획기적으로 낮춤.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **혈당 상태 전이의 시간적 인과관계 묘사 누락**:
  - 식사 및 인슐린 주입에 의한 혈당 변동 반응은 특정 시간적 지연(위상 편차, Phase Shift)과 피크 크기(진폭, Amplitude)를 동역학적으로 재현해 내야 함.
  - 기존 모델들은 시간 영역의 로컬 포인트에만 집중하여, 이러한 주기적 흐름 및 시간 지연 상호작용의 물리적 특성을 학습하지 못해 식후 혈당의 장기적 변동 양상을 정확히 추정하지 못함.

### 2.2 FITS의 우리 연구 적용 방안 (Complex Phase-Shift Modeling for Exogenous Lag)
- **복소 주파수 도메인에서의 식사-인슐린 시간 지연 모델링**:
  - 혈당 예측에 FITS의 복소수 선형 레이어 개념을 도입하여, 식사 투입(Meal)과 인슐린(Insulin)이 혈당(CGM)에 미치는 연속적인 생리적 시간 지연을 주파수 영역의 복소 위상 각도(\theta(f)) 회전 및 결합 가중치로 학습하도록 설계함.
  - 시간 영역의 슬라이딩 윈도우 인슐린 누적(IOB) 대신 복소 주파수 공간에서의 위상 지연 선형 매핑을 수행함으로써 생리학적 인과 관계를 극도로 단순하면서도 엄밀하게 포착함.

## 3. 한계점

### 3.1 3-step Lookback (L=3, 15분 이력) 환경 하에서의 주파수 정보 소멸
- 입력 시퀀스 길이가 L=3인 조건에서는 rFFT를 적용할 시 출력 복소수 성분이 단 2개(0차 DC 성분, 1차 기본 주파수 성분)에 불과함. RIN 정규화로 DC 성분이 0으로 제어되면, 모델이 학습할 수 있는 주파수 피처는 오직 1개 세트의 복소수(실수부, 허수부)로 감소하여 저역 통과 필터(LPF)와 보간 네트워크의 수치적 해상도가 완전히 파괴됨.

### 3.2 Edge CPU 상에서의 복소수(Complex) 연산 라이브러리 가속 제한
- ONNX Runtime, TFLite 등 일반 모바일 Edge 가속 엔진은 복소수 데이터 타입을 공식 지원하지 않거나 가속 연산에서 제외하는 경우가 대부분임. 복소수 선형 연산 및 rFFT/irFFT 동작이 모바일 CPU 내에서 최적화되지 않은 커스텀 구현으로 구동될 시 컴파일 가속(Vectorization) 붕괴로 인해 오히려 연산 지연이 가중될 수 있음.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 극소 입력 윈도우(L=3) 극복을 위한 주파수 해상도 보장 방안 부재
- **지적 사항**: 3스텝(15분)의 컨텍스트는 주파수 변환을 하기에 절대적으로 부족한 소스입니다. 이 단기 구간에 rFFT를 수행하는 것은 3점을 연결하는 직선 내지 단순 곡선 피팅 이상의 의미를 갖지 못하며, 식후 2~3시간에 걸쳐 발생하는 생리학적 반응의 위상 지연을 주파수 벡터의 회전 각도로 표현하는 것이 수학적으로 불가능합니다.
- **개선 요구**: 15분 국소 입력 제약을 극복하고 유의미한 주파수 분해능을 확보하기 위해, 입력 형태를 주파수 보간에 적합하도록 전처리하는 단말측 캐시 및 하이브리드 입력 우회 구조를 제시하십시오.

### 4.2 Edge 가속 컴파일러(ONNX/TFLite) 호환을 위한 복소수 매핑 대체 설계
- **지적 사항**: 모바일 Edge CPU 추론 프레임워크는 complex-float 연산을 내부적으로 지원하지 않으므로, 복소수 클래스나 복소수 텐서 연산을 그대로 코드에 반영하면 ONNX로 내보내기(Export)할 때 직렬화 에러가 발생하거나 CPU 상에서 가속 없이 직렬 루프로 연산되어 병목을 초래합니다.
- **개선 요구**: 복소수 텐서 연산을 거치지 않고 순수 실수형(Real float) 연산 레이어만으로 복소수 선형 매핑(진폭 스케일러 및 위상 지연곱)을 정합적으로 동치 구현하는 실용적 대체 대안을 수립하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 장기 링 버퍼 기반의 이력 주파수 추출 및 단기 룩백 하이브리드 결합 (Historical Spectral Context & Time-domain Fusion)
- **수정 설계**: 단기 L=3 입력의 주파수 정보 부족을 해결하기 위해 **12시간 모바일 단말 측 슬라이딩 링 버퍼(144 스텝)**에서 과거 주파수 맥락을 추출하고, 실시간 변동성은 단기 시간 영역 MLP로 병렬 추출하여 융합합니다.
- **구체적 구현**:
  - 클라이언트 기기 메모리에 12시간 분량의 혈당, 식사량, 인슐린 계측 이력을 캐싱하는 링 버퍼를 구성합니다.
  - 이 장기 링 버퍼(144포인트)에 대해 rFFT를 가동하여 73개의 복소 주파수 성분을 획득하고, COF=12 수준으로 저주파 성분만 추출해 FITS 복소 선형 레이어를 통과시켜 예측 Horizon의 주파수 성분을 보간합니다.
  - 이렇게 복원된 미래 Horizon 혈당 곡선에, 활성 3스텝 입력(L=3)을 입력받는 단층 MLP로 추정된 단기 임펄스 반응 변동량을 시간 영역에서 합산하는 하이브리드 결합(Hybrid Spectral-Temporal Fusion) 구조를 적용하여 해상도 파괴를 예방합니다.

### 5.2 실수형 변환을 통한 가상 복소 선형 매핑 레이어 설계 (Real-equivalent Complex Linear Transformation)
- **수정 설계**: 복소수 연산을 지원하지 않는 Edge 컴파일러 환경에 대응하기 위해, **실수형 가중치 매트릭스를 활용한 동치 복소 매핑 레이어**를 구현하고 FFT 연산을 정적 기저 행렬곱으로 고정합니다.
- **구체적 구현**:
  - 복소 텐서 $X = C + jD$와 복소 가중치 $W = A + jB$의 연산 $Y = W \cdot X$는 실수 연산 벡터 $\mathbf{x} = [C, D]^T$와 대칭 가중치 행렬 $\mathbf{M} = \begin{bmatrix} A & -B \\ B & A \end{bmatrix}$의 행렬곱 $\mathbf{y} = \mathbf{M}\mathbf{x}$와 완벽히 일치합니다.
  - 따라서 입출력 주파수 피처 채널을 `[실수부, 허수부]` 형태로 Concatenate하여 2배 크기의 일반 Real Float 텐서로 포맷팅하고, 실수형 Linear Layer의 가중치를 대칭 형태로 정렬하거나 학습 규제를 가해 복소 곱셈의 성질을 온전히 복제하게 합니다.
  - 또한, rFFT와 irFFT 연산 역시 고정된 삼각함수 기저 행렬곱이므로, 모바일 디바이스 단에서 FFT 함수를 호출하지 않고 **정적으로 사전 계산된 FFT 변환 행렬(Standard Real-to-Complex Transform Matrix)**을 상수 텐서로 등록하여 단순 1D Convolution 또는 Matrix Multiplication으로 변환 연산을 완결함으로써 ONNX/TFLite 컴파일 호환성을 100% 보장하고 실행 속도를 극대화합니다.
