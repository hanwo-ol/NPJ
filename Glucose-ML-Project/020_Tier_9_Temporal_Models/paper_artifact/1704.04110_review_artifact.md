# Literature Survey Review: DeepAR: Probabilistic Forecasting with Autoregressive Recurrent Networks

- **논문 제목**: DEEPAR: PROBABILISTIC FORECASTING WITH AUTOREGRESSIVE RECURRENT NETWORKS
- **저자**: David Salinas, Valentin Flunkert, Jan Gasthaus (Amazon Research / International Journal of Forecasting 2020)
- **분석 시점**: 2026-06-10
- **리뷰어**: 인격 2 (연구원 에이전트)

---

## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 전통적인 시계열 예측 방법론(ARIMA, Exponential Smoothing 등)은 단일 시계열 또는 소규모 그룹에만 적용 가능하며, 대규모 시계열 데이터셋(수천~수백만 개)에서 유사 시계열 간의 공유된 패턴(Shared patterns)을 학습하는 전역 모델(Global model)을 구축하기 어려움.
- 실제 비즈니스 의사결정(수요 예측 등)에서는 미래의 점 예측(Point forecast)뿐만 아니라 불확실성을 포함하는 calibrated 확률 분포(Probabilistic forecast)를 도출하는 것이 중요함.
- 대규모 시계열 데이터셋은 각 시계열의 크기(Scale/Magnitude)가 멱함수 법칙(Power-law)에 의해 수십~수백 배씩 차이가 나기 때문에, 일반적인 신경망은 데이터 Normalization 및 가중치 업데이트 시 저수위(Low-velocity) 및 고수위(High-velocity) 시계열 간의 편향으로 인해 성능이 저하됨.

### 1.2 제안하는 방법론: DeepAR
- **Autoregressive Recurrent Network 아키텍처**:
  - LSTM 셀 기반의 다층 순환 신경망(RNN) 구조를 백본으로 사용함.
  - 각 시점 $t$에서 외생 변수(Covariates) $x_{i,t}$, 직전 시점의 실제 관측값 $z_{i,t-1}$, 그리고 이전 hidden state $h_{i,t-1}$를 입력받아 새로운 hidden state $h_{i,t}$를 생성함.
- **파라미터화된 Likelihood 출력**:
  - 네트워크가 타겟 값을 직접 예측하는 대신, 예측하고자 하는 분포의 파라미터 $\theta$(예: 가우시안 Likelihood의 평균 $\mu$와 표준편차 $\sigma$, 또는 카운트 데이터를 위한 음이항 Likelihood의 평균 $\mu$와 형상 파라미터 $\alpha$)를 출력하도록 구성함.
  - 미래의 예측 구간에 대해서는 몬테카를로 조상 샘플링(Ancestral Sampling) 루프를 통해 미래 경로(Sample traces)들을 반복 생성함으로써 최종 확률 분포와 Quantiles를 계산함.
- **크기 핸들링(Scale Handling) 기법**:
  - 각 시계열별 스케일 인자 $\nu_i$(예: 과거 이력의 평균값)를 정의하고, 입력 변수 $z_{i,t-1}$를 $\nu_i$로 나누어 네트워크에 주입하며, 출력되는 확률 분포의 평균 $\mu$에 다시 $\nu_i$를 곱하여 복원함.
  - 미니배치 샘플링 시 각 시계열이 선택될 확률을 스케일 $\nu_i$에 비례하도록 설정하여 대규모 고매출 아이템에 대한 과소적합을 예방함.

### 1.3 실험 결과
- Amazon 실측 판매 데이터(parts, ec) 및 공공 데이터셋(electricity, traffic) 평가에서 대표적인 통계 모델(ISSM, ETS, Croston) 및 일반 RNN 구조 대비 약 15%의 확률적 예측 오차(Quantile Loss/Risk) 개선 효과를 입증함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **개인별 생리적 변동 폭 차이에 따른 스케일 왜곡 및 불확실성 무시**:
  - 당뇨 환자마다 인슐린 저항성이나 섭취 식사량의 절댓값 스케일이 극도로 다르기 때문에, 고정된 단일 에뮬레이터 모형은 baseline 혈당 수치가 높거나 인슐린 민감도가 매우 낮은 특정 환자군에서 예측 값이 붕괴되는 한계를 가짐.
  - 또한, 식후 인슐린 투여 후 저혈당 위험도를 판단하기 위해서는 단순히 30분 뒤의 점 예측 혈당뿐만 아니라, 하방 10% 신뢰선(p10 quantile)이 저혈당 기준치(70mg/dL)를 침범할 확률적 리스크를 계산해야 함.
  - DeepAR의 스케일 핸들링($\nu_i$) 및 Likelihood 파라미터 출력 구조를 결합하면, 각 환자의 fasting glucose 수준에 맞게 입출력을 동적 스케일링하고 하방 10th 및 상방 90th percentile의 예측 경로들을 몬테카를로 기법으로 도출하여 임상적 안전 범위를 확보할 수 있음.

### 2.2 DeepAR의 우리 연구 적용 방안 (Patient-Specific Scaled Probabilistic Emulator & Quantile Regression Decoder)
- **환자별 스케일 정규화 융합**:
  - 환자 $i$의 fasting glucose 또는 최근 12시간 평균 혈당 수치를 스케일 인자 $\nu_i$로 정의함.
  - CGM 입력 값 $z_{t-1}$을 $\nu_i$로 나누어 유닛 영역으로 변환 주입하고, 모델의 출력 분포 평균에 다시 $\nu_i$를 결합하는 환자별 스케일 핸들링을 혈당 에뮬레이터에 내장함.
- **온디바이스 확률적 저혈당 가드**:
  - 에뮬레이터의 출력 헤드에 평균/분산을 출력하는 Gaussian Likelihood 헤드를 적용하여 5분 단위 추론 시 미래 60분 간의 혈당 궤적을 100회 조상 샘플링함.
  - 샘플링된 궤적들 중 p10 quantile 곡선이 70mg/dL 이하로 하락하는 시점을 계산하여 저혈당 사전 알람을 울리는 온디바이스 가드 시스템을 구축함.

## 3. 한계점

### 3.1 3-step Lookback (L=3, 15분 이력) 환경 하에서의 LSTM 순환 상태 초기화 붕괴
- $L=3$ (15분)의 극도로 짧은 룩백 제약 하에서는 LSTM 셀의 순환 상태 $h_{i,t-1}$가 장기 대사 패턴(예: 과거 4시간 전 식사 효과)을 전파할 수 없음.
- 룩백 시퀀스가 3스텝에 불과할 때 LSTM에 direct 주입하면 순환망 고유의 문맥 유지 능력이 무력화되고 일반 MLP와 유사하게 축소됨.

### 3.2 몬테카를로 조상 샘플링 루프의 모바일 CPU 연산 병목 및 지연
- DeepAR의 특징인 Autoregressive Ancestral Sampling은 미래 $h$스텝을 예측하기 위해 매 예측 시점마다 $h$번의 RNN 순방향 연산과 난수 추출을 반복해야 함.
- 100개의 예측 궤적을 만들기 위해 이 작업을 100회 반복하면 모바일 ARM CPU 환경에서 극심한 추론 지연과 전력 소모를 야기하여 실시간 모니터링 환경에 부적합함.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 L=3 환경 하의 컨텍스트 소실 해결 요구
- **지적 사항**: 3스텝 룩백 조건에서는 LSTM의 초기 hidden state $h_0$가 환자의 최근 안정 상태(Warm-up)를 대변하지 못해, 식후 2시간 혈당 예측 시 상태 추정이 틀어집니다.
- **개선 요구**: 실시간 단말 상에서 과거 12시간 이력을 누적하는 링 버퍼를 구현하고, 추론 시점 직전까지의 이력 시퀀스(최소 36스텝 이상)를 LSTM 인코더 브랜치에 통과시켜 warm-up된 hidden state $h_{t_0-1}$를 얻은 뒤, 이를 예측 시점의 디코더 은닉 상태 초기치로 제공하십시오.

### 4.2 Autoregressive 몬테카를로 샘플링 병목 완화 요구
- **지적 사항**: 모바일 단말 CPU에서 100회 이상의 다중 궤적 오토레그레시브 샘플링 루프를 매 5분마다 계산하는 것은 불가능합니다.
- **개선 요구**: 실시간 온디바이스 추론 시에는 Autoregressive sampling 루프를 배제하고, LSTM 인코더의 마지막 상태 $h_{t_0-1}$로부터 향후 12스텝(1시간) 전체의 target quantiles(p10, p50, p90)를 단 한 번의 Feedforward pass로 다중 헤드 출력하는 Non-autoregressive Quantile Regression Head 구조를 사용하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 12시간 단말 링 버퍼 기반의 LSTM State Warm-up 및 Patient Scale Normalization (12h Buffering State Warm-up)
- **수정 설계**: 단말 상의 **12시간 링 버퍼(144 스텝)** 데이터를 활용해 환자별 스케일 인자 $\nu_i = \text{mean}(z_{1:144})$를 실시간 갱신하고, 예측 시점 직전 2시간 분량(24스텝)의 스케일 정규화된 혈당 시퀀스를 LSTM에 사전 주입하여 은닉 상태를 충분히 정렬(Warm-up)한 뒤, 최신 **L=3** 구간 정보와 결합하여 최종 상태를 활성화합니다.
- **구체적 구현**:
  - 모바일 단말 메모리에서 최근 24스텝 CGM 데이터를 로드하여 $z'_{t} = z_{t} / \nu_i$로 정규화한 뒤, 인코더 LSTM 셀을 순방향 통과시켜 context vector $h_{warmup}$을 생성합니다.
  - 이 은닉 상태와 $\nu_i$ 스케일 융합 피처를 디코더 레이어에 전달합니다.

### 5.2 Non-autoregressive Quantile Regression Head 및 TFLite INT8 Quantization (Non-autoregressive Quantiles & TFLite Quant)
- **수정 설계**: 다중 샘플링 루프를 전면 제거하고, LSTM 디코더 위에 12스텝 미래 출력을 직접 매핑하는 **Non-autoregressive Quantile Head**를 탑재하여 p10, p50, p90 세 가닥의 Quantile 곡선을 단일 연산으로 동시 출력하며, 모바일 배포용으로 모델 가중치를 TFLite INT8 양자화 컴파일합니다.
- **구체적 구현**:
  - 출력 레이어를 `nn.Linear(hidden_dim, 12 * 3)` 구조로 정의하여 미래 1시간 구간의 p10, p50, p90 값을 한 번에 획득하며, 손실 함수는 확률적 Quantile Loss의 총합으로 사전 학습합니다.
  - 학습된 PyTorch 가중치를 ONNX를 거쳐 TFLite로 변환하고 INT8 양자화를 적용함으로써 추론 레이턴시를 1밀리초 이하로 극소화하여 ARM CPU의 연산 자원을 절약합니다.
