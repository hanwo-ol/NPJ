## 1. 논문 핵심 요약

### 1.1 해결하고자 하는 문제
- 전통적인 시계열 예측 모형은 수치 영역(Continuous domain)에서 손실 함수를 최소화하도록 설계되어, 비선형적인 다중 분포나 급격한 임펄스성 노이즈를 매끄럽게 모사하지 못하는 한계가 있었음.
- 시계열 데이터를 텍스트 토큰으로 프롬프팅하는 LLM 기반 모델들은 높은 계산 복잡도와 정밀도 유실 문제를 겪고 있었으며, 시계열에 직접 대응하는 도메인 제로샷 모형 설계가 요구됨.

### 1.2 제안하는 방법론: Chronos
- **회귀를 분류로 변환 (Regression via Classification)**:
  - 입력 시계열 수치 데이터를 스케일링한 후, 고정된 $B$개의 균등 빈(Uniform Bins)으로 양자화(Quantization)하여 이산적인 토큰 ID 시퀀스로 변환함.
  - vocabulary 크기는 양자화 빈 수 $B$ (기본값 256)에 특별 토큰 `PAD`와 `EOS`를 추가한 형태로 설정됨.
- **기존 LM 아키텍처 재사용**:
  - 모델 구조를 임의로 변경하지 않고 기존 T5 아키텍처(20M부터 710M 파라미터)의 입출력 임베딩 차원만 시계열 vocabulary 크기(B+2)로 재조정하여 활용함.
  - 양자화된 토큰 시퀀스에 대해 다중 클래스 교차 엔트로피(Cross-Entropy) 손실 함수를 사용하여 학습을 수행함.
- **스케일링 기법 (Mean Scaling)**:
  - 각 시퀀스의 이력 컨텍스트 내 절댓값 평균값 $s = \frac{1}{C} \sum_{i=1}^C |x_i|$을 구하여 수치를 정규화하고, 예측 후에는 이를 역으로 곱해 실측 스케일로 복원함.
- **확률적 샘플링 예측**:
  - 출력단에서 다중 분류 확률 분포로부터 다음 토큰을 오토레그레시브하게 반복 샘플링하여, 여러 개의 궤적(Trajectories)을 도출함으로써 불확실성을 포함하는 확률적 예측 분포를 구성함.
- **학습용 합성 데이터 증강 (KernelSynth & TSMixup)**:
  - 가우시안 프로세스 커널을 임의 조합하여 다양한 주기와 트렌드를 가진 합성 데이터를 대량 생성하고, 실제 시계열 간 볼록 결합(Mixup)을 통해 데이터 다양성을 강화함.

### 1.3 실험 결과
- 42개의 서로 다른 도메인 시계열 데이터셋 벤치마크에서 기존의 지도 학습 기반 딥러닝 모델(PatchTST, TFT) 및 통계 패키지 대비 뛰어난 제로샷 예측 정확도와 분포 일관성을 입증함.

## 2. Glucose-ML 프로젝트(Stage 1) 잔여 한계와의 매핑

### 2.1 Stage 1의 핵심 한계
- **비선형 다중 혈당 궤적 모델링 부재**:
  - 당뇨 환자의 식사 시간 및 운동 여부에 따라 동일한 초기 혈당값에서도 급상승 또는 급강하의 상이한 다중 분포가 나타날 수 있음.
  - Stage 1의 평균 손실 기반 회귀 모델들은 이러한 다중 분포의 평균값만을 예측하여 저혈당/고혈당 위험을 과소평가함.

### 2.2 Chronos의 우리 연구 적용 방안 (Dequantized Probabilistic Sample Trajectory)
- **혈당 양자화 분포 인코더 도입**:
  - 수치 기반 회귀 대신 혈당 수치를 1mg/dL 또는 5mg/dL 단위 빈으로 양자화하여 Chronos 스타일의 이산 분류 분포를 추정함.
  - 다중 분류 헤드로부터 다변량 샘플링 궤적들을 수십 회 도출하여 최악의 케이스(저혈당/고혈당 위험 확률)를 백분위수 구간으로 예측 범위로 시각화함.

## 4. 감시자 검수 및 리뷰 피드백 (인격 3)

### 4.1 3-step Lookback ($L=3$) 환경 하에서의 국소 스케일링 왜곡 및 컨텍스트 부재
- **지적 사항**: Chronos는 Mean Scaling 계수 $s$를 입력 컨텍스트의 평균치로 계산합니다. 하지만 $L=3$ (15분 이력) 환경에서는 스케일 인자가 단 3개의 최근 혈당값에 의존하므로, 환자의 장기적인 혈당 기저 대사나 전반적인 일일 혈당 변동 범위(예: 80~250 mg/dL)를 반영하지 못하고 현재 극도로 왜곡된 국소 스케일로 압착됩니다. 또한, T5 모델이 단 3개의 토큰만 보고 미래 토큰을 생성할 경우, 시계열의 장기 트렌드나 상승/하강 속도를 인식할 수 있는 주의집중 연결(Contextual Attention)이 생략되어 오토레그레시브 생성 시 무작위 확률적 랜덤 워크(Flat Line or Random Fluctuation)가 생성되어 오차가 심각하게 누적되는 현상이 발생합니다.
- **개선 요구**: 15분 국소 윈도우 조건에서도 스케일 왜곡을 차단하고 컨텍스트를 주입할 수 있는 스케일링 인자 보정안을 제시하십시오.

### 4.2 Edge CPU 환경 하에서의 다회차 Autoregressive 디코딩 Latency
- **지적 사항**: Chronos는 다음 5분 단위 예측을 위해 토큰을 생성하고, 이를 다시 입력으로 피드백하여 다음 토큰을 생성하는 오토레그레시브 구조입니다. 60분 예측(12스텝)을 하려면 T5 모델의 Forward Pass를 12회 순차적으로 실행해야 합니다. 특히 확률 분포 측정을 위해 100개의 궤적 샘플을 구하려면 12 * 100 = 1,200회 연산이 필요합니다. 이는 모바일 Edge CPU 환경에서 수 초 이상의 실행 지연을 발생시켜 백그라운드 실시간 감시 시스템의 제한 리소스를 초과하게 됩니다.
- **개선 요구**: 실시간 Edge 단말에서 확률적 궤적을 획득하는 데 요구되는 디코딩 연산 오버헤드 감축 우회안을 마련하십시오.

## 5. 수정 및 보완 설계안 (인격 4)

### 5.1 장기 이동 평균 스케일러 및 메타 토큰 인젝션 (Long-Term Moving Scale & Meta Token Injection)
- **수정 설계**: 국소 스케일링 왜곡과 컨텍스트 부재를 해결하기 위해, **사용자 기저 이동 평균 스케일러**를 적용하고 입력 시퀀스 앞단에 **오프라인 메타 컨텍스트 토큰**을 삽입합니다.
- **구체적 구현**:
  - 스케일링 인자 $s$를 실시간 3스텝이 아닌, 과거 24시간 혈당 절댓값 평균 $s_{day} = \frac{1}{288} \sum_{i=1}^{288} |x_i|$로 변경 고정하여 환자의 고유 대사 스케일을 보존합니다.
  - $L=3$ 입력 토큰 앞단에 오프라인으로 사전 계산된 장기 변동 지표(예: 일일 표준편차, 최저/최고 혈당 차이 등)를 나타내는 4개의 '메타 토큰'을 인위적으로 주입하여 `[Meta_SD, Meta_MinMax, Glucose_t-2, Glucose_t-1, Glucose_t]` 형태로 토큰 시퀀스를 구성합니다. 이를 통해 T5 인코더-디코더가 환자의 기저 상태를 파악한 상태에서 3스텝의 실시간 변동을 예측하도록 설계합니다.

### 5.2 단일 패스 확률적 예측 및 MLP 로짓 증류 (Single-Pass Probabilistic Forecasting & MLP Logit Distillation)
- **수정 설계**: Edge CPU에서의 연산 폭발을 제어하기 위해, **Non-autoregressive Direct Head**로 모델을 전환하거나, **MLP 기반 다단계 양자화 모델로 증류**를 수행합니다.
- **구체적 구현**:
  - T5 디코더의 오토레그레시브 구성을 전면 제거하고, 인코더 최종 Layer에 예측 Horizon 길이(12스텝) 크기의 다층 출력 선형 레이어들(Linear Heads)을 병렬로 연결하여 단 한 번의 Forward Pass로 미래 12스텝의 양자화 확률 분포 매트릭스($12 \times 256$)를 동시에 출력하는 Non-autoregressive 구조로 변환합니다.
  - 혹은, Chronos가 출력한 12스텝의 소프트맥스 로짓 값을 모바일용으로 설계된 초경량 MLP 학생 모델(예: 3-layer MLP, 200KB 이하)에 지식 증류하여 단말에서는 오직 CPU 텐서 연산 1회만으로 양자화 확률 분포를 직접 획득할 수 있도록 구현합니다.
