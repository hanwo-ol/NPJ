# 4. 방법론 (Methodology)

## 일반적인 설정 (General setup)
이 시나리오는 생명 보험 포트폴리오를 나타내는 국가의 데이터 세트(K개)가 수집된 상황을 고려합니다. 여기서 목표는 노출 대비 사망자 수를 추정하는 것입니다. 그러나 내부 데이터가 부족하여 특정 타겟 국가(영국)에 대한 사망률을 직접 추정하기는 어렵습니다. 하지만 타겟 국가를 포함한 여러 국가의 외부 사망률 데이터에는 접근할 수 있습니다. 전이 학습 프레임워크는 사전 훈련된 글로벌 모델에서 출발하여 합성 데이터 세트를 기반으로 타겟 국가에 대한 세분화된 사망률 예측을 제공합니다.

## 사전 훈련 모델 (Pretrained model)
우리는 포아송(Poisson) 분포 가정을 기반으로 음의 포아송 로그 우도(negative Poisson log-likelihood) 함수를 사용하여 위험 예측 모델(GBM)을 피팅합니다. 타겟 국가를 고려하지 않은 상태에서 소스 국가들의 데이터를 사용해 벤치마크 글로벌 모델을 개발합니다. 이후 타겟 인구와 소스 인구 간의 외부 데이터 유사성을 활용하여 타겟 국가에 대한 합성 포트폴리오 데이터를 생성합니다.

## 국가 유사성 지수 (Country similarity index)
목표 국가가 소스 국가들과 얼마나 유사한지 측정하기 위해 외부 보험 및 사망률 데이터를 기반으로 '국가 유사성 지수'를 생성합니다. 생명 보험, 의료 통계, 전체 사망률을 나타내는 Q개의 항목에 대해 각 국가 간의 거리를 맨해튼(Manhattan) 거리 측정법으로 계산합니다. 이후 지수 함수를 통해 거리를 유사성 점수로 변환하여 비교를 가능하게 합니다.

## 타겟 국가를 위한 합성 데이터 세트 (Synthetic portfolio data for target country)
사망률 데이터가 전혀 없는 국가의 경우 합성 데이터 생성이 효율적인 솔루션을 제공합니다. 연령 및 성별 분포를 가정하고 유사성 점수에 비례하여 K개 데이터 세트의 특징 조합을 리샘플링(resampling)합니다. 그 후 각 국가의 알려지지 않은 이질성을 해결하기 위해 데이터 증강(data augmentation) 기술을 사용하여 노이즈를 도입합니다. 유사성이 높을수록 더 적은 노이즈가 추가되도록 설계합니다.

## 전이 모델 (Transfer model)
사전 훈련된 글로벌 모델은 직업 등급과 같이 국가 간에 직접 비교할 수 없지만 사망률에 큰 영향을 미칠 수 있는 로컬(지역적) 요소를 제외하고 있습니다. 따라서 이 모델 위에 로컬 데이터를 사용하여 특화된 지역 모델을 학습시킵니다. 먼저 합성 데이터 세트의 글로벌 특징을 기반으로 글로벌 예측을 생성하고, 이후 특화된 GBM 모델을 사용하여 예측을 조정합니다. 이 과정은 유사성에 따라 각 국가의 특성을 반영하여 예측을 미세 조정합니다.

## 일치도 평가 지표 (Agreement metrics)
전이 학습을 통해 얻은 사망률이 영국 보험 가입자의 예상 사망률 대리 지표인 CMI 사망률과 얼마나 일치하는지 평가하기 위해 스피어만 상관관계(Spearman correlation), 코사인 유사도(Cosine similarity), 중앙 집중식 R-제곱(Centered R-squared) 지표를 사용합니다. 이들 지표는 순위, 방향적 일관성, 분산 정렬 측면에서 예측을 검증합니다.

## 드리프트 모델 평가 (Drift model evaluation)
남은 불일치를 평가하기 위해 타겟 국가의 예상 사망률과 전이된 사망률 간의 편차(Drift)를 유발하는 요인을 정량화하는 드리프트 모델을 제안합니다. 실제 예측 오류의 비율을 타겟으로 하여 잔차를 추정하고 다양한 변수나 특징 카테고리에 대한 불일치를 조사합니다.
