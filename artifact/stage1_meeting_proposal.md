# Stage 1 잔여 실험 제안서

## 1. 우리 연구가 풀고 있는 문제

연속혈당측정기(CGM)는 매 5~15분마다 환자의 혈당을 자동으로 기록하는 센서이다. 

이 데이터를 바탕으로 **"지금으로부터 15~45분 뒤 혈당이 몇 mg/dL일 것인가"**
를 AI로 예측하는 것이 본 연구의 과제이다.

이 예측이 정확하다면, 저혈당이나 고혈당이 발생하기 전에 환자에게 미리 경고를 줄 수 있다. 그러나 현실적으로, 병원 A에서 수집한 데이터로 학습한 AI 모델이 병원 B의 환자에게도 잘 작동하는지 -- 즉 **일반화 가능성** -- 는 아직 충분히 검증되지 않았다.

---

## 2. 선행 실험에서 무엇을 했는가

우리는 LightGBM(결정트리 기반 머신러닝 모델)을 사용하여, 여러 코호트의 CGM 데이터로 학습한 모델이 다른 코호트의 환자에게도 적용될 수 있는지를 실험하였다.

구체적으로, 1형 당뇨(T1D) 환자 데이터를 소스(학습용)로, 2형 당뇨(T2D) 또는 혼합(Mixed) 코호트를 타겟(예측 대상)으로 설정하여, 질환 유형이 다른 병원 간 전이가 가능한지를 검증하였다. 1형 당뇨는 자가면역에 의한 인슐린 결핍이, 2형 당뇨는 인슐린 저항성이 주된 원인이므로, 혈당 변동 패턴이 근본적으로 다를 수 있다.

이때 5가지 학습 전략을 비교하였다:

| 전략 | 설명 |
|---|---|
| **Source-Only** | 다른 병원(T1D) 데이터만으로 학습. 대상 병원 데이터는 전혀 사용하지 않음 |
| **Target-Only** | 대상 병원 데이터만으로 학습. 다른 병원의 지식을 전혀 활용하지 않음 |
| **Mixed** | 다른 병원 + 대상 병원 데이터를 단순 합산하여 학습 |
| **CORAL** | 다른 병원 데이터의 통계적 분포를 대상 병원에 맞게 정렬한 뒤 학습 (도메인 적응) |
| **TrAdaBoost** | 다른 병원 데이터 중 대상 병원과 유사한 샘플에 높은 가중치를 부여하여 학습 (전이학습) |

여기서 **Target-Only는 "전이학습을 전혀 사용하지 않는 기준선(baseline)"**
이다. 전이학습(CORAL, TrAdaBoost)의 존재 의의는 다른 병원의 데이터를 활용하여 Target-Only보다 더 나은 성능을 달성하는 것이다.

---

## 3. 무엇이 문제인가

선행 실험 결과, CORAL과 TrAdaBoost는 Source-Only에서 발생하는 성능 하락(negative transfer)을 해소하여 Target-Only 수준까지 성능을 회복하는 데는 성공하였다. **그러나 Target-Only를 유의미하게 초과하지는 못하였다.**

이것이 문제인 이유:

> **전이학습의 핵심 가치는 "다른 병원의 데이터를 활용하여 대상 병원만의 데이터로는 달성할 수 없는 수준의 성능을 끌어올리는 것"이다.** 만약 전이학습이 Target-Only와 동일한 성능밖에 내지 못한다면, 다른 병원의 데이터를 수집하고 통합하는 비용과 노력이 정당화되지 않는다.

---

## 4. 아직 답하지 못한 질문

위 결과에 대해 네 가지 가능한 해석이 존재하며, 아직 어느 것이 맞는지 구분되지 않았다:

| 해석 | 의미 |
|---|---|
| **A. 우연** | 특정 난수 시드나 하이퍼파라미터 조합에서만 나타나는 현상. 조건을 바꾸면 전이학습이 더 나은 성능을 보일 수도 있다 |
| **B. 데이터 특이성** | 사용한 특정 데이터셋 조합에서만 발생하는 현상. 다른 병원 조합에서는 전이학습이 효과적일 수 있다 |
| **C. 질환 유형 차이** | 소스(T1D)와 타겟(T2D)의 병태생리가 근본적으로 달라서, 어떤 전이학습 기법이든 이 갭을 넘기 어려운 것일 수 있다. 즉, 실험 난이도 자체가 높게 설정된 것이지 방법론의 한계가 아닐 가능성 |
| **D. 모델의 구조적 한계** | LightGBM + CORAL/TrAdaBoost가 혈당 데이터를 독립적인 개별 행(row)으로 처리하기 때문에, 혈당의 시간적 흐름(추세, 관성)을 구조적으로 학습하지 못하는 한계 |

해석 C와 D의 구분이 특히 중요하다. 만약 원인이 C(질환 차이)라면, 방법론을 바꿔도 개선이 어렵다. 반면 원인이 D(모델 구조)라면, 시계열 전용 아키텍처로 전환하여 개선할 수 있다.

---

## 5. 제안하는 실험

위 네 가지 해석을 구분하기 위한 진단 실험을 제안한다:

| 실험 | 검증 대상 | 핵심 질문 |
|---|---|---|
| 재현성 검증 (S1-1) | 해석 A 배제 | 난수 시드를 10개로 바꿔도 "전이학습이 Target-Only를 이기지 못한다"는 결론이 일관되게 유지되는가? |
| 다기관 교차 검증 (S1-2) | 해석 B, C 구분 | 26개 데이터셋을 순환하며 테스트할 때, 같은 질환 간 전이(T1D -> T1D)에서도 동일한 현상이 나타나는가? |
| 잔차 시간 구조 분석 (S1-4) | 해석 D 확인 | 모델의 예측 오차가 시간적으로 상관되어 있는가? (즉, 모델이 놓치고 있는 시간적 패턴이 존재하는가?) |
| 도메인 거리 분석 (S1-3) | 보조 증거 | 병원 간 데이터 분포 차이가 클수록 성능 하락도 커지는가? |
| 분류 전환 (S1-5) | 임상 함의 | 위 한계가 임상적 분류(저혈당/정상/고혈당) 판단에서도 동일하게 나타나는가? |

특히 S1-2(다기관 교차 검증)에서는 **질환 유형별 하위 분석**을 수행한다:

- **T1D 코호트가 타겟인 경우** (소스도 T1D): 같은 질환 간 전이에서도 Target-Only 초과 실패가 나타나는가?
- **T2D/Mixed 코호트가 타겟인 경우** (소스는 T1D): 선행 실험과 동일한 설정에서의 결과 재확인.

만약 같은 질환 간 전이(T1D -> T1D)에서는 전이학습이 성공하고, 교차 질환 전이(T1D -> T2D)에서만 실패한다면, 원인은 해석 C(질환 차이)이다. 반대로 같은 질환 간 전이에서도 동일하게 Target-Only 초과에 실패한다면, 이는 해석 D(모델의 구조적 한계)를 강하게 지지한다.

---

## 6. 예상 결과와 다음 단계

**만약 해석 D(모델의 구조적 한계)가 확인된다면:**
- 정적 머신러닝의 한계를 데이터로 입증한 결과 자체가 논문의 1차 기여(Stage 1 논문)가 된다.
- 이 증거를 근거로, 시계열 전용 아키텍처(RNN, Transformer 등)를 활용한 전이학습(Stage 2)으로 전환하는 타당성이 확보된다.

**만약 해석 C(질환 유형 차이)가 주요 원인이라면:**
- 같은 질환 내 전이학습의 유효성이 확인되었다는 긍정적 결과와, 교차 질환 전이의 고유한 난이도를 규명한 기여가 남는다.
- Stage 2에서는 교차 질환 전이보다 동일 질환 내 다기관 전이에 초점을 맞추는 방향 전환이 가능하다.

**만약 해석 A 또는 B로 귀결된다면:**
- 정적 전이학습이 특정 조건에서는 유효함을 보여주는 결과가 되며, 이 역시 논문으로 보고할 가치가 있다.

어느 방향이든 논문으로 귀결되므로, 이 실험은 연구 진행에 손실이 없다.
