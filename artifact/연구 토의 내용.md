재현성의 정의

- 한 환경(예: 특정 병원)에서 개발된 모델이 다른 환경에서 수집된 새로운 데이터셋에 대해서도 일관된 성능을 보이는가
    - 모델의 외부 타당성 또는 일반화 능력(Generalizability)과 연관
        - 동일한 모델 또는 알고리즘을 새로운 데이터에 적용했을때 **성능 지표**들이 얼마나 유지되는지 판단
            - 성능지표: Accuracy, Precision, Recall, F1-score, Sensitivity, Specificity, AUC
        - 내부 데이터로만 평가된 모델은 성능을 과대평가하며, 외부 데이터 적용시 성능이 떨어지는 사례가 보고됨 (Maybe overfitting: may need to consider bias + variance trade off)
            - reference: https://doi.org/10.1038/s41746-022-00614-9
        - 보통, 모델의 재현성을 평가하기 위해서는 Training에 사용되지 않은 독립된 데이터셋을 가지고 성능지표가 안정적으로 유지되는지를 정량적으로 측정
- Approach 1: 모델 학습 단계에서의 일반화 예측 지표
    - Training에 사용되는 데이터 및 모델 자체만으로 외부 데이터에 대한 성능 유지 가능성 예측
        - 데이터 다양성 지표: 훈련 데이터 자체의 다양성 정량화 (즉, 다양하면 할수록 일반화할 잠재력이 높음)
            - Dispersion:  $D(G) = \sum_{(x_i, x_j) \in G}d(x_i, x_j)$
                - 데이터 셋 내 모든 관측쌍 사이 거리의 합 (computational cost highly depends on sample size)
                - $d(x_i, x_j)$: cosine
                - Dispersion 값이 클수록 (다양할수록) 데이터의 범위가 넓어 잠재적으로 훈련 데이터에서 포착하지 못한 새로운 상황도 포괄할 가능성이 높음
                - May use convex hull in embedding space instead.
                - 하지만 데이터가 convex hull 밖에 존재한다면 이 Dispersion 척도는 충분하지 않음
                - reference: [https://aclanthology.org/2022.coling-1.437.pdf#:~:text=2,respectively%2C we define the dispersion](https://aclanthology.org/2022.coling-1.437.pdf#:~:text=2,respectively%2C%20we%20define%20the%20dispersion)
        - Learning Curve Extrapolation with logistic or power-law function
            - 훈련 초기에 learning curve가 stable하거나, train set/ validation set간 차이가 커지면 일반화성능이 낮음을 의미
            - 하지만 새롭게 이용할 데이터의 도메인과 훈련에 이용했던 데이터의 도메인의 차이가 큰 경우 이런 learning curve가 새 데이터셋의 learning curve와 일치한다는 보장은 없음
            - reference: [https://arxiv.org/abs/2310.20447#:~:text=,the performance in earlier epochs](https://arxiv.org/abs/2310.20447#:~:text=,the%20performance%20in%20earlier%20epochs)
        - 모델 불확실성 지표: 예측 확률의 신뢰도 또는 모델의 불확실성
            - 모델 불확실성 추정 기법을 통해 훈련 데이터의 예측분포를 살펴보고 over-confidence 경향이 있으면 데이터의 도메인이 바뀔때 오판 가능성이 높음.
                - reference:  [https://aclanthology.org/D19-1222.pdf#:~:text=and slow,predict performance drops with an](https://aclanthology.org/D19-1222.pdf#:~:text=and%20slow,pre%02dict%20performance%20drops%20with%20an)
        - 모델 복잡도 및 매개변수 평탄도:
            - 일반적으로 내부 검증 성능이 높은 모델. 즉,. traing set, validation set간의 차이가 작은 모델이 외부 데이터에서도 더 잘 작동하는 경향을 보임
            - 일반화할수 있는지의 여부는 도메인 분포 차이, Confidence Bound, Flat minima로 결정 가능. 이중 Flatness는 일반화여부를 결정할수있는 요소.

    - Approach 2: 도메인 분포 차이 기반 성능 예측 척도
        - 훈련 도메인과, 새 데이터의 도메인 간 분포 차이를 직접 측정

    - 딥러닝 기반 유방암 진단 기술이 직면한 현재의 과제와 향후 연구 방향성을 제시.
    
    **(2) Why is the work important**
    
    - 유방암 - 여성에게 가장 흔하게 발생하는 악성 종양, 조기 발견과 정확한 진단이 환자의 생존율과 직결됨.
    - 기존 병리학자들이 현미경을 통해 시각적으로 판단하거나 IHC 염색을 하는 방식은 비용과 시간이 많이 소요되는 단점이 있음.
    - 현재 IHC 기반 검사 결과의 약 20%가 오류일 가능성이 있는 등, 수동 진단**도** 오진의 위험이 존재함.
    - 전산 병리학과 딥러닝을 통해 이러한 한계를 극복하고 임상 작업의 효율성과 진단의 질을 크게 향상시킬 수 있으니, 내가 모은 정보 가지고 연구할 수 있다고 주장.
    
    **(3) What is the literature gap**
    
    - 딥러닝 모델- 우수한 성능을 내기 위해서 방대한 양의 훈련 데이터가 필요함. 의료 분야 - 병리학자의 수작업 라벨링이 필요 -> 데이터 확보 난이도 및 비용이 높음.의사 결정 과정을 알 수 없는 '블랙박스' 모델 -> 실제 의료 현장에서 의료 전문가들의 완전한 신뢰를 얻기에는 Interpretability가 부족.
    - 기존 딥러닝 모델 - Deterministic 성격을 띠고 있음, > 훈련에 사용된 데이터와 다른 분포를 가진 새로운 샘플을 만났을 때 심각하게 오작동할 수 있는 위험이 있음.
    
    **(4) How is the gap filled**
    
    - 사실 직접적으로 gap을 채우려는 논문은 아님
    - 본 논문은 리뷰 연구임 -> 연구자들이 데이터를 쉽게 찾고 활용하도록 공개 데이터셋과 소스 코드를 모아 데이터 접근성 문제를 완화하고자 함.
    - 데이터 부족 문제를 해결할 방법으로 두 개 이상의 이미지를 결합해 새로운 훈련 샘플을 만드는 Image composition이나, Transfer learning을 제안만 하고 있음.
    - 블랙박스 문제에 대응 - MIL이나 GNN 등을 적용해 전문가가 이해할 수 있는 Explainable AI를 구축하는 최신 연구 접근법이 있으니 연구가 필요하다고 소개.
    
    **(5) What is achieved with the new method**
    
    - 논문에서 검토된 연구들에 따르면, 딥러닝 프레임워크를 보조 도구로 활용할 경우 인간의 진단 오류율을 85%까지 감소시킬 수 있다고 함.
    - 과거 진단 대회인 Camelyon에서 병리학자의 암 발견 민감도가 73.2%에 그친 반면, 딥러닝 기반 접근 방식은 92.4%의 압도적인 발견율을 달성 해버림.
    - 앙상블 모델 등 다양한 최신 딥러닝 기법을 적용한 유방암 진단 모델들이 최대 99.55%에 달하는 매우 높은 분류 정확도를 기록하고 있음.
    
    **(6) What data are used**
    
    - 사용되는 데이터 형태는 전체 슬라이드 이미지WSI, H&E 염색 조직 샘플, Mammogram 이미지, MRI 영상 등임.
    - 학습 및 평가를 위해 BreakHis, DDSM, INbreast, Breast Cancer Wisconsin Dataset 등 다양한 글로벌 공개 유방암 데이터베이스를 활용함.
    
    **(7) What are the limitations**
    
    - 연구자들은 딥러닝 모델을 지속적으로 발전시키기 위한 Annotation이 달린 훈련 데이터의 절대적인 양이 여전히 부족하다고 말하고 있음.
    - 실제 의료 환경에 완전히 배포하기에는 진단 시스템의 신뢰성을 보장하기 어렵기 때문에, 예측 결과에 대한 Uncertainty도 인식하고 평가하는 모델 개발이 추가로 필요하다고 함.
    - 성능 향상을 위해 딥러닝 앙상블 기법을 활용할 경우 시스템의 연산 복잡도가 지나치게 높아지므로, 이를 관리 가능한 수준으로 낮추기 위한 Knowledge distillation 등의 추가 연구를 요구하고 있음.
